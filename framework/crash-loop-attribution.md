# 暴跌互爆归因与救市需求判断框架（融资余额三分法）

> 入库：2026-10-09（提案 `proposals/20261009-pattern-nomination-crash-loop-attribution.yaml`
> 人审通过，证据跨 2026-07 杠杆恐慌与 2026-10 机构互爆两个剧本）。
> 对应 `reasoning-patterns.yaml` pattern_id: `crash_loop_attribution`。

## 一句话原理

**先归因"谁在互爆"，再推导"要不要救市"**：涨出来的风险（估值泡沫）跌一波就消化完；
跌出来的风险（机构互爆恶性循环）没有强有力的向上力量无法打破——历史上每一次都靠
GJD 买入终结。因此暴跌中的核心问题不是"何时跌够"，而是"这是什么剧本、需不需要
GJD、GJD 托的是什么底"。

## 使用场景

- 指数或主线板块连续暴跌，出现"不计代价一键清仓"式下杀
- 需要回答：这轮下跌什么性质 / 会不会止跌 / 要不要等国家队 / 融资盘会不会爆仓
- 前提：融资余额、龙虎榜机构席位、外围联动三类数据可得

## 四步推理

### Step 1 互爆主体识别（三分法）

| 剧本 | 判别数据 | 数据特征 |
|------|---------|---------|
| 融资盘互爆（杠杆平仓螺旋） | **融资余额走向** | 暴跌中余额骤降 = 杠杆平仓中；余额仍增 = 散户在加仓，**排除**融资盘互爆 |
| 外围传导 | 隔夜美股/韩股/费半 | 外围同步暴跌 → 传导剧本；外围平稳 → 内部剧本 |
| 机构互爆 | 龙虎榜机构席位 + 领跌结构 | 机构专用席位抱团撤退 + 机构重仓股（公募/险资/社保重仓）领跌 |

数据锚点优先级：**融资余额是第一锚点**——它直接区分"散户杠杆剧本"与"机构剧本"。

### Step 2 恶性循环机制确认

机构互爆循环链条：低成交量下部分资金卖出 → 杀跌触发止盈 → 绝对收益结构被动卖出
→ 量化调仓 → 赎回压力下卖未跌停持仓 → 相互踩踏持续放大。

确认标志（同时出现才算成立）：
- 持续下杀已与基本面无关
- 重仓基金不计成本卖出
- 跌停卖不出去转而卖没跌停的持仓（流动性挤压特征）

### Step 3 救市需求判断

- 涨出来的风险 → 估值消化型下跌，**不需要**外部力量，跌一波即结束
- 跌出来的风险（机构互爆循环）→ **只能由 GJD 级买入打破**，判断重心转为
  "GJD 何时进场、以什么形式进场"

### Step 4 救市形式与力度校准

- GJD 增持央企/宽基 ETF 托的是**指数底与权重底**，科技等成长底仍需自身筹码出清确认
- 单日拉抬对情绪帮助有限，护盘需**持续一至两周**才有效
- ⚠️ 机构互爆历史样本少；GJD 的经验在散户杠杆爆仓（2015 年），机构互爆的资金规模
  难判断，救市力度存在不确定性——不要默认"GJD 来了就万事大吉"

## 数据通道

| 数据 | 通道 | 说明 |
|------|------|------|
| 两融余额/融资净买入（日频） | `qing_investment.marketdata.get_margin_balance(days=N)` | 东财 RPTA_WEB_MARGIN_DAILYTRADE，T 日晚间披露；与 UP 截图同口径（2026-10-09 实测吻合） |
| 龙虎榜机构席位 | 龙虎榜数据 | 机构专用席位净买卖方向 |
| 外围联动 | 隔夜美股/韩股/费半 | 判断是否传导剧本 |
| 领跌结构 | 板块/个股行情 | 领跌是否机构重仓方向、跌停分布 |

融资净买入 = 融资余额日差值（接口不直接给偿还额/净买入，差值口径与 UP 图一致，
尾差为四舍五入级）。

## 历史案例对照

| | 2026-07 杠杆恐慌 | 2026-10 机构互爆 |
|---|---|---|
| 融资余额 | 加速新高逼近 3.1 万亿历史高点 | 节前连降后 10-08 反增 +41 亿（散户加仓） |
| 互爆主体 | 融资盘+量化放大 | 险资/社保/公募/私募/FOF/量化卡风控赎回线 |
| 外围 | 韩股去杠杆传导 | 外围平稳，纯内部 |
| 救市形态 | 国家队增持央企+宽基 ETF 托指数底（7-19~21 判定） | 待观察，历史经验在 15 年散户杠杆剧本 |

## 证伪条件

- 暴跌中融资余额骤降且散户席位割肉为主 → 实为融资盘互爆，三分法误判主体
- 机构互爆循环在未见 GJD 级买入的情况下自行终结 → "只能靠 GJD 打破"被证伪
- 外围同步暴跌被证明是主因 → 外围传导剧本误判为内部互爆

## 与相邻框架的边界

- `fund_flow_segmentation`（两路资金分层）：解读**普涨日**的资金结构；本框架处理**暴跌日**的归因
- `sentiment_cycle`（情绪周期）：定位冰点/修复；本框架回答暴跌的**性质与外部力量需求**，
  二者可串联：先本框架定剧本，再情绪周期定修复节奏
- `macro_transmission`：外围冲击传导链；本框架 Step 1 的外围排除法复用其数据，但结论方向相反
  （排除外围后才落到内部互爆）
