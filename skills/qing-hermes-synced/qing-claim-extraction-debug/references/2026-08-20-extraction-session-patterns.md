## 新坑：美股/日股字母代码不能进 related_stocks（2026-08-20 早盘实测）

### 症状
Gate 2 报错：
```
related_stocks code='MRNA' 不是纯数字字符串
related_stocks code='MRK' 不是纯数字字符串
```

### 根因
related_stocks 的 code 字段被 Gate 校验为**纯 6 位数字**。美股（莫德纳 MRNA、默沙东 MRK）、
日股（铠侠 285A，东财返回 `285A 铠侠 日股`）都不是 A 股代码——既不能放 related_stocks
（字母/混合代码报错），也不能在 statement/interpretation 里标 `(MRNA)`（Gate 2 文本
代码正则只认 `（\d{6}）`）。

### 处理
- **从 related_stocks 移除**（美股/日股标的 A 股知识库不收）
- 文本中保留公司名不标代码；若 Gate 2 因公司名报"未标注 6 位代码"，
  把**完整匹配片段**加入 NON_COMPANY（与 §13 非 A 股规则一致）
- 与港股的差异：港股是 5 位数字代码（00268）会报"不是 6 位"；美股/日股是字母/混合
  代码（MRNA/285A）报"不是纯数字"——**两类都是非 A 股，统一进 NON_COMPANY**，
  美股注释 "美股"，韩股注释 "韩股"，日股注释 "日股"

### 排查
东财 suggest API 返回 SecurityTypeName 字段可识别：
- `深A/沪A/科创板/北交所` → A 股，可进 related_stocks
- `美股/日股/韩股/港股` → 非 A 股，从 related_stocks 移除
