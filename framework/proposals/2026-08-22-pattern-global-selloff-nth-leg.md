# 模式提名：全球同源抛售"第 N 棒"定性 → 操作含义分化

## 模式内容

1. A 股大跌时先做归因定位：只在 A 股内部找原因会得出偏悲观、偏错误的结论；
   把视野放到全球传导链（美债长端 → 美股半导体 → 韩股熔断 → …），若 A 股是链条的**第 N 棒而非第一棒**，
   则定性为**全球同源抛售的外力扰动**。
2. 定性决定后续所有推演的方向：
   - **内生性回调** → 需要时间换空间、需要板块自我出清，按若干日的出清节奏推演；
   - **外力扰动** → 只需要外力本身消失，不按内生出清节奏推演时间。
3. 外力并不消灭内部问题：A 股自身的筹码结构问题（高位拥挤、增量集中）是被外力**放大**而非**创造**——
   外力退去后，这些问题仍然在，仍需单独跟踪。

## 触发与动作

- 触发：A 股放量大跌，且隔夜/同期外盘出现同向异动（美债、费半、亚太股市）。
- 动作：先定性第几棒 → 外力型则盯外力解除指标（如 30 年期美债收益率，当期参考 5.33%，
  claim-20260819-072）而非内部出清节奏；内力型则按时间换空间推演。

## 证据

- 2026-08-19（大跌日）："这不是 A 股自己的调整……A 股是这条链条的第四棒"（claim-20260819-043）；
  同日操作含义二分（claim-20260819-052）。
- 2026-08-20：市场按"外力扰动"定性走出缩量修复而非深度出清，与该推演的方向一致（弱验证，未达独立命中标准）。

## 证伪条件

- 外力指标解除（美债回落、费半止跌）后 A 股仍继续缩量创新低 → "外力只需消失"推演失效，转回内生出清框架。

## 窗口与局限

- 证据集中 08-19 单日单事件、单 regime（恐慌/调整）——归因类模式样本天然稀疏，转正需等待下一次
  全球同源事件的对照验证。与 2026-08-19 主轨 patch 提案（驱动力归因前置）互补：那个管 Agent prompt，
  本条管分析框架。
