# 模式提名：指数-情绪背离识别（涨跌家数口径）

## 模式内容

1. 每日必答"指数端与情绪端是否同向"：指数涨/平但下跌家数显著多于上涨家数（如超 3000 只下跌）
   = 指数强情绪弱背离；指数跌但涨停/连板情绪坚挺 = 指数弱情绪强背离。
2. 背离方向的含义不对称：指数强情绪弱 = 指数被权重/防御掩盖，回踩未被消化——
   「调整不充分往往会带来更剧烈的分歧」；指数弱情绪强 = 结构性机会仍在
   （与同日"高度宽度背离"提案联用）。
3. 与存量模式的关系：`reasoning-patterns.yaml` 中 example `intraday_sector_rotation_signal_20260105`
   的 step1「情绪背离识别」覆盖盘中"指数高开 vs 连板滞后"的背离，本模式是其复盘尺度独立化：
   以涨跌家数为硬口径、双向定义、每日必答。

## 触发与动作

- 触发：stage_reason 引用上涨/下跌家数数据时（盲判包每日必含）。
- 动作：必须显式输出「同向 / 背离」判断；判背离时写明被谁掩盖（权重/防御品种）及其含义，
  并在 scenarios 的构造中体现（背离日的修复结论降置信度）。

## 配套数据

上涨/下跌家数、指数涨跌幅（盲判包已有，无新通道）；拉升时段板块构成见同日数据通道提案。

## 证据

- 2026-08-18（震荡）：UP「今天指数端与情绪端已经明显背离，亏钱效应非常直观」「今天的下跌家数
  与指数表现之间的落差，本身就说明这次回踩并没有被真正消化，只是被防御品种在盘面上掩盖了过去。」
  当日盲判 stage_reason 引用了涨跌家数（2121 vs 3292）却未上升为背离判断——数据被引用、
  推理步骤缺失。
- 2026-08-16 周复盘（震荡，评 8-14 盘面）：UP「指数与个股的方向明显背离，是典型的指数强、
  个股弱结构」（当日超 2900 只下跌 vs 创业板指 +1.12%）——同一判断在周复盘尺度复现。
