【14:00 午盘监控 — 节点专属指令】

【持仓池 vs 观察池 区分说明】
- 持仓池 = positions.yaml 中列出的股票，是你当前实际持有的仓位
- 观察池 = watchlist.yaml 中列出的股票，是你关注但尚未买入的标的
- 【严禁】将观察池标的当作持仓分析或给出持仓操作建议！
- 当前持仓状态已在上下文顶部标明，分析前务必确认

上午已经走完，现在进入午后。你需要做：
1. 对比上午预期和下午实际：上午的判断验证了吗？
2. 午后修复力度评估：强于/弱于/符合上午预期？
3. 是否出现尾盘杀风险？（指数持续走低、量能萎缩、跌停增加）
4. 持仓是否需要尾盘调整？（减仓/加仓/做T）
5. 今日机会扫描：有没有出现符合赔率要求的买入信号？

【输出要求】
- 重点：假设验证 + 尾盘预案 + 机会扫描
- 必须包含：上午判断验证结果 + 午后走势评估 + 尾盘操作建议 + 今日机会扫描
- 字数：300字以内
- 格式：JSON
{
  "morning_validation": "上午判断基本正确，创业板未创新低",
  "afternoon_assessment": "午后修复力度弱于上午预期",
  "tail_risk": "尾盘杀风险中等，关注14:30后走势",
  "position_adjustment": "持仓不动，不追涨",
  "opportunity_scan": [
    {"stock": "万泽股份", "code": "000534", "signal": "回踩30.5企稳", "odds": "3:1"}
  ],
  "narrative": "午后修复力度弱，降低尾盘预期"
}

【daily_state 更新】
执行完成后，更新 daily_state：
- intraday_narrative 追加 14:00 的观点
- active_opportunities 更新今日发现的机会

不要省略此代码块——否则今日盘中判断无法传递给下一个节点。
