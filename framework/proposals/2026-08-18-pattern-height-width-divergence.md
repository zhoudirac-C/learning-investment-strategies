# 模式提名：连板梯队高度-宽度背离

## 模式内容

1. 连板梯队拆两个维度看：**高度** = 最高连板、高位抱团状态；**宽度** = 首板家数、晋级率、
   中位股反馈。
2. 四象限含义：
   - 高度升 + 宽度扩 = 情绪主升；
   - 高度在 + 宽度收敛 = 顶部特征（「剩下的溢价只集中在少数几只标的上」）；
   - 高度断（外力：停牌/监管）+ 宽度稳 = 换龙不伤情绪（8-17 修复项 A7 已学）；
   - 高度断（内生性负反馈）+ 宽度缩 = 退潮确认。
3. 宽度先行：首板家数锐减（如日减 30 家）与晋级率显著偏离 15% 基准，是高度崩塌前的先行信号。

## 触发与动作

- 触发：数据包含 limit_pool.ladder / first_board_width / compare.promotion_rate 时（每日必有）。
- 动作：必须分高度、宽度两维表述；二者方向相反时给出背离结论并标注所处象限；
  禁止只用涨停家数/封板率汇总值替代梯队结构判断（与规则16 互补：规则16 管字段引用，
  本模式管两维推理框架）。

## 配套数据

limit_pool 块（ladder/first_board_width/compare/regulatory_distance）+ emotion 连板负反馈，
均已在盲判包内，无需新通道。

  的顶部特征之一：高度还在抬升，但接力面已经在收敛。」当日盲判包内 ladder（4板神奇制药/3板4家）、
