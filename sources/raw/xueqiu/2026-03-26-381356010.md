# 2026-03-26 边城浪子1986

今年终于有时间去现场参加业绩发布会，无论怎么看财报、听电话会，都不如见一面。 先说结论： 中国太平 现任高管是我见过的最专业的保险管理层，对保险行业的经营非常了解，也了解公司情况，绝对是精英。 其次，太平董秘说他们关注传统媒体、新媒体、分析师的各种问题，搜集整理高管们人手一份，所以市场认为太平管理层不在乎投资人是不对的，太平非常在乎市场声音，只是大多数人不知道而已。 会上董秘回复了现场分析师没问到，但是网络上关心的两个重要问题，1、各项财务指标的稳定性，公司努力做到兼顾各项财务指标的稳定，争取做到不要大起大落，有些投资人关注短期，比如NBV、净利润增速，有些关注长期如EV等，侧重点不同。公司以长期战略为主，主要就是资产负债匹配同时缩小风险敞口，举例NBV，增速慢主要是分红险的新业务价值低于传统险，但是分红险锁定风险敞口，解决了利差损的风险，所以还要卖，这是行业大趋势，不能因为价值低就不卖，价值低不代表没价值，价值低风险也小。价值高的要承担利差损风险，平衡一下还是要卖前者。但是，公司可以通过开发长久期的分红险提高NBV。2、分红问题，分红的可持续性考虑到今年的利润特殊性后，做到长期绝对值是增长的，除了极端情况比如影响力偿付能力，那肯定不能多分了，这是可以理解的，23-24年分的少，是因为偿二代不知道新会计准则对偿付能力有多大影响，所以选择保守，25年新会计准则落地，不确定性因素消除，所以正常分。 我判断2026年分红绝对值不会小于2025年。 关于投资端，看出来压力挺大的，25年权益的配置占总资产比例相比自己是最高，但是相比行业只能算中枢，坚定不移的新保费入市。权益采取80%高分红、20%新质生产力的哑铃策略。以A股为主，因为A股受外部环境影响较小，只受国家经济、企业业绩的内部影响；港股是即受国内经济影响，也受外部环境影响，所以港股波动太大，而险资最怕大幅波动。 投资副总对25年的投资回报率不满意，希望下次见面再聊投资话题能轻松些，所以26年最大的看点是总投资回报率的提升。 公司正在编制十五五规划，开局之年要坚决完成任务。让我印象深刻的是，总经理说十五五规划里面要让太平的员工有安全感、不要焦虑，这是我头一次看见有保险公司把员工的幸福放到5年规划。 最后说一下我的结论： 中国太平 的管理层是真正的长期主义，且央企开始卷了，并不仅仅是太平开始卷，是国寿、人保，这些央企都开始卷了，央企一旦开卷，民企基本没什么机会。 另外，港股真是给机会， 中国太平 确定性已经这么强了，股价还能跌，放在a股，这是不可能的。再有5年，我靠太平股息分红都能回本，股票多少钱，短期指标怎么样我已经不关心了，卖不卖的也无所谓了。 $中国太平(00966)$
