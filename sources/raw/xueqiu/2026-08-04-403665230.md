# 2026-08-04 幸运Huang

8月4日，海洋网联船务（ONE）公布2026财年第一财季（2026年4月1日至6月30日，即自然年2026年二季度）业绩。在经历了2025年四季度亏损8800万美元后，2026年一季度，ONE实现净利润5500万美元；2026年二季度ONE实现净利润3100万美元，环比递减，相当离谱。 本季度商业环境 货运需求在本季度内发生了显著变化，从4月时的需求状况参差不齐转变为5月和6月的持续复苏。具体而言，来自中国的货运量有所增加，这主要得益于提前采取行动以应对预期中的燃油附加费上涨、可能的关税变动以及库存补充所带来的影响，这些因素共同推动了跨太平洋贸易领域需求的强劲表现。亚欧贸易也持续呈现复苏态势。 本季度全球船队规模扩大了逾30万个标准箱，使总运能提升至超过3400万个标准箱。然而，霍尔木兹海峡的运输中断以及持续的港口拥堵现象，部分抵消了新增运能的影响，限制了市场供给的有效增长。 在强劲货运需求的支撑下，供需状况趋紧，各类贸易航线的运费继续呈现上升趋势。在亚欧贸易领域，持续的港口拥堵限制了运力，进一步加剧了供需紧张的局面。 霍尔木兹海峡持续的不稳定局势继续扰乱航运，导致承运人暂时无法恢复中东直航服务。 具体而言，2026财年第一财季（即自然年2026年二季度），ONE实现营业收入45.4亿美元，同比增长12.1%；息税折旧摊销前利润（EBITDA）为7.1亿美元，同比增长14.8%；息税前利润（EBIT）为7600万美元，同比增长100.0%；净利润为3100万美元，同比下降64.0%。EBITDA利润率为15.6%，EBIT利润率为1.7%（比一季度还要低。。 ）。 业绩如此之差的问题主要出在成本端上，看One自己的利润分析货量上涨和运费上涨利润增加了3.82亿美金，但是直接航次成本增加了1.01亿，货量上升导致成本增加1.32亿，燃油成本上升了1.25亿，间接成本上升了0.42亿，成本项增加导致利润损失了4亿。 燃油单价上面环比上升了51.4%，同比增加了24.5%，相比24Q2(自然季度）的燃油价格594USD/MT还要高出12%， 这个燃油价格的涨幅跟我5月初拍脑袋时的简单测算基本一致，比我7月东方数据出来以后估算的燃油价格涨幅要高出不少 One和美森一季报（燃油成本上升对船司成本影响估算） 网页链接 { 集运相关跟踪周报 week2628（东方海外Q2营运报告） } One自从去年萝卜脱离跑去双子星自己成为卓越联盟老大以后成本一直处于失控状态，去年的业绩表现远远差于前几年，成本状况也已经不像一家亚洲船司。去年的EBIT利润率一直比马士基还要差，四季度仅为-2.1%亏损，而同期海控航运EBIT还有9.27%，达飞也有7.4%。 二季度one的EBIT利润率和净利润均是环比下降差到离谱，而同期达飞和美森的数据不管是利润率还是利润都是环比增长。从去年的数据看同属海洋联盟的达飞表现一直要比老司机和萝卜，one都好，跟海控利润率数据相关变化趋势一致性更好（绝对值一直低几个点），达飞二季度的数据参考意义更大。 26Q2同行比较之--达飞 尽管Q2表现如此之差，One还是大幅上调了全年指引: 由于运价上涨和货物需求强劲，ONE目前预计2026财年净利润将达到9亿美元（之前为3亿美元）。 ONE指出，由于霍尔木兹海峡的局势仍然不断变化，最新预测假设运营状况将于10月恢复至冲突前的水平;而好望角航线改道措施则将持续整个财政年度 需要注意的是按照这个全年指引意味着Q3的EBIT大概在7.74亿美金是Q2的10.2倍，Q3的净利润大概在7.19亿是Q2的23.2倍。。。。 而26Q4和27Q1合计的2.5亿EBIT和1.5亿净利润虽然相比26Q3这个季度是很低了，但也是远高于26Q1和26Q2这两个季度（这个预测我感觉不能适用于海控，否则太吓人。。 ）。 $东方海外国际(00316)$ $中远海控(01919)$ $中远海控(SH601919)$
