## 原文

围绕人工智能商业化，最近出现了一场值得关注的争论：即使模型越来越强、使用者越来越多，AI 公司的收入还能保持此前的增长速度吗？争论的焦点，是企业开始给 AI 使用设定预算，以及模型公司对少数大客户的依赖。这关系到一个问题——今天高速增长的 AI 消费，有多少能够长期持续。

一个具体事件发生在摩根大通。根据《Business Insider》9 月的报道，该银行对部分使用 Claude Code 的员工设置了每月 2,000 美元的支出上限，用户可以申请提高额度。Claude Code 是 Anthropic 推出的 AI 编程工具，可以协助工程师编写、修改和检查代码，其运行会消耗被称为 token 的模型处理单位。随着工具使用深入，企业需要把账单与实际产出对应起来。摩根大通的措施说明预算管理正在加强，但尚不能证明该银行的 AI 总支出已经下降。

另一条引发讨论的消息涉及 Meta。媒体转述《纽约时报》的报道指出，Meta 曾在内部预测，每年采购 Anthropic AI 工具的支出可能高达 100 亿美元。这里有一个重要区别：这是潜在年度支出的预测，不能直接当成 Anthropic 已经获得的收入。不过，它提出了一个值得研究的问题：如果一家模型公司的收入较多来自少数大型客户，那么这些客户调整预算、采用自研工具或增加其他供应商，都可能影响增长速度。

这让一些投资者想起了云通信公司 Twilio。Twilio 通过接口向企业提供短信、语音等服务，Uber 曾是其重要客户。公司披露显示，Uber 在 2017 年持续减少使用量，其收入占比从上一年的 14% 降至 8%。这个案例揭示了按用量收费业务的一个特点：客户无需彻底离开，也能明显减少账单。放到 AI 行业，企业可以继续使用某个模型，同时减少无效调用、把简单任务交给便宜模型，并把采购分散给不同供应商。

因此，讨论 AI 收入时，需要分清“年度经常性收入”和“年化收入运行率”。前者通常被简称为 ARR，后者可能只是把最近一个月的收入乘以十二。按用量收费的业务也可以有稳定的收入，但稳定性需要由客户持续消费和合同承诺来支撑。一个月的高额消耗，如果包含集中试用、重复运行或尚未受预算约束的使用，就未必能够持续一年。企业开始控制成本后，用户数和完成的任务量仍可能增加，收入增长却可能放缓。

另一方面，竞争格局也在变化。《华尔街日报》报道，OpenAI 因内部测试发现的安全问题，取消了原定十月推出的 GPT-6.1 Astra。这可能给 Anthropic 留出竞争窗口，也提醒整个行业：模型能力提升之后，还需要达到企业能够放心部署的可靠性要求。与此同时，社交平台流传的 Claude 在 GitHub 提交信息中提及量增长的图表，也不能直接证明付费收入增长——开发者活动、企业采购与模型公司的利润，是三个不同的指标。

这场争论真正涉及的，是 AI 增长的质量和兑现时间。长期看好 AI，与短期担心收入低于预期，并不矛盾：即使一家公司的收入仍在增长，只要低于估值所隐含的速度，投资者也可能重新定价。但目前这些事件，还不足以确认 Anthropic 已经出现增长拐点。接下来需要观察的是，大客户减少的支出能否被新增需求补上，预算上限实际限制了多少消费，以及收入增长能否带来相应的毛利。AI 的商业价值，最终需要通过企业持续付款的意愿来验证。
