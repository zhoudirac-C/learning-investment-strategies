# 量能源门口径对称化

## 分析

当日缺席数据为无（油价缺失已在宏观三条件中正确标注『不可校验』并靠10Y美债4.784%>4.70%失效条件闭环出『利率压制未解除』，未影响结论方向，不构成数据缺），错因集中在流程与概念层。①概念误用：AI 以规则28(a)『破位收涨=修复尝试』将盘前『调整/外力扰动』改判震荡，但触发信号为创业板指+3.41%缩量大阳（量-17%），且驱动可溯源至隔夜外力映射（费半+3.37%、美光+6.1%/闪迪+11.9%、KOSPI+4.61%）催化AI硬件涨停潮——『修复尝试』概念被用于『缩量+外力反抽』场景，『反抽』与『修复/震荡』未切割；且宽基结构未修复（上证3932.70仍低于5日线3945、AI自己写明『收复条件=放量收回5日线上方』），单指数收线不满足阶段切换前提。②步骤缺：重定性环节缺『冲突证据裁决』与『次口确认』两个中介步骤——同一份输出内自持至少五项调整侧证据：(a)宏观三条件之一失效=压制未解除、自述『外力正向映射而非压制解除』；(b)量能源头=存量高低切（证券-48.77/银行-32.08/保险-19.14亿流出对冲半导体+231.88/通信设备+187.61亿流入、成交额19460亿平量环比-4.2%非增量）；(c)上证120min顶（9/3 formed）+上证/科创50 60min顶部钝化在位=禁判主升；(d)防御端煤炭-2.85%/银行-1.72%转跌+种业连板潮=『防御轮动末端、变盘临近』；(e)科创50(25天)/上证(27天)超期周期上级别压制——但流程中无任何步骤要求这些证据与28(a)信号做优先级裁决，单日大阳直接翻转stage；且volume_source_qualify只被用于否决『放量攻击定性』、未对称约束『修复定性』，AI在watch_next自写的『右侧确认=回踩后再度放量上行』确认原则未回灌进阶段判定步骤，导致调整中的外力反抽被升格为震荡。

## 处置建议

volume_source_qualify增补对称规则：量能源子判定=存量高低切（行业流出对冲流入、成交额平量如19460亿环比-4.2%）时，不仅禁止『放量攻击』定性，同等禁止基于单日K线的『修复/阶段升级』定性，stage维持原判直至增量资金口径出现；并将watch_next中的『右侧确认』原则固化为阶段改判的前置校验项。
