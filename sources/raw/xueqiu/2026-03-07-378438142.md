# 2026-03-07 不穿正装

二代刀片电池和闪充的发布，既是汽车电动化上半场结束的哨声，也是燃油车走向终结的丧钟 — 这两天和朋友热烈讨论 比亚迪 新发布的二代刀片电池和闪充技术，心潮澎湃，我坚信新的能源时代已经来临。受限于作者的创作水平，这里只能粗浅地把一些认知和推演结论，以及胡言乱语整理成稿，博君一笑。 — 首先来作一个简单的推演。 以杭州为例，根据豆包数据，目前 全市域范围共分布有450座公共加油站，同时存在5.1万座公共充电桩,50万座私有充电桩。 同样根据豆包数据，现在杭州的油车和电车的数量是3:1，我们先假设年底 比亚迪 的闪充车占电车的10%。 按照 比亚迪 官方的数据，2026年底杭州每3公里布设一座闪充站，假设全都是站中站，每座配备4把枪。全杭州的数量预计为89座，预计为 180个充电位 （豆包演算），当然官方显示实际目前已经有 至少128个充电位 。 同时，城市公共加油站每个站按10个车位考虑加油位，全杭州一共有4500个加油位（实际更少，因为有很多小站）。 现在我们假设全杭州有75万辆油车，和25万辆电车，那么其中有2.5万辆闪充车。 根据公布的数据，加油和闪充的补能速度一致，即5分钟加油500公里，5分钟充电500公里，且油车是得你一进加油站就有服务员来给你插油枪的前提下。 那么每个加油位将对应166辆油车，每个闪充桩将对应138辆闪充车。 也就是说，从补能体验上看，加油站的负荷更高，闪充要比加油更不容易排队，更加便利。 — 这时候就有人来刚了，你 比亚迪 26年杭州就卖2.5万辆车可以倒闭了，闪充肯定比加油更加紧张。 来看公开数据，2025年，杭州 比亚迪 销售35万辆，而全年比亚迪国内共有约350万辆销售额。也就是说，杭州一个城市买了去年比亚迪10%的车。 2026年刨除一二月，如果今年再卖35万辆，你180个桩顾得过来么？ 所以我就说这群人没脑子， 比亚迪 有脑子，不像这些杠精活在梦里，一个城市买的人越多，我闪充站布的越多不就行了，我为什么要去没人买的城市铺那么多闲置的桩？ 假设2026年杭州 比亚迪 闪充车销量是50万，布设的桩按2万座的10%同比增加，杭州将布设2000个站，每个站4把枪，8000个闪充位， 每个闪充桩将对应63辆闪充车 。 假如我再放个海， 杭州到年底只布了1000个站，每个闪充桩仍然只对应126辆闪充车 ，仍然比加油站少！ 而另一边实际情况是，全杭州2024年底有480万机动车，其中油车超过360万辆，实际一个加油位对应800辆油车！！！ 一边是1:800，一边是1：126， 比亚迪 在杭州要每年卖50万辆连卖6年且期间保持4000个闪充位一桩不新建，才能对应当前杭州的油车的困境，问题是，这可能么？ — 因此我提出三点暴论 第一暴论：燃油车将成为历史 搭载二代电池的新能源汽车，拥有超越燃油车的补能速度，并将完全替代燃油车的生态位。 第二暴论：加油站将成为历史 铺满大街的闪充站，将以远超燃油车的便利性在任何地方为新能源汽车完成补能，加油站将永久退出历史舞台。 第三暴论：人类第一次接近能源自由 — 所以，燃油车的丧钟已经敲响。敲响者的名字叫，王传福，比亚迪。 — 最后再补充几个观点 第一，充电即加油，闪充站全面替代加油站； 第二，闪充车主99%的可能性只会冲5分钟（就好像很多人300加一次油），因为500公里是大部分人2周甚至1个月的里程； 第三、有家桩的情况下，车主使用闪充的需求一年不会超过2000公里。 第四，一座加油站的建设成本在1500万以上，时间跨度最快8个月，而一个8枪闪充站中站的成本至多需要600万，改造时间两周以内（官方声称7天以内） 至于第三个暴论，我还没想透，但我直觉， 比亚迪 将成为国家电网的二弟。 $比亚迪(SZ002594)$ $上证指数(SH000001)$ $ $深证成指(SZ399001)$
