# 2026-07-10 养叔的猫

看到很多企业都发布了半年报预增公告，几乎都是大增的行情，尤其科技版块，几百上千甚至过万的百分比。猫叔重仓 中远海控 ，不由得有些羡慕。距离海控半年报还有一个多月，二季度已经结束，就来一版猫叔的中远海控2026年半年报的预增吧。 一、先上结论 猫叔预计： 中远海控 2026年第二季度单季归母净利润将在98.00亿元至110.00亿元之间，2026年H1累计归母净利润在156.77亿元至168.77亿元之间。 虽然比2025年上半年（175.36亿元）存在约3.7%至10.6%的小幅同比下滑，但这主要还是受制于2025年第一季度异常高基数（116.95亿元）的拖累，具体原因大家都懂，就不多说了。从环比与单季度同比的边际变化来看，2026年第二季度利润预计会实现逾60%的环比爆发。结合公司近期实施的大规模的回购注销， 中远海控 全年的利润中枢有望在下半年传统旺季（只要不出现旺季不旺的情况）的催化下向更高水平迈进。 二、2026年一季度财务与运营复盘 2026年一季报， 中远海控 在报告期内实现营业收入517.97亿元，同比下降10.63%；归属于上市公司股东的净利润为58.77亿元，同比下降49.75%；扣除非经常性损益后的归母净利润为58.60亿元，同比下降49.66%。此外，息税前利润（EBIT）为87.63亿元，同比减少78.15亿元，降幅达47.14%，EBIT利润率收缩至14.05%，较上年同期减少了12.37个百分点。 主要原因还是2026年第一季度，CCFI均值同比下降了16.32%。众所周知，一季度计入结算的多数长协订单是在2023年底至2024年初的运价低谷期所签订，这就让公司集装箱航运业务的国际航线单箱收入降至1110.36美元，同比大幅下降200.73美元。 然而，在利润表承压的同时， 中远海控 的资产负债表却展现出了不错的韧性。截至2026年3月末，公司资产负债率进一步压降至40.90%，创下自2008年以来的同期最低水平。公司总资产规模达到4860.23亿元，归属于上市公司股东的所有者权益稳步增长至2356.90亿元。公司期末货币资金余额高达1497.00亿元，不仅足以全额覆盖所有的有息负债，更使得公司处于实质上的“净现金”状态。这种充裕的账面流动性，为公司后续抵御地缘政治风险、执行巨额资本开支以及实施大规模股东回报计划构筑了深厚的资金基础。 三、全球贸易需求端在二季度的反季节爆发 这种爆发，猫叔说过多次，有几个方面的原因。 首先，“旺季前置”效应与抢出口潮。具体不再赘述。 其次，新兴市场的强劲动能。在传统的中美、中欧贸易主干线之外，东盟、非洲、中东以及拉美等新兴市场的贸易量保持了10%以上的同比增长，成为支撑全球集装箱吞吐量增长的核心引擎。泰国、越南至美国航线的业务量增幅甚至超过50%。 中远海控 多年来在“ 一带一路 ”沿线及区域内市场的深耕布局，今年二季度充分承接了这部分高增长红利。 第三，美加墨世界杯放大了需求。不多讲。 需求端的爆发，直接推高了二季度集运现货市场的运价。 中远海控 的营收结构，我们需要区分反映即期现货市场的SCFI与包含大量长协合约的CCFI之间的滞后与错位现象。 数据来源：上海航运交易所 从表格中可以清晰看出，二季度SCFI均值达到了约2336.67点，较一季度环比涨了近43.8%。在欧美航线爆舱频发的情况下，亚欧干线的即期运价在5月至6月间甚至突破了4000美元/TEU的高位。与此同时，CCFI均值在二季度的攀升相对温和，约在1343点至1350点区间，环比涨幅约19.5%。 中远海控 的欧美主干航线中，长协客户的占比通常在50%至60%左右。那么，CCFI的稳步上行为公司的基础营业收入托起了坚实的底盘，保障了基本盘不失；而剩余40%的现货舱位（对应SCFI指标），则完全享受了运价环比暴涨43%带来的巨大业绩弹性红利。这种“长协锁底、现货冲高”的收入结构，是引爆二季度利润非线性增长的核心机制。 WCI本周小涨，即期运价大概会在本月中下旬转弱。等待后续的旺季需求打开。 四、同业可比公司数据交叉验证 长荣海运、阳明海运、万海航运，在航线结构与现货敞口上与 中远海控 具有高度的相似性（均高度依赖欧美远洋主干航线）。其每月公布的营收数据是我们看集运的行业景气度的一个重要指标。对比分析这块，大家可以关注 快手 哥 @Terry_JW 他在对照三傻财报预估海控利润方面，是资深行家。 猫叔不作过多阐述，简略分析之。 数据来源：各公司月度营收公告 数据显示，三傻在4月、5月及6月的营收不仅全面实现同比大幅增长，且呈现出逐月加速扩张的环比动能。以万海航运为例，其6月合并营收达到161.66亿元新台币，不仅实现了连续第三个月的环比增长（+17.11%），更创下了自2024年9月以来的22个月新高；上半年累计营收达765.41亿元，实现同比正增长。阳明海运6月营收同样受惠于旺季需求及地缘政治带动的运价走揚，录得165.91亿元新台币，同比大增42.00%。 同业公司在二季度营收端的逐月跳涨，印证了二季度集运行业整体呈现“量价齐升”的繁荣景象，这为 中远海控 二季度收入规模的扩张提供了行业背书。 猫叔对海控的二季度有信心，还有一个重要原因。即在海外主要航运巨头在2026年一季度的业绩普遍承压甚至亏损下， 中远海控 在一季度58.77亿元归母净利润就极其不易，凸显了海控在成本管控、单箱盈利能力以及全球航线网络调配上的绝对领先优势。当二季度行业贝塔整体向上反转时，拥有更强阿尔法属性的中远海控，其利润弹性必然远超海外同行。 五、归母净利润量化预测模型 可以有三个预测模型。 模型一：基于CCFI均值的推演-保守 在航运业量化分析中，业界普遍采用CCFI综合运价指数与大型班轮公司季度净利润之间的线性回归模型来测算基准利润。根据历史数据的高度拟合，得出以下核心方程： y = 0.1632x－111.82 （x代表特定季度的CCFI均值，y代表该季度的预测归母净利润，单位为亿元人民币）。 2026年第二季度CCFI均值预计在1343点至1350点之间。我们将中枢值1350.28点代入公式： y = 0.1632·1350.28 － 111.82 = 220.36 － 111.82 = 108.54亿元。 考虑到现实商业环境中存在一定的利润摩擦。 一方面，占总运量60%左右的长协订单存在价格传导的时滞效应，一季度部分较低价格签署的旧合约在四五月份仍有长尾执行期。另一方面，绕行好望角导致燃油消耗量激增，尽管后续通过附加费转嫁，但在二季度初不可避免地侵蚀了部分毛利。 因此，考虑到上述“长协拖累+成本高企”的保守假设，适度下修理论值，则2026年二季度单季归母净利润落在 80.00亿元至95.00亿元 的保守区间，对应半年度累计净利润为138.77亿元至153.77亿元。 猫叔注： （1）公式中的0.1632，是回归系数/斜率， 这是通过历史数据拟合计算出的斜率，代表了 中远海控 利润对运价指数波动的边际敏感度。CCFI季度均值每上涨1个点，中远海控的单季度归母净利润理论上就会增加0.1632亿元（即1632万元人民币）。 （2）公式中的111.82，是截距， 这是线性回归模型在Y轴上的负截距。从商业运营的角度来看，它代表了航运企业在一个季度内所面临的折旧、港口摊销、基础人工等综合刚性固定成本与基础损益。我们可以通过它算出企业的“盈亏平衡点”，即当 y = 0 时，求得 x 约等于 685。即当CCFI均值跌至约685点附近时，公司集装箱航运主业理论上刚好达到盈亏平衡；只有当CCFI有效越过这一基准线，公司才能开始创造实质性利润。 模型二：站在机构的脑壳上推演-乐观 伴随二季度运价的飙升，国内多家头部券商对 中远海控 2026年的全年盈利预期进行了密集的大幅上调。其中， 天风证券 将2026年归母净利润预测大幅上修至298.73亿元（原预测为203亿元）； 华泰证券 同样将其2026年净利润预测上调至288.67亿元； 国金证券 等机构亦做出了相应的积极调整。再根据标普（S&P）及Moomoo数据终端汇总的分析师一致预期，中远海控2026年第二季度营业收入预计将达到550.93亿元人民币。这一数值较一季度的517.97亿元环比增长约6.3%。 航运业具备极其显著的经营杠杆属性。当运费收入越过盈亏平衡点，边际增加的收入将以极高的比例直接转化为营业利润。二季度SCFI环比大涨逾43%带来的纯现货增量收入，将大幅推升公司的利润率中枢。若假设二季度归母净利率由一季度的11.3%修复至18%-20%的常态高景气区间，则550.93亿元的收入对应的单季净利润约为99.16亿元至110.18亿元。 基于券商上修的全年近300亿利润目标及二季度收入预期，则二季度归母净利润约为 98.00亿元至110.00亿元 ，站在机构 的脑壳上，那就需需要乐观的预测区间。 模型三：基于SCFI与单箱边际利润的推演 这个是最为乐观的情景假设模型。 二季度的常规出货箱量天然高于一季度淡季，且长协运价（CCFI）稳健托底，确保了基础营收盘的绝对安全。 真正决定利润上限的是占四成的现货市场。 2026年Q2，SCFI均值较Q1大幅上涨超43%。在燃油附加费（BAF）机制完全覆盖新增燃油成本的前提下（详见后文分析），现货运价上涨带来的单箱毛利空间被彻底打开。若将同业可比公司（如万海、阳明等）动辄30%以上的营收月度环比增幅完全映射至 中远海控 的现货利润转化上，其二季度盈利理论上可触及115.00亿元至125.00亿元的极限高位。 将上述三种模型路径进行贝叶斯加权平滑处理： Path A ： Q2净利润约80亿-95亿元，H1累计约138.77亿-153.77亿元。 Path B ： Q2净利润约115亿-125亿元，H1累计约173.77亿-183.77亿元。 Path C： Q2净利润约98亿-110亿元，H1累计约156.77亿-168.77亿元。 鉴于 中远海控 一贯稳健审慎的会计确认准则，以及欧美长协履约的实际刚性， 猫叔认为Path C（中性均衡路径）是当前测算下的最准确路径。即中远海控2026年半年度归母净利润将落在 156.77亿元 至 168.77亿元人民币 区间 。 七、下半年展望与潜在风险提示 基于二季度形成的运力紧缺惯性，以及7月至10月全球海运传统旺季的叠加效应，如果下半年CCFI均值中枢能够稳步企稳于1700点的高位区间，结合长协运价的滞后兑现，下半年将贡献全年绝大部分的利润弹性。基于此中性偏乐观的推演， 中远海控 2026年全年归母净利润有望挑战472亿元人民币甚至更高水平，实现逾53%的全年同比暴增。 然而，实现这一全年宏伟目标面临以下三大核心风险变量的考验。 1、红海突发复航 红海终究有一天会全面复航，但是哪一天，不知道。航程的恢复将导致前期被延误和绕航吸纳的巨大运力在短期内集中向市场倾泻，全球有效集装箱舱位供给可能在一至两个月内暴增10%以上。届时，SCFI与CCFI指数将面临很大的下跌。 但全面复航也会加剧欧洲尤其北欧港口的拥堵，抵消一部分压力。 2、全球宏观经济硬着陆与库存周期反噬 二季度集运需求的繁荣，在很大程度上透支了三、四季度的出货潜力（即关税威胁下的旺季前置效应）。若下半年美国长期高息环境最终导致消费端实质性衰退，或者欧洲经济陷入停滞，前期囤积在海外仓库的商品将面临漫长的去库存周期。这种需求的反噬，会导致传统的三季度旺季呈现“旺季不旺”的窘境，货运量萎缩可能会引发船东间的价格战。 需求永远是集运的底座！ 3、环保脱碳法规（CII）与资本开支压力 从长期供给端来看，国际海事组织（IMO）推行的CII（碳强度指标）评级执行力度正在逐年加大，迫使大批老旧、高能耗船舶不得不降速航行或被强制淘汰出清。虽然短期内这种出清有利于压抑供给过剩，但中长期来看， 中远海控 等龙头企业必须承担巨额的绿色资本开支以完成船队的 新能源 迭代（如订购甲醇双燃料船等）。高昂的新船折旧与绿色燃料采购成本，将逐步推升行业的整体盈亏平衡点，对长远利润率构成隐性压制。 但绿色船舶和码头对长远来说，是好事。 总之—— 上半年是丰收的，面对下半年错综复杂的全球地缘与经济变量， 中远海控 已手握充裕的现金筹码与极高的盈利安全垫，蓄势迎接新一轮的价值发现之旅。 $中远海控(SH601919)$ $上证指数(SH000001)$ 猫叔注：纯属猫叔自个儿研究了玩，不构成任何投资建议！
