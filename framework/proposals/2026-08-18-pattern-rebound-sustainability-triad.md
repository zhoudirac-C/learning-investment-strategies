# 模式提名：反弹持续性三论证（对称性 / 获利盘 / 筹码结构）

## 模式内容

判断反弹"涨没涨完"时，依次过三个论证，禁止只用反弹天数超窗口直接判结束：

1. **对称性**：下跌段的时间/幅度 vs 反弹段的时间/幅度是否成比例。显著不成比例
   （跌一个月 vs 涨半个月）→ 涨没涨完的成分更大。
2. **获利盘结构**：上涨速度与累计获利盘决定兑现压力。涨速不快 + 获利盘不多 →
   兑现需求不强烈，小级别顶部结构不易兑现为实际下跌——「没有大涨，就没有大跌」。
3. **筹码结构**：前段下跌是否已清洗杠杆与不坚定筹码。清洗彻底 → 缺少新的下跌理由，
   唯一理由是「涨多了要兑现」（最弱的下跌理由）。

三论证同向支持时，回调按换手/内生性回调处理，不按趋势反转处理；
两论证以上转弱时，才把「反弹结束」摆上桌面。

## 触发与动作

- 触发：cycle_state.rebound_day 接近或超过 theoretical_window（盲判每日 cycle_state 环节）。
- 动作：禁止直接判「反弹结束/进入调整」；必须逐条过三论证并写明结论，再定 position；
  结论写入 operation.basis 或 cycle_state.note。

## 配套数据

下跌段起止与幅度（kline 已有）、反弹段涨速（kline 可算）、杠杆/筹码代理
（两融余额本地暂无数据源，过渡期用下跌段跌幅与恐慌标记近似，如实标注近似口径）。

## 证据

- 2026-08-18（震荡）：UP「一是对称性：7月整整跌了一个月，目前只反弹了半个月，幅度与时间都
  远不成比例，涨没涨完的成分更大。二是获利盘结构：这一波上涨速度不快、累积的获利盘不多，
  兑现需求就不强烈，所以此前多次出现的15分钟、30分钟顶部结构都没有兑现为实际下跌——没有大涨，
  就没有大跌。三是筹码结构：7月的下跌已经把杠杆与不坚定的筹码清洗得比较彻底，眼下缺少新的
  下跌理由，唯一说得通的理由只是涨多了要兑现。」当日盲判以「反弹第11天超窗口」为主要依据
