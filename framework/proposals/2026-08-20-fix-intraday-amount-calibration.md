# intraday_amount 预估模型校准 + 量能口径规则修订

## 分析

2026-08-19 判错根因 3：量能口径系统性失真，盘前/复盘两路同染。

- `src/investment_engine/intraday_amount.py:56` 的「预估全天」= 10:30 累计 ×
  (240/60)，即 ×4 朴素外推。A 股首小时成交占比通常 40-50%，该模型系统性高估
  近一倍；形态判定 `open_est > close_actual * 1.2 → 冲量滑落（全天缩量）`
  （同文件 60 行）因而几乎天天触发——已落盘 3 天（08-17/18/19）3/3 全中，
  预估/实际偏差约 2 倍（48501 vs 25110 亿）。
- 实际量能 08-17→18→19 为 23875 → 24008 → 25110 亿，逐日放大；08-19 环比
  +1103 亿（+4.6%）。UP 当日复盘：「今天不是缩量，是放量……抛压被充分释放，
  同时盘中有人在接」，并据此推翻「明日惯性下杀」的单一结论——该变量是
  「惯性下杀 vs 快速释放」分歧的核心判据。
- prompt 规则 9（`replay.py` 与 `premarket.py` 两处）强制「形态优先、禁止
  环比」，其注脚「对应 UP 的『看似放量实则全天缩量』」源自另一个 UP 案例，
  被硬编码为普适规则；叠加失真模型后，08-19 两路输出均被锁定为「全天缩量」，
  与事实和 UP 判定双重冲突。
- 影响面：`replay.py:315-319` 的确定性校验（规则10/12：冲量滑落→禁放量攻击/
  主升）同样以该字段为输入，模型失真会沿校验层继续放大。

## 处置建议

1. **预估模型校准**：用 TDX 60min 历史 K 线（同通道，扩 count 取近 20 交易日）
   计算各时点「累计成交/全日成交」占比中位数，预估全天 = 时点累计 ÷ 该时点
   占比中位数；输出附校准残差（近 20 日预估/实际偏差中位数），供阈值重定。
2. **形态判定并列环比口径**：`intraday_amount` 块新增字段（如
   `环比前日_pct`，今日实际 vs 前日实际）；「形态」字段名与取值不动
   （dataset 模块 docstring 明确 prompt 规则 9 引用该字段、一字不能改），
   新增字段与形态并列呈现。
3. **prompt 规则修订**（`replay.py`、`premarket.py` 两处同步）：
   - 规则 9 改为「量能性质定性须并列引用盘中形态与环比口径；两者冲突时
     （如形态=冲量滑落但环比放量）不得单一口径强制定性，须在 stage_reason
     写明冲突并给出双向解读（如：冲量滑落=追涨意愿不足；环比放量=下跌有
     承接）」；
   - 规则 10 的 ±30% 偏差阈值随校准后残差重定；
   - `replay.py:315-319` 校验器同步：冲量滑落禁放量类结论的硬校验，在校准
     上线前保持，上线后按新口径复核。
4. **验收**：回放 08-17~08-19 三天——校准后预估/实际偏差中位数应显著低于
   现状（现状约 100%）；08-19 的 stage_reason 不得再出现与「环比 +4.6%」
   矛盾的单方「全天缩量」定性。
