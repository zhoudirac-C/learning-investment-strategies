# 盲判 prompt 压缩 A/B 检验报告（v15 vs v16）

日期：2026-09-05　脚本：`scripts/blindtest_prompt_ab.py`　产物：`evals/blindtest/ab-prompt/{v15,v16}.jsonl`
设计文档：`docs/tasks/2026-09-05-blindtest-prompt-v16-ab.md`

## 背景与方法

v15 = 37 条经验补丁规则（9,742 字符）；v16 = 压缩版（5,632 字符，-42%），
37 条归并为推理链五步（定位置→定归因→定结构→定量价→定方向）+ 特殊盘面 + 输出纪律，
校验层 `validate_result` 不动。两臂同窗口（2026-08-17 ~ 08-28，10 个交易日）、
同数据包、同校验路径（run_with_validation），模型 deepseek-v4-flash、temperature=0。

## 结果

| 指标 | v15 | v16 | 判读 |
|---|---|---|---|
| 阶段一致率 | 50.0% (n=10) | 70.0% (n=10) | v16 +2 天，n 小，噪声内 |
| 方向5日超额命中率 | 66.7% (n=12) | 50.0% (n=10) | v16 -16.7pp ≈ 少中 2 个方向，噪声内但方向为负 |
| 标的5日超额命中率 | 45.8% (n=24) | 31.8% (n=22) | v16 -14pp ≈ 3 只标的，噪声内但方向为负 |
| 校验重试日数 | 4 / 10 | 8 / 10 | **v16 翻倍，真实成本回归** |

逐日阶段对照（truth 为沪深300 机械标签；震荡×8、调整×2）：

- v16 在 08-19/21/26 三天避免了 v15 的「调整」误判（结构优先约束生效），
  但在 08-18 反错（v15 对）；两臂同错 08-20/28。
- 重试翻倍的主因：v16 把 v15 逐块重复的「必须引用 X 字段」泛化为一条
  「在场数据必引用」，模型不再稳定产出校验关键词（08-19 触发规则13 机构未引用）。
  泛化条文 vs 关键词校验层的耦合风险已在设计中预见，实测兑现。

成本核算（按 LLM 台账 ptok 估算）：v15 = 14 次调用 × ~78K ≈ 1.09M tokens；
v16 = 18 次 × ~76K ≈ 1.37M。**压缩省 2.4% 输入，重试翻倍反使总成本 +26%**。

方向明细要点：v16 的失误集中在 08-27/28 的涨价榜追高（氟概念 -7.87%、
稀缺资源 -4.32%、先进封装 -4.33%）——形式上都带了催化引用与失效条件，
属「追高动机未被约束」而非「规则未执行」；v15 同期选了 pcb_ai_chain/黄金概念
等主线避险组合。样本太小，无法区分结构性回归还是运气。

## 结论

按预登记标准（方向/标的不显著差 且 重试率不明显升高 → 保留），**v16 未通过，
生产默认回退 v15**（`replay.SYSTEM_PROMPT = SYSTEM_PROMPT_V15`，一行指回）。

## 沉淀与下一步

1. 本次真正的结构性发现：**system prompt 只占总输入 ~5.5%**（9.7K / 176K 字符），
   压缩它的收益上限就是 2-3% token；体积大头在 user 数据包（stocks 42K /
   index 34K / chains 28K / lhb 23K / directions 16K）。下一步瘦身应打 user 包：
   sectors 数组只留候选方向相关项、index 60 根砍 20 根+预算均线、chains 只进
   当日活跃链、lhb 席位名截断。
2. v16 保留为 `SYSTEM_PROMPT_V16` 迭代基线。修复点：引用义务恢复逐块点名
   （校验关键词必须在条文中出现），再扩窗复验。
3. 窗口 10 天不足以裁决方向命中率（1 个方向 ≈ 8-10pp）：下次 A/B 用 ≥20 个
   交易日（方向样本 ≥40），并先看重试率是否拉回 v15 水平。
4. A/B 基建已固化：`run_replay(system_prompt=, prompt_version=, use_validation=)`
   + `scripts/blindtest_prompt_ab.py`，后续 prompt 改版可直接复用。
