## 模式一：外盘冲击开盘定价论（NEW）

**模式内容**：隔夜外盘大跌的默认先验是"只定价开盘"——开盘后市场回到 A 股自身量能
与接力节奏。判「调整/外力扰动」前须过三步：①首次定价检查——冲击发生在 A 股收盘后
则今日为首次定价，只反映在开盘；②冲击量级源头校准——查源头宽基跌幅（标普/纳指）
而非行业指数/个股（MRVL -10% ≠ 系统性冲击），宽基仅微跌则杀伤限情绪端与映射板块；
③承接判据前置——判调整必须附加"承接失败"的盘面证据预期（开盘放量破位+无差别下跌
放大），而非外盘跌幅本身。

**触发与动作**：

- 触发：隔夜外盘大跌（费半 ≤-2% 或纳指 ≤-1.5%）且模型即将判「调整」。
- 动作：stage 基准先按震荡/低开高走构造；stage_reason 逐条回答上述三步。
- 与规则24 关系：24 管"必须引用外部链条"，本条管"引用之后如何定权重"，互补。

**证伪**：开盘 30min 放量破位且下跌无差别放大（08-20 形态），升级调整。

**证据**：

- 08-31 UP 早盘：「如果是后者（贴现率失控），跌的不会只有0.3%」「只反映在开盘那一下
  的定价里，开盘之后市场会回到自身的量能与接力节奏上」；08-28 UP 早盘标题即框架：
  「外盘只定价开盘，接不住才是问题」；08-30 周复盘：「低开不可怕，接不住才可怕」。
- 同日盲判把费半-3.47%/MRVL-10.28% 线性外推为全天调整（基准情形A），实际低开高走
  +0.86%——本周唯一 miss。盲判情形B（冲击钝化）覆盖了正确路径但先验权重错配。

## 模式二：外力/内生归因盘面鉴别清单（扩展规则24）

**模式内容**：定 nature 时查三证据——①当日有无新消息冲击；②跌停家数（≈0 或极少数）；
③连板梯队完整度。三无+缩量 → 内生性回调（"需要的是时间与位置"，不主动降仓）；
有冲击+跌停扩散 → 外力扰动（降仓）。

**触发与动作**：

- 触发：每次写 nature。
- 动作：stage_reason 附三证据读数；判「外力扰动」但三无 → 违规重试（可机械化：
  pack 有 daban 跌停数 + limit_pool 梯队完整度）。

**证伪**：鉴别为内生但次日亏钱效应扩散（跌停飙升/梯队批量断板）→ 改判。

**证据**：

- 09-01 UP 复盘：「没有出现消息面冲击，全市场无一跌停，连板梯队完整……内生性回调，
  而非外力扰动」「内生性回调需要的是时间与位置，外力扰动才需要主动降低仓位预期」。
- 盲判 09-01/09-02 连续两天 nature=外力扰动——stage 命中但归因错误（实盘 09-01 无一
  跌停、约 3300 只上涨，属内部过热降温被记到隔夜外盘账上）。

## 模式三：防御轮动穷尽信号（扩展规则21）

**模式内容**：防御阶段跟踪轮动序列（医药→消费→有色→种业→军工…），当补涨到最后一个
防御分支且领头高股息（银行/煤炭）触压力位或率先转跌 → 判防御阶段末端、变盘临近，
directions 禁止新增防御方向。

**触发与动作**：

- 触发：directions 候选含防御方向，或防御分支已轮动 ≥3 个。
- 动作：stage_reason 列出防御轮动序列状态；末端信号成立时防御方向只可标退潮/回避。
- 与规则21 关系：21 管"昨日防御方向今日禁顺延"，本条管"整个防御阶段的末端识别"。

**数据依赖**：需维护近 5 日防御分支轮动序列状态（当前 pack 无此字段，见数据缺口）。

**证伪**：领头高股息创新高且防御继续扩散 → 末端判断作废。

**证据**：

- 09-02 UP 复盘：「轮到最后一个补涨、同时领头的高股息碰到压力位，这本身就是变盘信号
  ——防御的钟摆已经摆到了尽头」；盘中「煤炭两天高开低走，高股息避险没必要」。
- 同日盲判新增绿色电力（高股息属性）+ 维持 broker_finance——UP 看到末端时盲判刚上车。

## 模式四：调整终局剧本推演（NEW）

**模式内容**：判调整且已持续多日时，scenarios 除 T+1 二分支（延续/反抽）外，必须含
终局路径：跌到位时间窗 + 位置锚（波段前低/区间底）+ 确认信号链（大票日线底背离/
高标开板冰点/量能放大）+ 确认后的做多窗口与仓位阶梯。

**触发与动作**：

- 触发：连续 ≥2 日判调整。
- 动作：scenarios 增加"终局情形"；watch_next 含终局确认信号（个股级底背离、冰点
  完成事件等）。

**证伪**：位置锚放量击穿或窗口到期信号未现 → 剧本作废重估。

**证据**：

- UP 剧本时间线：09-03 盘中「KC 跌到1600 是好事，调整不充分该来的总会来」（起点）→
  09-04 11:22「下周一再往下杀一波，打出底背离，开启一轮反弹」→ 14:27「后面两周是
  本月唯一做多窗口……仓位6-8成」→ 20:38「剧本这不就成了嘛，下周一跌到位，有行情做了」。
- 盲判同期 scenarios 全程"不抄底/逢高减仓"，无终局推演——若下周反弹启动，盲判没有
  任何仓位预案。既有 rebound_day_count 只管反弹计数兑现，不管调整终局。

## 模式五：地量地价·做空动能衰竭识别（与规则18互补的正向信号）

**模式内容**：成交创阶段新低 + 指数未深跌 + 下探回升 = 做空动能衰竭，定性"底部区间
确认"。两分离：确认底部 ≠ 确认走强，走强裁判只有量能放大。禁止仅凭跌破短期均线判
「内生瓦解」。

**触发与动作**：

- 触发：成交额创 20 日新低且指数涨跌 <|0.5%|。
- 动作：nature 禁判「内生瓦解」；stage_reason 须区分"区间确认"与"走强确认"。
- 与规则18 关系：18 是判瓦解前的反向否决清单（三信号），本条是调整末段的正向企稳
  区间识别。

**证伪**：次日放量破位下跌 → 区间判断失效（09-04 恰好证伪"走强"但未证伪"区间"）。

**证据**：

- 09-03 UP 复盘：「典型的地量地价修复K线……缩量而不深跌、下探而能回升」「"确认底部"
  与"确认走强"是两件事——后者必须见到量能放大」，并正确预言次日情绪冰点。
- 同日盲判收盘轨对近平地量日宣判「内生瓦解/破位确认」——机械标签命中（r20 口径）
  但性质刻画过度，且次日情景全防御。

   三连败，无延时重试/降级通道，双轨互证形同虚设。建议 429 时排队延时重试（>60s）
