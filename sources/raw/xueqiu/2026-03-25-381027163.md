# 2026-03-25 重剑堂

$Meta(META)$ 有意思。。。 / 转 Meta Platforms (META.O)自2012年IPO以来首次向高管提供股票期权，此举旨在留住并补偿高管，因为该公司将继续大力投资以在激烈的AI竞争中脱颖而出。 Meta 公司周二提交的文件显示，如果未来几年其股价达到预期目标，公司将推出新的期权。Meta公司发言人表示，这些期权将提供给直接负责公司最重要和最具战略意义投资的高管和其他高级领导。如果Meta股价达到每股1116.08美元（较当前水平上涨88%），第一批期权将解锁。Meta股票周二在纽约收于每股592.92美元。后续几期期权的目标价位更为激进，最高可达3,727.12美元，是当前股价的六倍多。所有期权将于2030年8月前发放给高管，无论Meta的股价表现如何；如果五年后仍未被行使，则期权将失效。
