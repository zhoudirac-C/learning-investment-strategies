# 2026-05-17 黑色面包

简单来说，所有人都知道疯狂不可持续，大家都需要说服自己什么时候离开这个赌局，而特朗普的访华和结束看起来很像一个时间点，于是演变成了周五的疯狂过山车。 也没啥好分析的，一切逻辑弱于资金的流动，能玩的玩，不能玩的走，等待下一次的契机。 前几天预言了功率半导体的爆发，因为看了下手上的项目，功率半导体相关的一季度表现都有所回暖，而且去和他们沟通得到的反馈也不错。 功率半导体这块，特别是第三代半导体的氮化镓和碳化硅，其实更多是一个困境反转的逻辑。众所周知，2024-2025年整整两年的时间三代半从天之骄子被砸进土堆里，碳化硅器件价格从硅基器件的3-4倍价格一路被砸到基本持平。但是客观来说，三代半器件比硅基还是强不少的，以前太贵所以渗透率不高，现在真愿意和硅基平价抢市场，那能力还是碾压。 但是你说有多赚钱，其实也很难。首先早期的结构就是下游不赚钱，衬底小赚，外延大赚，晶圆厂量不够不赚钱，模组厂被大客户车厂按着打更赚不到钱。后来衬底疯狂大扩产，外延被下游传导压力，就没人赚钱了。现在的情况，外延往下至少基本见底了，不会更坏了，会恢复到多好不好说，但以前买的炉子能开起来了，这块看天域和瀚天的财报基本就能看出来。 衬底这块现在多个进先进封装散热的故事，但是这个事是这样，市面上的这两年没开起来的长晶炉估计有个小几十个亿的capex，碳化硅衬底厂技术好和坏，影响厂商的产量成本，但是就算再菜的厂商，也是能做出合格片来的——对于一些厂商来说，他不需要赚钱，不需要良率，只要能出片，能卖到大厂，就有机会在市场讲故事，比如业内那几个知名笑话。所以每一代碳化硅的衬底出来之后，价格都会掉的飞快，头部大厂只能再忍一忍，想办法把技术做好，成本进一步往下压，再熬一熬把一些太离谱的熬死，才能出头。 所以这个行业是真的恶心。 氮化镓会稍微好一些，一方面他上车规大功率没优势，所以22-23年那一波的疯狂扩产氮化镓的格局没有太恶心，另一方面他进AI数据中心1200V超高压平台的前景和性能要比碳化硅器件好。另外一方面就是MicroLED进CPO，这事我原本不是很信，因为十几年前我就在玩这个了，不太能信任他的良率和稳定性，但是最近确实听了大产业方的一些演讲，感觉至少他在功耗方面的优势还是吸引了不少人入局的，乐观来看未来CPO短距的方案里MicroLED能吃掉30%-40%份额，这块也是氮化镓未来一块强预期的市场。 先看看吧，CPO方案离完全定型还有距离。 设备这块，目前卖方很激进，锚定先进和存储的扩产，给了一些很变态的数字，反正抱着头部肯定比小卡拉米靠谱。 然后先进封装这一侧，Cerebras周四上了，且不管阿美怎么炒，我对他们的方案倒是非常感兴趣。C家的方案已经说明，现在对于高集成的AI系统来说，光刻的Reticle Size已经成了最大瓶颈。 ASML 针对先进封装刚新出了一款XT260，但是也只是相对提升了25%，完全不够用。拼接终归是权宜之计，所以我看好能够做到2微米线宽级别的超大尺寸光刻方案。 别的，次新现在是最大泡沫。DPW上市前最后一轮大概五六十亿，深圳还没上市的比他强的不少于五家；SJ最大的问题在于和H家的关系，H家极其擅长背刺合作伙伴（其实已经在干了），别的没研究过，也不谈了。反正去玩的随时做好被砸个大的的心理准备就行。 H家入股InP光芯片公司，H家对InP的研究比国内很多厂商要深，他们要高度拥抱InP路线，反正最近看了两三家做材料的，今年的预期和订单都非常非常高，至于能不能达到先期炒作的水平，那就看下游厂家有多疯狂了。 还有不少准备蠢蠢欲动搞题材的，植物人、量子、医药、世界杯，这些就各凭本事了。
