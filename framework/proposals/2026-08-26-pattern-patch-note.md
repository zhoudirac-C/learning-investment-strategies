# 资金流方向需二次验证

## 分析

稀缺资源方向判断失真的核心错因：1) 数据缺：判断称“铜/金价上行周期方向明确”，但当日缺席global_macro数据（宏观三条件未检验），无法验证商品价格周期位置，仅凭国内3日净流入45.9亿、5日贵金属+9.82%及铜陵有色+4.98%等数据推断趋势，导致在基准下跌时资源股beta放大（-2.85% vs -0.93%）；2) 步骤缺：选择方向时未执行资金流质量与持续性校验——当日lhb机构净卖出家数27>14且机构高位股净卖出（中际联合-1.94亿），首板39家较昨-17、涨停家数萎缩，存量博弈下3日净流入可能为游资短线轮动而非趋势资金，但AI仍将“维持”方向赋予稀缺资源，缺少对板块内封板质量及资金性质的二次确认步骤。

## 处置建议

增加步骤：依据板块资金净流入选方向时，必须结合当日lhb机构净买卖家数、封板率、晋级率判断资金性质；若机构净卖出占优或宽度萎缩，则资金流信号降权，只列为观察而非操作方向。
