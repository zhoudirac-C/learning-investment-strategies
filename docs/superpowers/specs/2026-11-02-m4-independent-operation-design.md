# M4：独立运行与 Qing-Agent 每日市场验证 — 设计文档

日期：2026-11-02  
状态：方向已由用户确认，待实施  
替代关系：接替 `2026-08-09-m4-graduation-check-design.md` 作为 M4 本体方向；旧判分器继续作为可靠性统计工具保留

## 一、背景与决定

旧 M4 以“连续 8 周达标后毕业”为启动前提，并把 AI 与青枫浦上Q每日观点的差异对照作为影子期的重要信息。现在青枫浦上Q（`school=qing`）不再提供新增动态，未来样本不会继续产生，旧流程即使等待也无法恢复完整输入。

**范围限定**：本文所称“退出”只指青枫浦上Q的新增实时输入和每日差异对照退出，不是退出全部专家。代码已确认 Qing-Agent 当前包含 `qing`、`gator` 和 `watchlist` 注册项；鳄鱼派的采集、规则、patterns、冲突卡与双学派输出契约继续保留。

因此 M4 改为：**青枫浦上Q停止新增输入后，Qing-Agent 以既有多专家架构转入独立运行建设；每天冻结 Qing-Agent 的专家视角与最终合成判断，并用后续市场结果持续验证可靠性。**

这里必须区分两个结论：

- **运行决定**：M4 不再等待旧式 `graduated`，独立运行现在开始。
- **可靠性结论**：不因启动 M4 而自动获得。2026-10-25 的 `not_yet` 保留为历史基线，今后每天用新增市场样本重新验证。

## 二、目标与非目标

### 目标

1. 拆除 Qing-Agent 对 青枫浦上Q 实时观点、青枫浦上Q 情绪和 青枫浦上Q 优先裁决的依赖。
2. 将每日可靠性验证对象明确为 Qing-Agent，而不是只验证 shadow 轻管线。
3. 建立“判断冻结 → 到期市场结算 → 错因归因 → 方法修订”的每日闭环。
4. 用持续更新的样本量和滚动指标表达可靠性，不用一次“毕业”替代长期验证。

### 非目标

- 不把启动 M4 写成“已经证明可靠”。
- 不用历史 青枫浦上Q 文本补齐或伪造当前的 青枫浦上Q 对照。
- 不接真实交易接口，不自动下单，不输出无条件买卖指令。
- 不因单日涨跌或单笔盈亏修改方法；过程合规与结果表现分别评价。

## 三、多专家架构与退出边界

- 当前注册表 `config/schools.yaml` 包含 `qing`（青枫浦上Q及缠论原著）、`gator`（鳄鱼派）和 `watchlist`（观察池）。M4 只处理 qing 的实时增量退出，不删除其他注册项。
- 当前实现不是每个专家对应一个独立 LangGraph 节点，而是在共享图中按 `school` 注入 patterns、gator 确定性规则快照和学派冲突卡，再由同一分析、合成与输出链路生成结果。M4 保留这一架构，不虚构独立专家节点。
- 青枫浦上Q历史 raw、claims、wiki 和来源中立 pattern 保留为教材、历史案例与规则来源；其历史命中率只作基准率参考，不代表当前仍有信息渠道。
- 每日运行不再要求 qing 的 `up_sentiment`、`direction_signals` 或任何“青枫浦上Q今日观点”字段；历史字段不得伪装成当前信号。
- 鳄鱼派的现有采集、gator patterns、`gator_rules_snapshot`、冲突辩论卡及双学派输出契约保持有效。M4 不得借“拆锚定”移除或削弱 gator。
- “青枫浦上Q优先”不得参与冲突裁决；既有双学派平权、分歧双列和 standing 长期并列规则不变。市场结算用于可靠性统计，不自动裁决学派冲突。
- shadow 记录与旧 qing-vs-shadow 报告转为历史对照和方法诊断资产，不再决定 M4 是否允许启动。
- 若未来偶然获得青枫浦上Q内容，只能作为独立留档样本，不恢复为每日运行的必要输入。

## 四、验证对象与留痕契约

### 4.1 验证对象

每日验证 Qing-Agent 实际对用户产生的**最终合成判断**，同时保留可追溯的专家视角，包括：

- 市场阶段与判断依据；
- 各专家的 `school`、观点、证据和规则快照；
- 方向判断及其失效条件；
- 标的判断及其相对基准；
- 操作框架中的触发条件、仓位约束和失效条件；
- 数据缺口、能力边界与生成时使用的规则版本。

最终结果结算是主口径；只有专家视角明确给出方向/标的和期限时才单独计分，否则只做过程与证据质量检查。不得把 gator 规则输出归到 qing，也不得用最终合成结果倒算某个专家的事后命中率。

shadow 可继续提供对照样本，但不能替代 Qing-Agent 本身的留痕与结算。

### 4.2 分轨冻结

盘前、盘中、收盘输出分轨保存，不得互相覆盖。每条记录至少包含：

- `date`、`track`、`generated_at`、`data_as_of`；
- 结构化最终判断、原始输出及 `expert_views[]`；
- 每个专家视角的 `school`、证据引用和适用期限；
- 判断适用日期或期限；
- 使用的数据版本、规则版本和 prompt 版本；
- `pending_maturity / scored / error / missing` 状态；
- 到期后的 `stage_hit`、`due_scores` 与归因引用。

收盘后的当日解释只能接受过程合规和当日事实核对；只有明确指向未来且带期限的部分，才能进入预测评分。不得把收盘后知道的结果改写成事前命中。

### 4.3 不可改原则

已冻结记录只允许追加结算、校验和归因，不允许覆盖原判断。确有数据错误需要重跑时，保留原记录并将新记录标为新版本；旧归因和提案同步失效，沿用既有 supersede/retract 纪律。

## 五、市场验证口径

| 维度 | 口径 | 用途 |
|---|---|---|
| 留痕完整性 | 时间戳、数据时点、期限、触发与失效条件是否齐全 | 每日运行门禁；缺项不得进入预测评分 |
| 市场阶段 | 与既有机械真值标签的一致性 | 参考项，不单独作为预测力证据 |
| 方向表现 | 方向给出后 5 个交易日相对沪深300的超额表现 | 主要结果指标 |
| 标的表现 | 标的给出后 5 个交易日相对沪深300的超额表现 | 主要结果指标；样本不足须显式标注 |
| 假设证伪 | 方向/假设到期 miss 比例，与适用的历史基准对照 | 可靠性参考，不阻塞独立运行 |
| 过程与执行 | 当时信息下是否按规则、触发和失效条件执行 | 防止用结果倒推决策质量 |

原“连续 8 周达标”改为滚动 4 周/8 周观察窗：报告同时给出命中率、样本数、环境分布和缺失天数。旧阈值可作为异常告警线，但不再是 M4 启动或继续运行的前置条件。

可靠性由持续证据表达，不再使用一次性的“已毕业/未毕业”概括全部状态。样本不足时输出 `insufficient_data`，不能用少量命中写成稳定可靠。

## 六、每日闭环

1. **判断冻结**：Qing-Agent 在盘前、盘中或收盘分别生成输出，记录生成时间、数据时点、判断期限、专家视角和最终合成结果。
2. **事实核对**：检查引用标的、行情、日期、学派归属和失效条件；事实错误、归属错误与观点错误分开记录。
3. **市场结算**：收盘后回填当日可结算项；方向与标的在 T+5 到期后结算相对沪深300表现。
4. **错因归因**：按数据缺、步骤缺、概念误用、信息差分类；信息差指当前公开数据通道的边界，不再特指“没有青枫浦上Q新观点”。
5. **方法修订**：重复问题进入提案制，经人审后修改规则、术语、数据通道或 prompt；不得因单笔结果临时改规则，也不得以结算结果自动消除多专家分歧。
6. **可靠性报告**：每日记录完整性，每周汇总滚动 4 周/8 周指标、分环境样本、缺失和未到期数量；最终合成结果与可独立结算的专家视角分开报告。

## 七、异常与缺失处理

- **LLM 429/超时**：当日标记 `error`，记录重试与失败原因；后续按原任务补跑，不能让正式盘后失败覆盖并抹掉已存在的盘前记录。
- **原输入快照缺失**：标记 `missing`，不得用事后数据重建一份冒充当时的判断。
- **市场数据缺失**：对应指标标为 `insufficient_data`，不进入命中率分母。
- **未到期**：保持 `pending_maturity`，不得提前判对或判错。
- **连续缺报**：可靠性报告必须置顶告警；独立运行继续，但不得声称该窗口验证完整。

## 八、M4 实施与验收

M4 工程实施至少拆成以下四项，不以本设计文档落地冒充功能完成：

1. Qing-Agent prompt 与冲突裁决拆除青枫浦上Q实时锚定，保留 gator 与双学派平权契约；
2. Qing-Agent 盘前/盘中/收盘结构化分轨留痕，覆盖专家视角与最终合成结果；
3. 复用既有市场结算能力，接入 Qing-Agent 记录并保留版本历史；
4. 生成每日完整性报告和每周滚动可靠性报告。

完成验收必须同时满足：

- 在无青枫浦上Q当日输入、但保留 gator 现有输入的情况下跑通一次真实 Qing-Agent 日流程；
- 同一最终判断可回链到冻结原文、各专家视角、数据时点、规则版本和后续市场结算；
- 盘前预测与收盘复盘不会混算，qing/gator 的证据归属不会混淆；
- 429、缺失、未到期均有独立状态，报告不会把缺失误计为命中；
- prompt 中不再存在青枫浦上Q实时情绪、方向优先级或优先裁决；gator 规则快照、patterns 和双学派冲突输出未被移除；
- 模式召回按学派执行 validation 门禁：qing 未验证的来源中立规则只能进入明确标注的实验对照，不得作为通用生产方法注入 Qing-Agent 生产 prompt；gator 现有专家视角保留，并标注草案/未独立验证，不伪填命中率；
- 相关回归测试通过，且输出仍遵守触发条件、失效条件、数据时间戳和非自动交易红线。

可靠性验证在 M4 验收后持续进行；M5 的季度校准在 M4 上线并积累足够样本后启动，不再等待旧式毕业。
