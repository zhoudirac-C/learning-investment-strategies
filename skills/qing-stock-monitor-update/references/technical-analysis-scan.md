# 全项目标的扫描 + 技术分析

## 工具

`scripts/scan_all_stocks.py` — 扫描项目中所有产业板块提到的核心标的，轮询获取实时行情+历史K线，结合 strategy_pack 中的介入区间 + 技术分析，判断今天是否适合买入。

## 用法

```bash
cd ~/learning-investment-strategies
venv/bin/python3 skills/qing-stock-monitor-update/scripts/scan_all_stocks.py
```

## 技术分析维度

### 1. 均线系统
- MA5、MA10、MA20 计算
- 多头排列（价>MA5>MA10>MA20）→ +2分
- 短期多头（价>MA5>MA10）→ +1分
- 空头排列 → -2分
- 短期空头 → -1分
- 均线缠绕 → 0分

### 2. 支撑位/压力位
- 取近20日高点和低点
- 从近期高点回撤 >20% → +1分（调整充分）
- 从近期高点回撤 <5% → -1分（仍在高位）

### 3. 回撤幅度
- (近期高点 - 现价) / 近期高点 × 100%
- 用于判断调整是否充分

### 4. 量价关系
- 今日量能 vs 20日均量
- 放量 >1.5x → +1分
- 缩量 <0.6x → -1分

### 5. K线形态
- **长下影线**：下影线占比>50%且实体<30% → +2分，止跌信号
- **阳线反包**：今日阳线包住昨日阴线 → +1分，强势信号
- **十字星**：实体<10% → +1分，变盘信号
- **大阳线**：实体>5% → +1分
- **大阴线**：实体>5% → -1分
- **连续阴线后收阳**：反弹信号 → +1分

### 6. 综合评分
- strong_buy: >= +3分
- buy: >= +1分
- neutral: 0分
- sell: <= -1分
- strong_sell: <= -3分

## 买入判断逻辑

```
可买入 = 当前价在介入区间内 AND 技术信号积极（评分>=1）
等回踩 = 未达区间 OR 技术信号偏空
不介入 = 博主明确不介入（entry_zone: 只观察不介入）
无区间 = 未配置具体介入区间
```

## 关键修复记录

### 腾讯K线字段顺序（重要！）

腾讯财经历史K线API返回的字段顺序：
```
k[0]=日期, k[1]=开盘, k[2]=收盘, k[3]=最高, k[4]=最低, k[5]=成交量
```

**常见错误**：把 k[3] 当成 low、k[4] 当成 high，导致 low > high，所有技术分析结果错误。

**正确写法**：
```python
result.append({
    "date": k[0],
    "open": float(k[1]),
    "close": float(k[2]),
    "high": float(k[3]),    # 腾讯格式: k[3]=最高
    "low": float(k[4]),     # 腾讯格式: k[4]=最低
    "volume": float(k[5]),
})
```

## 使用场景

1. **每日开盘前**：扫描所有标的，找出今天可买入的机会
2. **用户问"还有什么可买"**：用脚本扫描全项目标的，而非仅看已有 entry_points
3. **Claims 一致性校验**：更新 strategy_pack 前，扫描确认没有与博主纪律矛盾的配置
4. **盘中动态更新**：博主发布新观点后，快速判断哪些标的受影响

## 注意事项

- 脚本只判断"是否适合买入"，不判断"是否适合卖出"
- 对于"只观察不介入"的标的，脚本会明确标注为🚫不介入
- 对于无具体介入区间的标的，脚本会标注为❓无区间，提醒需要补充配置
- 技术分析仅供参考，最终决策需结合博主观点和大盘环境
