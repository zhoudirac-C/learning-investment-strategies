# 明确'放量'定义需结合绝对量分位

## 分析

AI将创业板指跌破9-17底部日收盘3298.31作为方向转折铁证，但未按审计项要求处理多指数分歧：cycle_state中已承认科创50/上证指数反弹天数远超其小窗口（2天），却以'参考意义有限'为由舍弃，仅锚定对空头最有利的创业板指，属于单点锚定（概念误用）。同时，成交额环比+2.99%但60日分位仅10%，绝对量处于低位，AI将'环比微增'表述为'放量下跌'，用错放量概念；跌停56家/炸板105家被触发极端情绪阈值，但事后真值为'调整'，说明该阈值在调整市中不构成方向转折证据。流程上缺少'破位有效性验证'和'多指数周期区间标注'步骤，导致将情绪冰点直接升格为恐慌/转折。

## 处置建议

将'放量下跌'判定条件补充为：成交额环比增幅>5%且60日分位>50%，或绝对量处于近期高位；仅环比正增长且60日分位10%时不得使用'放量'表述。
