# 房地产城市更新

> 来源：博主 2026-05-30 宏观视频《分化时代下的房地产、消费和港股》
> 核心判断：房地产增量时代已经结束，存量更新才是未来方向

---

## 一、房地产K型分化现状

### 1.1 供需结构

- 上海有 1400 万套住房，其中 400 万套空置，200 万套为纯老年人居住
- 未来潜在抛压达 **600 万套**
- 全国各城市都类似，但**核心地段优质房产仍能保持上涨**

### 1.2 价格走势

- 全球规律：房价见顶回落后，核心城市跌幅通常在 **30%-40%** 后企稳
- 目前中国核心城市房价已经出现**企稳迹象**
- 今年房地产投资增速仍为负，但跌幅收窄到不到 **7%**
- 较此前15%以上的下滑明显收敛，**整体下坠减速正在筑底**

### 1.3 库存与政策定位

- 当前全国房地产库存**高于2015年去库存起点**
- 全面见底仍需时间，全年销售预计仍为负增长
- 主要城市租售比低于按揭资金成本 **3.1%**，投资性需求难以起来
- 央行将 DR 利率维持在 **1.3%**，用便宜资金托底
- **政策定位是托底而非刺激大涨**，住房不炒的方向不变

## 二、城市更新：从增量到存量的范式转变

### 2.1 政策核心要求

国务院城市更新规划将房地产增长逻辑从增量征地盖房转向**存量更新改造**：

- **核心要求**：不得新增地方政府隐性债务
- 未来增量住宅只有**改善型住房**
- 从过去的刚需满足转向建设**安全舒适绿色智慧的好房子**

### 2.2 危旧房与城中村改造

- 本质是**升级版去库存**，通过拆迁安置带动购房
- **不会走棚改大水漫灌的老路**
- 强调资金平衡不新增隐性债务

### 2.3 政策松绑细节

- 允许地方专项债投入
- 支持符合条件的项目发行 **REITs**
- 存量土地转型给了**不超过5年的过渡期**，不用马上补地价
- 大幅降低了老厂区转型文创、商业的启动成本

## 三、投资方向与受益板块

### 3.1 直接受益方向

| 方向 | 逻辑 |
|------|------|
| **建材家居** | 改善型住房需求带动 |
| **家装** | 存量房翻新需求 |
| **智能家居** | 安全舒适绿色智慧的好房子 |
| **适老化改造** | 老龄化社会刚需 |
| **存量物业企业** | 老厂区转型、REITs发行 |

### 3.2 与过去房地产刺激的本质区别

| 维度 | 过去（棚改大水漫灌） | 现在（城市更新） |
|------|---------------------|-----------------|
| 增长逻辑 | 增量征地盖房 | 存量更新改造 |
| 资金来源 | 央行PSL+地方债大水漫灌 | 专项债+REITs，不新增隐性债务 |
| 住房结构 | 刚需为主 | 改善型住房为主 |
| 受益主体 | 开发商 | 建材、家装、智能家居、物业 |
| 政策定位 | 刺激大涨 | 托底防风险 |
