# Watchlist 介入价位计算工作流

## 触发场景

新建 watchlist 或更新观察池后，为 P1/P2 标的计算具体介入价格区间。

## 数据源

```bash
# 批量获取实时行情（腾讯财经 API）
curl -s 'https://qt.gtimg.cn/q=STOCK_CODES' | iconv -f gbk -t utf-8 | awk -F'~' '{print $2, $4, $5, ($4-$5)/$5*100}'
# 输出：名称 最新价 昨收 涨跌幅%
```

## 介入区间计算规则

| 标的当日涨幅 | 策略 | 介入区间计算 |
|-------------|------|-------------|
| 涨停(≥9.5%) | **等分歧回踩，严格不追板** | 昨收 ~ (昨收+最新)/2（补缺口区间） |
| 大涨(5-9.5%) | 等分歧 | 最新×0.95 ~ 最新×0.98（回调5%左右） |
| 小涨(0-5%) | 等分时均线附近 | 最新×0.96 ~ 最新×0.98 |
| 收跌/大跌 | 等缩量止跌企稳 | 价格附近±2%，确认不再创新低 |

## UP 方法论引用

- **涨停票**：「绝不在加速段追板」「等分歧回踩补缺口不破」
- **大涨票**：「等分歧后缩量回踩」「回踩5日线/10日线且缩量企稳后再放量」
- **收跌票**：「等缩量止跌企稳，确认不再创新低后轻仓，不在下跌途中接飞刀」

## 止损规则

- 止损位 = 介入区间下限再往下 3-5%
- P1 标的硬止损：跌破且30分钟不能收回 → 强制止损
- 持仓不超过 1.5 成（弱市纪律）

## 输出格式（写入 watchlist.yaml）

```yaml
entry_zone:
  description: 一句话描述策略
  current_ref: 'YYYY-MM-DD 最新=X.XX(涨跌幅%)'
  price_range: '下限 ~ 上限'
  confirm_signal: 确认信号描述
  hard_stop: 跌破X且30分钟不能收回
  position_ratio: 仓位比例
```

## 禁止行为

- ❌ 给涨停票设"追板"介入区间
- ❌ 给收跌票设"抄底"价格
- ❌ 给 P3 观察标的设主动买入区间
- ❌ 介入区间超过 UP 方法论的合理回调范围
- ❌ 忽略全A指数确认条件（防守日不建仓）
