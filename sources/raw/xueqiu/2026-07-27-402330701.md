# 2026-07-27 舟宿夜江

$拼多多(PDD)$ TEMU最近新发布了针对“商品描述不一致”的运营规则提醒，主要是针对： 1. 尺寸夸大标注尺寸与实物不符（例如：XXXL特大加厚，标注34*28英寸、100片装，实际尺寸远小于描述）。 2. 对比图夸张：使用夸张对比图，误导消费者（例如宣传图：比床还大；实物图：实际很小）。 3. 功能不全/虚假宣传宣传功能与实际不符，无法使用（例如：驱蚊手环无驱蚊效果；扩香仪无扩散香味；香蕉蜡烛无香味）。 4. 商品品质差：太松、漏水、易坏、易破损（例如：漏水、易破损）。 5. 实物与SKU图不一致：SKU图与实物差异大，图货不符（精修图 vs 实拍图差异大）。 这五大商品与实物描述不一致的高违规风险。 对应的平台治理流程即处罚SOP也很清洗：夸大宣传虚假描述 → 消费者投诉差评退款 → 店铺TCR（差评率/纠纷率）升高 → 平台处罚（下站处罚、流量调控）。 处罚的方式分两种，一种是直接下架，固定7天、15天或30天，到期恢复；另一种是流量调控，这个更灵活，系统动态调整，什么时候恢复看后面的表现。 表面上看是处罚，本质上是把流量从"差商品"手里拿回来，重新分给"好商品"。不需要人工审核团队去一家一家查，靠数据和算法自动完成。 这套机制的意义在于： 1.对消费者来说，最直接的就是买到的东西跟看到的基本一致。不是说平台能保证每一单都完美，而是那些货不对板的卖家会被系统"识别"出来，慢慢就得不到流量了，自然淘汰。消费者在平台上搜索的时候，排在前面的东西至少描述是相对靠谱的，踩坑的概率降低了很多。消费者不是靠"信任 拼多多 "，而是靠"知道平台会管"才敢继续下单。 2.对合规卖家来说，这套机制反而是保护。过去那种劣币驱逐良币的情况，譬如合规卖家老老实实用实拍图、标真实尺寸，成本比别人高；别人用夸张图、虚标参数，点击率更高，流量全跑他那去了。现在平台用TCR把虚标的筛选出来限流，真实描述的卖家反而能获得更多曝光。不是平台"照顾"合规卖家，而是系统把不合规的卖家筛掉了。当然，平台也给了上架前的8项自检清单，包括： · 图片真实：使用实拍图，避免夸大效果，并与实物一致 · 尺寸准确：尺寸标注准确，并与实物一致 · 数量正确：数量描述与实际一致 · 功能真实：产品功能真实可验证 · 材质一致：材质描述与实物一致 · SKU一致：SKU注册图与实物保持一致 · 参数准确：参数/信息真实，不误导 · 避免夸大宣传：不使用绝对化、夸大词汇 所以，对于合规卖家来说描述真实 → 消费者体验更好 → 卖家TCR更低 → 差评更少 → 流量稳定 → 曝光提升 → 持续盈利 → GMV增长。 3.对平台来说，这是一笔很划算的账。如果都靠人工巡检、抽检（仓库抽检机制也还在）、审核团队，成本极高。Temu这套玩法，相当于把品控成本转嫁给算法，让消费者用评价和售后投票，系统自动执行。这套机制跑通了，平台在品控上的投入产出比会非常高。而且TEMU在海外面对的是更严格的消费者保护环境，这套靠数据驱动的治理体系，某种程度上是它能快速铺量的底气所在。 所以综合来看是，这套规则短期看对一些不合规的卖家是压力，长期看对平台生态是好事。劣质卖家被边缘化，优质卖家拿到更多流量，消费者体验提升、复购增加，平台的GMV和货币化率才能持续往上走。 这更像是在建一套"规则过滤器"。把不靠谱的过滤掉，靠谱的自然就留下了。 最终的目的还是让卖家合规经营，提升商品体验，赢得更多流量与消费者信任！
