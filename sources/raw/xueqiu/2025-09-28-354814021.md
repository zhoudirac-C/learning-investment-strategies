# 2025-09-28 黑色面包

1. 关于H的灵衢和A的磐久，技术参数这边做解析的人很多，公众号随便一搜都是，还有一堆似是而非的供应商。我们换个讲法，在亦步亦趋跟着北美抄了两年作业之后，我们终于发现按这种搞法只能被按着打，达子给好卡我们就发展快一点，不给卡我们就发展慢一点，脖子被人狠狠抓在手里。怎么办？现在我们的战略基本定下来了，扬长避短，搞超节点。我们的长处是什么？是完备网络，是世界顶尖的通信水平，是世界顶尖的能源电力，我们要用互联设计，用高能耗，去弥补制程端在片上互联的落后。只要这块的差距能缩小，在其上做应用层的创新，这点我们可以把北美按在地上打。 2. A和B在AI领域的激进姿态在股价上得到了回报，外资对于CN的AI叙事兴趣正在增强，其他的，Z家T家会不会随之加大投入，很有可能。类似OpenAI和 英伟达 的合作模式，只要OpenAI明年有IPO的迹象，这条路线就会有人抄，滚雪球。后面会有人找这种叙事的。 3. GKJ这块，我们离可用近了，但从可用到量产，到成本能和 台积电 竞争，还有很长的路要走。这条链上的企业，还是在情绪端，很难体现到业绩上。这也是为什么要拆分，因为拆出来的大家觉得比较low的那部分，才能做到能上市的业绩，去反哺烧钱的部分。可用的部分的进展，我们会比大家想象的快，量产部分的进展，会比大家想象的慢。 4. 然而机进展慢不代表产能进展慢，毕竟也有很多人说过，我们是屯了一大批机子的，在不计成本的情况下，极限能逼近到T5的水平。而且，后面我们不一定看到的全是S7，还有H7，甚至还有别的。理论上，这部分扩产的设备订单是会在下半年有所体现的，但能不能覆盖成熟制程建厂需求的下滑，不好说，这个观点之前也讲过了，看上去营收利润没变化甚至下滑，实际里面的结构已经变了。 5. 假借壳这个已经被关注了，搞这一套的现在已经被迫做出12个月无注入计划的承诺，实际上甚至可能是三年，最后还是要走真借壳实际IPO的道路，奉劝一些企业还是少走歪路。 6. 到产业端，产能的放宽非常明显，一些上半年拿不到产能的公司下半年已经拿得到了，产能放宽，直接受益是先进封装端，建了的线嗷嗷待哺。新技术这块，目前业内对于板级封装的确定性意见比较一致，不管是北美还是我们，芯片越做越大都是必然，板级对于成本的优化吸引了很多厂商，特别还有 京东方 这种大金主。玻璃基的产业化稳步推进中，微裂纹、通孔深宽比、表面镀膜均匀性等问题还待解决，业内对于进展速度没有去年那么乐观，但工作都是脚踏实地在做。 时间有限，这周聊到这。
