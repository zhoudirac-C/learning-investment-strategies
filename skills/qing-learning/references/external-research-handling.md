# 外部研究报告处理规则

> 最后更新：2026-06-07

## 问题

UP 在复盘/视频中经常引用投行报告（高盛、摩根士丹利等），但这些报告：
1. 不是 UP 原创内容
2. UP 通常会给出时效判断（如"延迟一个月""七八月份再看"）
3. 不能和 UP 的每日复盘/观点混在一起

## 处理规则

### 归档位置

不放入 `sources/raw/财经/`（那是 UP 内容专用）。单独建立：

```
sources/research/
├── index.md                          ← 索引 + 使用规则
├── {机构}_{日期}_{标题}.md            ← 要点摘录
└── pdfs/
    └── {机构}_{标题}_{日期}.pdf        ← 原始 PDF
```

### 不进入 qing-learning

- ❌ 不提取 claims
- ❌ 不更新 wiki/framework
- ❌ 不加 `ingest_status` frontmatter

### UP 延迟规则

如果 UP 明确说了"后面再看""延迟一个月"等：
- 在报告要点文件中标注 `⚠️ UP 提示：延迟至 YYYY-MM 后再看`
- 在 index.md 中标注预计再看时间
- 在关联的 UP raw 文档中添加引用链接

### 引用关系

在 UP 的 raw 文档中标注：
```markdown
> ⚠️ UP 提示：延迟至少一个月再看。
> 详见：[sources/research/...md](../../sources/research/...md)
```

同时在每日复盘 wiki 中新增「外部研究」章节链接。

## 案例

2026-06-07 周复盘中 UP 提到两份高盛报告（6月3日），明确说"时间节点差不多是七八月份""往后移就行"。
→ 归档到 `sources/research/`，标注延迟，不提取 claims。
