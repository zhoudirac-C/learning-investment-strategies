## 背驰族 expect 降级处理与理由

- 处理（未改 schema）：背驰用例的 expect 只断言结构结论——BC-001 断言双中枢、

## MACD 面积设计计算（代理口径）

代理量：段内逐根 `Σ|Δclose|`（主）与 `Σ(high-low)`（辅）。设计时先定转折点价位
使段跌幅成比例，再由生成器（/tmp/gen_cases_7c.py，一次性脚本未入仓）复核：

- BC-001：A 段(21→26) Σ|Δc| = 6.88；C 段(41→46) = 2.88（约 42%）。价格新低而
  面积显著缩小 → 标准背驰。B 中枢横盘对应"黄白线回拉 0 轴附近"（定性，注释说明）。
- BC-002 level2：A2(1→16) = 4.28+2.28+4.28 = 10.84；C2(31→46) = 2.88+1.08+2.08
  = 6.04 < A2 → 大级别背驰。level1：a1(31→36) = 2.88，c1(41→46) = 2.08 < a1
  → 次级别背驰。两级背驰段端点同为 idx 46，区间套收敛。
- 注意：Σ|Δc| 是设计代理，非 MACD(12,26,9) 柱面积；两实现对 bars 算出的真实
  MACD 面积比较可能与代理值有出入，属预期偏差源，对表时按 FAIL→偏差清单处理。
