# 2024-11-02 大杨能源笔记

根据 山东黄金 在2024年10月28日《关于为香港全资子公司融资提供担保的公告》（以下简称为“本公告”）上披露的山东黄金香港公司的营业收入和净利润，推算贝拉德罗金矿2024年1~9月的销量、库存、净利润等数据如下： 一、贝拉德罗金矿2024年1~9月销量和库存的推算 1、说明 （1）根据2024年10月28日 山东黄金 的《关于为控股子公司卡蒂诺纳穆蒂尼矿业有限公司融资提供担保的公告》，卡蒂诺纳穆蒂尼公司的2023年和2024年1~9月的营业收入和净利润均为0。 （2） 山东黄金 香港公司的合并数据应该包含按50%权益计算的贝拉德罗金矿数据、卡蒂诺纳穆蒂尼公司的数据以及香港公司自身数据等三个部分。 （3）香港公司自身，猜测目前无收入，但承担贝拉德罗金矿和卡帝诺项目收购款的银行利息，还会发生香港办公室租赁费、香港员工工资等费用。 （4）可以推测，香港公司发布的合并营业收入数据，应为按50%权益计算的贝拉德罗金矿的营业收入；合并净利润数据，应为按50%权益计算的贝拉德罗金矿净利润和香港公司自身净利润的合计数。 2、验证2023年营业收入数据 为了证明本文上的思路是否可行，首先验证2023年营业收入数据。 （1）“本公告”上的香港公司2023年营业收入为25.83亿元。 （2）根据 山东黄金 在以前的定增资料上披露的MAS公司的2023年营业收入为71,294.75万美元（100%金额）。 折算为按50%权益计算的贝拉德罗金矿人民币营业收入 = 71,294.75 * 2023年平均汇率7.0467 * 50% / 10000 = 25.12亿元 （3）上面的两个数据大致相同，误差率为2.75%（(25.83-25.12)/25.83=2.75%）。 小结：本公告上的香港公司2023年营业收入，就是按50%权益计算的贝拉德罗金矿的2023年营业收入。 3、贝拉德罗金矿的2024年1~9月的矿产金收入、销量、库存的推算 （1）美元营业收入的推算 本公告上的香港公司2024年1~9月的营业收入为29.9590亿元。 折算为2024年1~9月美元营业收入 = 29.9590 / 1~9月平均汇率7.1092 = 4.21亿美元 注）1~9月平均汇率7.1092，采用的是 赤峰黄金 在2024年3季报上披露的数据。 （2）矿产金销量的推算 1~9月矿产金销量 = 4.21 * 100000000 / 1~9月伦敦金均价2293美元 * 31.1035 / 1000000 = 5.72吨 误差范围 = 5.72 * 2.75% = 0.16吨 即，考虑误差范围的1~9月矿产金销量为，5.56~5.88吨。 注）因找不到2024年1~9月伦敦金均价数据，上面的2293美元为我个人测算数（（上半年均价2,202.91 * 2 + 3季度均价2,474）/3 = 2,293）。该数据不一定非常准确，但与实际均价应该相差不太大。 （3）矿产金产量的推算 1~9月矿产金产量推算数 = 全年7吨 / 12 * 9 = 5.25吨 （4）2024年1~9月销售的2023年底库存量的推算 1~9月销售的2023年底库存量 = 5.72 – 5.25 = 0.47吨 二、贝拉德罗金矿2024年1~9月净利润的推算 1、2023年香港公司自身（不含贝拉德罗金矿和卡帝诺）净利润的推算 山东黄金 在2023年报上披露的香港公司净利润为-3.67亿元（合并数），而贝拉德罗金矿按100%权益计算的净利润为2539.68万美元。 2023年香港公司自身（不含贝拉德罗金矿和卡帝诺）净利润 = -3.67 - 2539.68 * 50% * 2023年平均汇率7.0467 / 10000 = -4.56亿元 小结：香港公司自身（不含贝拉德罗金矿和卡帝诺）在2023年承担了贝拉德罗金矿、卡帝诺项目收购款的银行利息和办公室租赁费、员工工资等费用后，发生了约-4.56亿元的亏损。 2、2024年香港公司自身利润变动因素 山东黄金 为香港公司提供的担保余额为，2023年12月31日83.49亿元，2024年8月28日90.73亿元，2024年10月28日92.27亿元。 可以推测，2024年9月30日的担保余额比上年末增加8亿元左右。 小结： 山东黄金 为香港公司提供的担保余额应该与美元借款余额相同，且香港公司为贝拉德罗金矿和卡帝诺项目的收购而借入的银行贷款余额大概率不会变动，上面美元借款余额的增量可能是卡帝诺项目为开发建设而借入的银行贷款。因此暂时假设香港公司2024年自身利润水平与上年基本相同。 3、贝拉德罗金矿2024年1~9月净利润的推算 贝拉德罗金矿2024年1~9月净利润（按50%权益）= 香港公司1~9月合并净利润-0.46亿元 – 香港公司2023年自身净利润-4.56亿元 / 12个月 * 9个月 = 2.96亿元 结论： 1、以前的文章上我推算过，贝拉德罗金矿按50%权益计算的2023年底库存为0.92吨（系2023年产量和2023年销量的差额）。 2024年1~9月，预计销售了上面0.92吨当中的0.47吨（考虑误差时可能为0.31~0.63吨）。 2、香港公司的2024年1~6月营业收入为16.03亿元，2024年1~9月营业收入为29.96亿元，3季度收入大幅增长。且 山东黄金 在半年报业绩交流会上表示过，为了减少汇兑损失，贝拉德罗金矿留了一定的库存。因此，可以理解为大概率在3季度出售了2023年底留的部分库存。 3、贝拉德罗金矿2024年1~9月净利润（按50%权益）大约为3亿元，较2023年全年0.89亿元（2539.68万美元*50%*年均汇率7.0467/10000=0.89亿元）和2022年全年1.95亿元（5789.64*50%*年均汇率6.7261/10000=1.95亿元）大幅增长。 $山东黄金(SH600547)$ $山东黄金(01787)$ $山金国际(SZ000975)$ #黄金# 说明：以上都是对个人思考过程的记录，难免有差错和遗漏，不作为投资建议。
