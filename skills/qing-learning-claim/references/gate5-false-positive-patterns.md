# Gate 5 False Positive Patterns

## 按 raw 类型预判

### 早盘类
早盘类文本频繁出现以下通用词汇被误认为公司名：
- `综合影响有限` — "有限"后缀
- `涨的依然是科技` / `主战场仍在科技` / `其余非科技` / `金依然可在科技` / `统性流向非科技` — "科技"后缀
- `材料方向从电子` / `考虑让三星电子` — "电子"后缀
- `后者高度有限` — "有限"后缀
- `的再一次走强` / `再次走强才是信号` — 通用描述

### 复盘专栏类
常见：`高位科技` `低位科技` `硬科技` `科技内部` 等科技相关短语
已积累模式：参见 `gate_validate_claims.py` 的 `NON_COMPANY` 集合

### 盘中分析类（2026-06-12 新增）
大段产业逻辑分析文本中，`科技` `硬科技` 在上下文语境中被误匹配为公司名。

**2026-06-12 10:47 盘中动态（科技内部跷跷板+商业航天IPO）：**
```
- 模块构成了科技      ← "构成了科技内部的跷跷板"
- 味着不必因科技      ← "意味着不必因科技板块"
- 本没有离开科技      ← "根本没有离开科技"
- 资金在科技          ← "资金在科技股内部游走"
- 换而非离开科技      ← "换座位而非离开科技"
- 这是对科技          ← "这是对科技股仓位管理的指导"
- 出了三类硬科技      ← "给出了三类硬科技的仓位框架"
- 资金没离开科技      ← "资金没离开科技"
- 对冲比传统科技      ← "科技内部对冲比传统科技对防御"
- 作为硬科技          ← "作为硬科技内部分类的标尺"
- 光模块等硬科技      ← "光模块等硬科技形成明显反差" (5字+科技)
- 而应关注科技        ← "而应关注科技内部的资金切换" (4字+科技)
- 非资金流出科技      ← "非资金流出科技板块" (5字+科技)
- 不应用传统科技      ← "不应用传统科技vs防御" (5字+科技)
- 大于其他硬科技      ← "大于其他硬科技板块" (5字+科技)
- 然资金不出科技      ← "然资金不出科技板块" (5字+科技)
- 环境下不如科技      ← "环境下不如科技内部对冲" (5字+科技)
```

**模式**：当 interpretation/statement 中的"科技"前有2-5个汉字时，均被误匹配为公司名。特别是长短语（4-5字+科技）如"不应用传统科技""光模块等硬科技"。

**模式**：当 raw 是**大段分析性文字**（非短观点摘要），`Xx科技/Xx硬科技` 中的`科技`几乎全是通用词而非公司名。应在第一轮 Gate 2 失败时批量补入 NON_COMPANY。

**2026-06-12 09:48 早盘动态（上帝为什么不救你）：**
此帖无公司名匹配（纯寓言+行为偏差提醒，已标记不提取 claim），无 Gate 5 影响。

### 早盘类（通用）
常见：调整幅度有限、空间有限、机会但弹性有限
`有限` 后缀极易命中 — 需注意实际公司名（如 赛腾股份、银轮股份）不在此列

## 维护方法

1. 遇到新的假阳性时，确认它不是真公司名
2. 在 `gate_validate_claims.py` 的 `NON_COMPANY` 集合追加
3. 删除 `gate2_result.json` 缓存后重跑 `continue`
4. 在此文件记录新的模式，按 raw 类型分组
