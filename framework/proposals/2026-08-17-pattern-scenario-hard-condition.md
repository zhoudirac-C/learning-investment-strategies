# 模式提名：情景条件的硬阈值只挂结构信号（量能只写方向）

## 模式内容

1. **硬条件只挂盘中可观察的结构信号**：情景树（scenarios）的 condition 里，允许设阈值的变量
   限于——锚定方向是否承接（放量站稳 / 冲高回落）、跌停家数是否收敛（个位数与否）、
   标杆高位股是否松动、涨停家数与封板率的回升/退潮方向。
2. **量能只写方向性要求，不设绝对成交额阈值**："温和放大""继续萎缩""守住前日量级"即可。
   绝对阈值在临界日必然失效——结论全对但条件不触发，执行者面对"既非A亦非B"的盘面无所适从。
3. **指数点位阈值仅保留在结构位**：前高、中枢上下沿等结构位可保留点位；凭空推算的整数关口
   不设。
4. **每个情景须声明单一承重墙变量（key）**：key 是那个"塌了则其余推演全部顺延"的变量，
   不是指标平铺（与 2026-08-15 以点带面提案同源：先定点，再排面）。

## 触发与动作

- 触发：构造盘前/复盘情景树时（shadow premarket、qing 复盘 tomorrow_scenarios 均适用）。
- 动作：写 condition 时自检——含绝对成交额/非结构位点位的，改写为"结构信号 + 方向性量能"；
  随后用一句话回答"本情景的承重墙变量是什么"，写不进 key 字段的情景不成立。

## 证据

- 2026-08-17（震荡，反弹第 12 天）：盲判情形A挂"成交额(亿)回升至25000亿以上+创业板指站稳3600点"，
  实际成交 23874 亿（差阈值 4.5%）、创业板指 +3.14%（收 3740 远超 3600）——结论全对、
  量能条件未触发；UP 同日三情景全部为结构条件（CPO 承接 / 跌停收敛至个位数 / 标杆股状态），
  收盘逐条命中（跌停 10→1、中石科技 20cm 二板）。
- 2026-08-14（震荡）：盲判盘前情形A"成交额(亿)维持25000亿以上"、情形B"萎缩至23000亿以下"——
  同类绝对阈值在相邻交易日重复出现，确认是系统性写法而非单日偶发。
- 2026-08-17 反例对照（UP 侧）："两市成交能否守住上周五的量级"——量能以相对口径进入观察清单，
  不作硬阈值。
