# 缠论原始资料

这里保存缠论（缠中说禅）技术分析体系的原始学习资料，如《教你炒股票108课》等。

## 定位

- **非 UP 原创内容**：外部经典技术分析方法论，与 `sources/raw/财经/`（UP 原始文字稿）区分开
- **会进入学习流程**：与 `sources/research/`（机构研报，不提取）不同，本目录资料用于学习消化，提炼后的方法论归入：
  - `methodology/technical-analysis.md`
  - `knowledge/wiki/投资方法论/技术分析.md`
  - 生成的 claims 标注 `claim_type: technical-knowledge`、`timeframe: permanent`（操作工具层，不用于判断市场方向）

## 规则

- 原始资料保持原文，不随意改写
- 提炼引用时需标注来源文件路径
