# 2026-08-12 吕执着

我妈今天买菜回来说上周五花肉11块一斤，这周涨到13了。我又去看了眼猪粮比价和厄尔尼诺那张图： 8月4号更新的厄尔尼诺指数已经和24年1月（图中黄箭头）那持平了，当时后面猪肉确实走了一波反弹行情。 今年不知道波动会不会更剧烈一些。 找了下机构的观点，也分为保守派和激进派： 主流机构（保守派）的逻辑是：母猪去化确实在发生 → 但PSY（每头母猪每年提供的断奶仔猪数）提升会对冲相当一部分减量 → 冻品库存压制反弹空间 → 只会温和回升，不会暴涨 。 冻品库存的压制是悬在头上的一把剑。 激进派 高盛 的核心逻辑是：当前深度亏损不可持续 → 产能加速出清 → 6-9个月后供给断崖式收缩 → 供需格局由过剩转为短缺 → 猪价暴力反弹。 但确实保守派提到的PSY对冲产能去化效果、以及考虑到冻品库存，更贴合实际。 除非是产能去化超预期，叠加更多的气候、疫病因素才能达到 高盛 “产生短缺”的情况。 这也解释了为什么畜牧尽管在低位、散户资金不多，非散户资金7月有抄底，但 $养殖ETF鹏华(SZ159867)$ 却没有更进一步拉升的原因—— 这个局，目前看还不是太好做 ，故事确定性还不够强，不好吸引人。 如果后面基本面有变化，这局顺利开启， 那么ETF预计能回到年初2月的水平。 从宏大叙事来说，不管啥东西，只要中国人掌握了扩产能的方法，价格就是会被压制在低位…… 上到工业皇冠上的各种明珠，下到居民生活日用。 作为日常消费，享受廉价商品是挺舒服的。 但对于投资，就有点疼痛了—— 售价只往下波动，没有行情啊 ~ “我杀了我”这种剧本，之前的 新能源 、光伏都发生过，但愿未来半导体、存储、CPO不要重蹈覆辙。 1、光伏看反弹，反转还是难。 说起光伏，上周一，ETF轮动组合把券商换到光伏后，价差已经有9%了（光伏+8%，证券-1%） 这一轮光伏ETF反弹还是要借助太空光伏、逆变器和储能。 前者是题材，也受益于光伏反内卷超预期，海外懂王还主动提价“协助”反内卷； 后两者，逆变器和电力设备都是受益于北美AI缺电，产能出海搞建设；储能则是估值见底。 所以光伏ETF整体虽然很难重返巅峰，但能有个结构行情、较大幅度的反弹也很不错了。 2、机器人的热度和基本面。 宇树科技 IPO发行价150.8元/股，发行后市值约610亿，DeepSeek出资1.41亿参与战略配售。 不过 $机器人ETF鹏华(SZ159278)$ 昨天大涨后，今天没有受益热度反弹。 原因还是盘前笔记提到的那个乘联会数据——7月国内市场的零售数量拖了后腿，甚至盖过了出口的增量： 机器人板块，说破了天，大部分公司主营业务还是汽车零部件，所以日内有点情绪回落是正常的。 3、实控人低位定增被套的价值。 今天 $乐惠国际(SH603076)$ 开盘后快速涨停，微盘指数组合7月27号把它调进成分股的原因也很简单。 乐惠国际 的实控人大股东，自掏腰包3.5亿参与定增，定增价20.7。而当时价格才18块附近。 看过电影的股民都知道一个朴素的道理，被困不要紧， 一定要和主角在一起——才有被救的可能 。 所以18块哪怕是主动买套，也是相对安全的。当然组合运气不错当天就开始了反弹。 这个策略大家感兴趣的，可以定期翻市场公告跟踪找机会。 【重点】麻烦看清是【低位定增】、【实控人参与】，那些高位定增、外部投资机构被套的不要沾边。 配角、炮灰被套，导演很多时候没心思单独开辟剧情去营救…… 它家的啤酒品牌，鲜啤三十公里，德式小麦鲜啤口感是最好的，新上的这个750ML囤货放冰箱最方便，尺寸刚好站着放。 之前囤的1L装，全都要躺着~ 雪花也推了不稀释、不杀菌、不过滤的鲜啤，1L*2=136。 相比起来，乐惠6罐750ML是109，性价比还是高得多，7日鲜啤原浆1L*2是80，麦芽浓度和活酵母数还更高， 产品力是非常强的。 但老实说，他们家的 产品营销能力 还有很大的提升空间…… 所以这一轮主要还是从定增价安全边际角度出发；至于未来能否靠销量推动第二增长曲线，得走一步看一步。 当然也是风险提示，这类策略专注低吸，在高确定性位置找机会还行； 非要追涨后，再预判能否有更高估值空间确实不是强项 。 收工~
