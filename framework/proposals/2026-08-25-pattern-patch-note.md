# 在阶段判断流程中加入价格结构确认步骤

## 分析

AI判定为“震荡/缩量企稳”，但真值为“调整”。其依据是“成交额18318.4亿、环比-8.7%”、“上涨4234家vs下跌1245家”、“涨停65家(昨46家)、跌停仅2家、封板率74.7%”等宽度修复数据，并将此解释为“缩量宽度修复”和“缩量企稳”。但该解释将“缩量企稳”概念用错场景：缩量企稳通常要求指数止跌或收阳、量能萎缩至地量级别，而当日“创业板指-1.00%”、“沪深300-0.24%”仍收跌，成交额仅环比-8.7%未达地量状态，更应定性为“缩量反抽/调整中继”。同时，推理步骤缺少“价格结构确认”环节：invalidation中只设定了“跌停≥80家或上涨家数≤1000”或“外部链条升级”作为下修至调整的条件，未将“创业板指/科创50跌破关键支撑”等价格确认信号纳入判据，导致价格实际走弱时仍维持震荡判断。

## 处置建议

增加强制校验：当基于涨跌家数、涨停数量等宽度指标判定“震荡/企稳”前，必须先检查上证指数、创业板指、科创50是否收盘跌破5日均线或近期波段低点；若任一核心指数跌破，则无论宽度如何，优先判定为“调整”。
