# 2025-05-16 大杨能源笔记

矿产金毛利率是代表金矿股盈利能力的重要指标，比起因产品类型不同而不能横向比较的矿产金单位销售成本，更能全面、客观地反映一家金矿股的盈利能力。 矿产金毛利率 =（矿产金营业收入-矿产金营业成本）/矿产金营业收入 一、14家金矿股的2022~2024年度矿产金毛利率统计表 二、对9家金矿股矿产金毛利率情况的说明 1、 山东黄金 （1） 山东黄金 的矿产金毛利率，2024年为47.05%，2023年为48.91%，2024年同比下降1.86个百分点。 （2） 山东黄金 的矿产金销售单价，2024年为553.17元/g，2023年为450.89元/g，2024年同比增长22.68%。 山东黄金 的矿产金单位销售成本，2024年为292.90元/g，2023年为230.38元/g，2024年同比增长27.14%。 （3） 山东黄金 的矿产金销售单价与其他同行一样大幅增长，但矿产金单位销售成本的增长率超过其他同行，最终造成矿产金毛利率的小幅下降。 注）以上 山东黄金 数据均系含 山金国际 的合并数据。 2、 山金国际 （1） 山金国际 的矿产金毛利率，2024年为73.54%，2023年为60.76%，2024年同比上升12.78个百分点。 （2） 山金国际 的矿产金销售单价，2024年为549.60元/g，2023年为449.49元/g，2024年同比增长22.27%。 山金国际 的矿产金单位销售成本，2024年为145.40元/g，2023年为176.42元/g，2024年同比下降17.58%。 （3）因此， 山金国际 的矿产金毛利率大幅上升12.78个百分点是，矿产金销售单价增长22.27%的同时矿产金单位销售成本下降17.58%的结果。 3、 紫金矿业 （1） 紫金矿业 的矿产金毛利率，2024年为55.70%，2023年为45.07%，2024年同比上升10.63个百分点。 （2） 紫金矿业 的金锭：矿产金销售单价，2024年为533.39元/g，2023年为433.09元/g，2024年同比增长23.16%；矿产金单位销售成本，2024年为287.16元/g，2023年为286.09元/g，2024年同比增长0.37%。 紫金矿业 的金精矿：矿产金销售单价，2024年为504.30元/g，2023年为378.60元/g，2024年同比增长33.20%；矿产金单位销售成本，2024年为158.15元/g，2023年为158.83元/g，2024年同比下降0.43%。 （3） 紫金矿业 的金锭和金精矿的单位销售成本同比变动不大，但金价上涨带来较大的销售单价增长幅度，最终结果是矿产金的毛利率大幅上升。 4、 赤峰黄金 （1） 赤峰黄金 的矿产金毛利率，2024年为46.96%，2023年为35.69%，2024年同比上升11.27个百分点。 （2） 赤峰黄金 的矿产金销售单价，2024年为524.28元/g，2023年为435.73元/g，2024年同比增长20.32%。 赤峰黄金 的矿产金单位销售成本，2024年为278.08元/g，2023年为280.20元/g，2024年同比下降0.76%。 （3） 赤峰黄金 的单位销售成本同比变动不大，但矿产金销售单价大幅增长，最终结果是矿产金毛利率大幅上升。 5、西部黄金 （1）西部黄金的矿产金毛利率，2024年为53.73%，2023年为-16.84%，2024年同比上升70.57个百分点。 （2）西部黄金的矿产金销售单价，2024年为532.05元/g，2023年为448.02元/g，2024年同比增长18.76%。 西部黄金的矿产金单位销售成本，2024年为246.15元/g，2023年为523.45元/g，2024年同比下降52.98%。 （3）西部黄金在2023年因对采矿权出让收益做费用化处理和子公司停产原因单位销售成本非常高，但到2024年单位销售成本已恢复正常，同时矿产金销售单价大幅增长，最终结果是矿产金毛利率大幅上升。 6、 中润资源 （1） 中润资源 的矿产金毛利率，2024年为25.90%，2023年为-8.99%，2024年同比上升34.89个百分点。 （2） 中润资源 的矿产金销售单价，2024年为723.11元/g，2023年为457.55元/g，2024年同比增长58.04%。 中润资源 的矿产金单位销售成本，2024年为535.84元/g，2023年为498.68元/g，在20234年单位销售成本已经很高的基础上2024年又同比增长7.45%。 （3） 中润资源 因瓦图科拉金矿目前采矿设备和设施老化严重而近年来生产能力长期徘徊在低位的原因，毛利率低于其他同行。但今年进行的技改完成后，毛利率预计可以提升。 注）上面的2024年矿产金销售单价723.11元/g系我个人根据年报数据计算的结果（矿产金销售收入328,347,469.05元/（矿产金销量14,598.86盎司*31.1035）=723.11），这个数据挺异常，暂不清楚是什么原因造成的，我个人猜测是年报数据有误。 7、 四川黄金 （1） 四川黄金 的矿产金毛利率，2024年为56.55%，2023年为51.19%，2024年同比上升5.36个百分点。 （2） 四川黄金 因为未披露金精矿销量的金属量，无法计算矿产金销售单价和矿产金单位销售成本，也无从分析矿产金毛利率小幅上升的具体原因。 8、 中国黄金国际 （1） 中国黄金国际 的矿产金毛利率，2024年为35.28%，2023年为27.63%，2024年同比上升7.65个百分点。 （2） 中国黄金国际 的矿产金销售单价，2024年为2,659美元/盎司，2023年为1,962美元/盎司，2024年同比增长35.52%。 中国黄金国际 的矿产金单位销售成本，2024年为1,721美元/盎司，2023年为1,420美元/盎司，2024年同比增长21.20%。 （3） 中国黄金国际 的矿产金销售单价和单位销售成本均同比大幅增长，因前者增长幅度大于后者，最终结果是矿产金毛利率小幅上升。 9、万国国际矿业 （1）万国国际矿业的矿产金毛利率，2024年为55.64%，2023年为50.69%，2024年同比上升4.95个百分点。 （2）万国国际矿业虽然披露金岭礦的金锭销量，但未披露金精矿销量的金属量，因此无法计算矿产金销售单价和矿产金单位销售成本，也无从分析矿产金毛利率上升的具体原因。 三、总结 1、2024年报上的矿产金毛利率披露情况
