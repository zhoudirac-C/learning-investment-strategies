# Total Blackout: Sector Proxy via Sina hq.sinajs.cn

当 **Sina Market_Center/Change_Page 排行 API** 与 **EastMoney push2** 同时不可用时
（返回 `"Invalid service name"` + `Empty reply from server`），唯一可用的实时行情入口是 **Sina hq.sinajs.cn 单品报价**。

## 核心思路

无法获取全市场涨跌排行 → 通过手动选择每个板块的代表性股票（3-10只），用单个 `curl` 批量查询 Sina 基础行情，计算板块平均涨跌幅来替代。

## 命令模板

```bash
# 单个 curl 批量拉取 30-40 只股票，覆盖 4-5 个板块
curl -s 'https://hq.sinajs.cn/list=\
sz000636,sh600183,sz002138,sz300285,\
sz300750,sz002812,sz002460,sz002466,\
sz002371,sh688981,sh600703,sz300661,\
sh688041,sz000977,sz300308,sh688256,\
sh600900,sh601318,sh600519,sz000333' \
  -H 'Referer: https://finance.sina.com.cn' | iconv -f GBK -t UTF-8//IGNORE
```

## Python 解析模板

```python
import sys

def parse_sina_batch(output: str):
    """Parse Sina hq.sinajs.cn batch output into per-stock dict."""
    results = {}
    for line in output.strip().split('\n'):
        if '=' not in line or '"' not in line:
            continue
        code = line.split('=')[0].replace('var hq_str_', '')
        parts = line.split('"')[1].split(',')
        name = parts[0]
        open_p = parts[1]
        yclose = parts[2]
        price = parts[3]
        high = parts[4]
        low = parts[5]
        vol = parts[8]
        amount = parts[9]
        if yclose and yclose != '0.000':
            chg_pct = (float(price) - float(yclose)) / float(yclose) * 100
        else:
            chg_pct = None
        results[code] = {
            'name': name,
            'price': price,
            'chg_pct': chg_pct,
            'high': high,
            'low': low,
            'vol': vol,
            'amount_100m': float(amount) / 1e8 if amount else 0,
        }
    return results
```

## 板块强度推断规则

| 代理指标 | 推断 |
|---------|------|
| 板块内 7 只股票平均涨幅 >+3%，且 3+ 只涨幅 >+5% | **板块性涨停潮**，可确认主线 |
| 板块内 7 只股票平均涨幅 +1%~+3%，全部正向 | **普涨**，板块方向有效 |
| 板块内龙头 +3% 但跟风 1 只 -1%，其余在 0 附近 | **分化**，仅龙头有效 |
| 板块内 3+ 只下跌且 >-2% | **退潮**，回避 |
| 半导体设备（北方/中微）+ 但设计（兆易/澜起）- | **内部分化**，资金从设计切设备 |
| 高股息（长江电力/平安）- 且 MLCC/锂电池 + | **风险偏好回升**，防御资金回流成长 |

## 常见陷阱

| 陷阱 | 说明 |
|------|------|
| 代表股票选择偏见 | 手动选股可能遗漏弱势股，导致板块强度高估。保守解读：只看"明确信号"（涨停/大跌），不看模糊信号 |
| 科创板/创业板 20cm 影响 | 科创板和创业板的涨停板是20%，计算涨幅时注意与主板的10%对比 |
| 个股大幅波动干扰均值 | 单只股票异常涨跌（如兆易-5%）会拉低板块均值。建议同时看"中位数"和中位值附近范围 |
| 少数龙头权重过大 | 宁德时代+4.44%拉高了锂电池均值，实际上跟风股可能只有+2%。使用中位数+龙头分开报告 |
