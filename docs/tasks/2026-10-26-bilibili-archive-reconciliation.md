## 1. 核销口径

- **原文**：本地 Markdown 的 frontmatter `dynamic_id` 与尾部原始 API `id_str` 一致，且有正文、图片链接或可用详情；只有占位文件的记为待补详情。
- **转写**：有可核验的正文转写才记完成。`ASR失败`、`ASR跳过`、只有音乐、与标题明显不符的模型输出均不算完成；非视频记为不适用，无语音视频转入画面/OCR路径。
- **claim**：以 `knowledge/claims/*.yaml` 的 `source_path` 回链为准。仅基于标题或封面 OCR 的低置信 claim 单独标注，不能代替正文学习。
- **pattern**：以 `framework/reasoning-patterns.yaml` 的 `source_raw` 回链为准；提案与正式入库分开。
- **framework**：核对正式方法论文档是否覆盖并有来源回链。pattern 不等于 framework；未经后续明确指令，不自动合并方法论，推理模式仍走提案与人审。
- 每层均由上游证据驱动，不用标题猜想补齐正文，不用单次行情观点直接提升长期框架。
