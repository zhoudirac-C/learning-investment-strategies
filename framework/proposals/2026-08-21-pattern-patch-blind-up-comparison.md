# 盲判优化提案：UP 推理思路五项（2026-08-20 三方对比）

## 背景

2026-08-20 三方对比：

- **早盘盲判**判「调整/内生瓦解」，真值「震荡」，miss。错法与 08-19 复盘盲判完全同构
  （情绪指标崩 → 趋势外推判调整），连续两天重现——08-19 归因提案
  （`2026-08-19-pattern-patch-note.md`，主轨 open）尚未落地，本提案与其互补而非重复：
  08-19 主轨管「外力/内生归因前置」，本提案管「内部情绪数据的反向检验与解读深度」。
- **复盘盲判**判「震荡/缩量企稳」，命中标签，但对照 UP 同日复盘，解读停在描述层
  （"涨幅居前+资金流入"），UP 的因果链与次日演绎全部缺失。

盲判推理链的具体缺口（对照 UP 同日产出逐条核实）：

1. 同样的极端情绪数据（跌停 118 家/上涨 449 家），UP 套"三信号见底清单"读出
   "接近极限、今天很难比昨天更差"，盲判做趋势外推判"内生瓦解"；
2. 盲判把昨日最强防御方向（银行/煤炭）标「维持」顺延，当日煤炭冲高回落、安泰集团
   触及跌停——踩中高低切，选了全场最差顺延方向；
3. 复盘盲判把"4096 家上涨"读作"情绪修复初现"（偏多），UP 读作"宽度修复非强度修复，
   反而消耗调整时间、延长调整周期"（偏空）——同一证据、相反结论；
4. 复盘盲判 nature 选「缩量企稳」，但 UP 在 08-16 已定性"缩量企稳只能证明卖方衰竭，
   还不能证明买盘回来了"——nature 枚举值本身的含义没有被吃透；
5. 复盘盲判对量能用自拍绝对阈值（"回升至 24000 亿以上确认修复"），UP 用量能周期路径
   锚定关键线（守住 2 万亿）——下台阶周期里前者可能永远等不到确认信号；
6. 连板梯队停在汇总层（高度 4 板、晋级率 13.79%），UP 的个股级故事（哈药控异动失败
   +机构净买入 10.65 亿矛盾、神奇制药换龙、金健米业独苗）全部缺席——这些恰是次日
   验证节点。

## 模式一：情绪极值三信号清单（判「调整/内生瓦解」前的反向检验）

**模式内容**：UP 反复使用的见底检验清单——①强势股补跌（核心连板高标同步跌停/
发风险提示）；②多杀多（跌停家数盘中反超涨停并飙升）；③流动性见底（缩量，
抛压衰竭）。判「调整/内生瓦解」前必须先过这三条：前两条已出现而第三条未出现
（放量下跌）时，正确定性是"接近极限但缺最后一跌/换手"，次日基准情形是
"很难更差 + 不直接反转 = 横向震荡"，而不是趋势延续。

**触发与动作**：

- 触发：跌停 ≥80 家或上涨家数 ≤1000 或晋级率 <12% 等情绪极端值出现，且模型即将
  输出「调整/内生瓦解」时（08-19、08-20 两天均为此形态）。
- 动作：stage_reason 必须逐条回答三信号（各自成立/不成立 + 数据引用），再下结论；
  三信号缺"流动性见底"时 market_stage 禁判「调整」，nature 禁判「内生瓦解」，
  情形构造按"震荡磨窗口"展开（UP 原话："今天很难比昨天更差，但也不该指望今天
  就直接反转"）。

**配套数据**：涨停池/跌停家数/连板名单/成交额环比，均已在盲判包内，无新通道。

**证据**：

- 2026-08-20（震荡）UP 早盘：「按此前梳理的三信号底部清单——强势股补跌、多杀多、
  流动性见底，昨天前两条已经同时出现……缺的是第三条，而放量的下跌恰恰说明流动性
  还没有见底——这就是为什么今天很难比昨天更差，但也不该指望今天就直接反转。」
  同日盲判未做该检验，判「内生瓦解」miss。
- 2026-08-13（放量阴线，震荡/调整边界）UP 复盘：「此时应回到三条见底判据去检验
  这一轮情绪周期是否结束：强势股是否补跌、是否出现多杀多、流动性是否见底。」
  ——清单为 UP 跨日复用框架，非单次语境。
- 2026-07-30（调整修复日）UP 复盘：「科技股早盘一度进入多杀多，午后德明利率先涨停，
  进一步激活资金做多情绪」——多杀多作为情绪释放信号的更早用例。

**证伪**：三信号齐备（含缩量）后指数仍连续破位下行，则清单的"接近极限"推论失效，
按趋势性调整处理。

## 模式二：宽度修复 ≠ 强度修复（普涨日的定性两步走）

**模式内容**：上涨家数大幅领先但指数冲高回落/翻绿时，禁止直接读作"情绪修复"，
必须分两步：①分解"谁在涨、谁在压"——涨的是超跌/低位补涨、压的是权重/前期高位
品种 = 宽度修复；②推演对调整周期的影响——缩量宽度修复"既没有完成充分换手，
也没有释放真实增量，不构成调整结束的信号，反而消耗掉了调整本该走完的时间，
大概率使调整周期进一步延长"（反抽定性）。

**触发与动作**：

- 触发：上涨家数/下跌家数 > 2 且指数收跌或长上影。
- 动作：stage_reason 必须写明宽度/强度归属与"修复 or 反抽"定性；判反抽时
  invalidation/scenarios 的关键线设为"量能是否守住当前台阶"而非"回升至上台阶"。
- 与既有提名的关系：补 `2026-08-18-pattern-index-sentiment-divergence.md`
  （指数-情绪背离识别）——该提名管"识别背离"，本模式管"背离日后的修复成色推演"，
  建议合并验证、转正时合为一个模式的两步。

**配套数据**：涨跌家数 + 指数涨跌（包内已有）；拉升板块构成（sector_intraday，
08-18 数据通道提案已实施）。

**证据**：

- 2026-08-20（震荡）UP 复盘：「个股普涨与指数走弱同时出现，说明今天的修复发生在
  宽度而非强度上——涨的是超跌与低位补涨，压的是权重与前期高位品种」「今天这种缩量
  宽度修复……反而消耗掉了调整本该走完的时间，大概率使调整周期进一步延长。」
  同日盲判包内 sector_intraday/涨跌家数齐备，输出未做分解。
- 2026-08-16（震荡）UP 周复盘：「缩量企稳只能证明卖方衰竭，还不能证明买盘回来了。
  存量博弈下的站住和增量进场的站上去，是两回事。」——"nature=缩量企稳"的正确
  含义注脚，直接适用于 08-20 复盘盲判的 nature 选择。

**证伪**：宽度修复后 1-2 日内量能重回上台阶且权重止跌，则反抽定性证伪，改判修复确认。

## 模式三：量能周期路径锚定（替代自拍绝对阈值）

**模式内容**：量能按周期路径看位置（UP 08-20 梳理：峰值近 4 万亿 → 降至 2.5-2.6 万
→ 回升 3 万+ → 跌破 2.5 万 → 缩至 2 万 → 反复后见 1.5-1.6 万地量）。下台阶阶段，
次日关键线是"能否守住当前整数台阶"（2 万亿），不是"回升至上台阶"（2.4 万亿）。
两条辅则：①整数关口反身性——"越是被反复挂在嘴边的整数量能位，越具有迷惑性，
它和 3000 点保卫战是同一种叙事"；②跌破后的资金反转风险——"此前高度集中涌入少数
高位品种的增量资金会反转成为砸盘主力"。

**触发与动作**：

- 触发：写 scenarios/watch_next 的量能阈值时（每次必触发）。
- 动作：先定位量能周期所处台阶，再用"守住/跌破当前台阶"的相对表述；
  绝对刻度只许引用方法论分档（对齐盘前 prompt 规则 15）；判"逼近整数台阶"时必须
  附整数关口反身性与跌破后资金反转的下行风险描述。
- 08-20 复盘盲判情形 A「成交额回升至 24000 亿以上 → 修复确认」为本模式的反例
  （下台阶周期中把确认线挂在上一台阶）。

**配套数据**：两市成交额日序列（近 60 个交易日，kline_cache 已有）。当前盲判包只有
当日/前日额与环比，**需补「成交额近 20/60 日序列 + 阶段峰值/谷值」小块**（轻量，
kline_cache 直接出）。

**证据**：

- 2026-08-20（震荡）UP 复盘：量能周期路径完整表述 + 整数关口论述（见上方引用）。
- 「地量」概念长期使用：06-11、07-08、07-09、08-04、08-06 早盘/复盘均有用例，
  跨 2 个月+、覆盖震荡/调整 regime。

**证伪**：量能不再下台阶、重新站上 2.5 万亿并持续 3 日以上，则"下台阶路径"假设
失效，阈值锚定切回放量确认框架。

## 模式四：弱市防御走强的反指性（高低切默认项）

**模式内容**：弱市（指数大跌/情绪冰点）中防御板块（银行/煤炭/石油石化等）逆势
净流入，定性为"资金在找一个不需要判断的去处"的避险对冲，**不构成做多证据，也不
构成次日延续证据**——"这种结构下大金融走强并不构成指数见底的证据，反而说明进攻端
暂时失去了共识"。次日若情绪修复，昨日防御品种默认退潮（高低切），进攻端低位方向
轮动走强。

**触发与动作**：

- 触发：弱市日防御板块净流入居前；或 directions 候选含"昨日净流入居前的防御方向"。
- 动作：盘前盲判 directions 禁止把昨日防御方向标「维持」顺延，须先答"今日修复
  概率"——修复情形防御默认退潮（标退潮或不选）；复盘盲判必须回溯昨日/今早所选
  方向的当日表现并标退潮（连续判断补齐，对齐盘前 prompt 规则 5 的闭环）。
- 与存量 `defense_to_sector_rotation`（防御股剧本，example 层）的关系：本条将其
  升级为带触发/证伪的独立步骤，并补"次日退潮默认项"这一反向推断。

**配套数据**：板块资金流（fund_flow 已有）+ sector_intraday 防御/进攻阵营分时
（已有）。无新通道。

**证据**：

- 2026-08-20（震荡）：UP 早盘「这是典型的防御性对冲结构——资金不是在这些方向上
  寻找收益，而是在寻找一个不需要判断的去处」；UP 复盘「昨天最强的防御性品种今天
  集体走弱，进攻性方向轮动走强，是标准的高低切结构」。同日盲判选银行/煤炭标
  「维持」，当日煤炭冲高回落、安泰集团触及跌停——反例成立。
- 高低切表述跨日多次：06-29（"一天之内风格三次切换"）、07-06、08-16（"高低切引发
  的内生性回调"）、08-18（"高低切比较明显"），覆盖震荡/调整 regime。

**证伪**：防御方向在修复日继续放量走强且指数同步企稳（防御与指数同向），则
"避险对冲"定性证伪，改按主线对待（如有业绩/政策催化另行定性）。

## 模式五：情绪事件个股化——矛盾点写成次日验证节点

**模式内容**：连板梯队分析不停留在汇总指标：①梯队独苗（唯一高位活口）必须点名
并给出"分歧转一致/断掉"的次日观察窗口；②断板事件落到个股——结合断板性质二分法
（已入库，`board_break_nature`，2026-08-15 提案）判定换龙/外力，并点名承接标的；
③机构席位 top 个股与情绪事件方向相反时（如控异动失败 + 机构大额净买入），必须写为
"次日需优先确认的矛盾"，进 watch_next 第一条。

**触发与动作**：

- 触发：limit_pool.ladder 存在（每日）；lhb.jgmmtj 个股净买卖额与该股当日情绪事件
  方向冲突时（必须显式检索此交叉）。
- 动作：watch_next 首条为个股级验证节点（标的 + 事件 + 确认/证伪条件）；与盘前
  prompt 规则 16 互补（规则 16 管字段引用，本模式管"把矛盾写成验证节点"）。

**配套数据**：limit_pool（已有）+ lhb 机构席位（已有，规则 13 已强制引用）+
emotion 断板名单（已有）。无新通道。

**证据**：

- 2026-08-20（震荡）UP 复盘：「机构今天在哈药股份上是净买入 10.65 亿元的大额动作，
  而该股同时出现控异动失败——买盘规模与情绪端表现方向不一致，这是明日需要优先
  确认的一处矛盾」；金健米业「唯一的活口且是连板高度……明日是观察窗口」；神奇制药
  「接过了新的医药情绪载体这个身份」（换龙承接点名）。同日复盘盲判仅有机构 top5
  合计数，无个股级节点。
- 2026-08-18（震荡）：高度-宽度背离提名（`2026-08-18-pattern-height-width-divergence.md`）
  已覆盖梯队结构两维分析，本模式补"个股级验证节点"写法，两者联用。

**证伪**：个股验证节点连续 3 日对次日情绪走向无预测力（节点写错对象），则回退到
汇总层表述。
