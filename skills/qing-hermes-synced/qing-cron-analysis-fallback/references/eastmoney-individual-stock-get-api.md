# 东方财富个股独立报价 API（`api/qt/stock/get`）

> 适用场景：需要单只标的精确实时行情（价格、涨跌幅、日内高低、成交量、成交额）
> 替代 `clist/get` 批量模式：个股独立 API 返回字段更完整（含涨跌额、5档盘口），且无需从列表中过滤
> 已验证：2026-07-21 11:25 成功获取 恩捷股份(002812) 行情

## 核心端点

```
GET https://push2.eastmoney.com/api/qt/stock/get
```

**参数**：

| 参数 | 说明 | 示例值 |
|------|------|--------|
| `secid` | 市场+代码：`0.{代码}` 深市，`1.{代码}` 沪市 | `0.002812` |
| `fields` | 返回字段（逗号分隔） | `f43,f44,f45,f46,f47,f48,f57,f58,f60,f170,f169` |

**快速检查**：
```bash
# 恩捷股份（深市 0.前缀）
curl -s "https://push2.eastmoney.com/api/qt/stock/get?secid=0.002812&fields=f43,f44,f45,f46,f47,f48,f57,f58,f60,f170,f169"
```

## 字段映射

| 字段 | 含义 | 单位/换算 | 示例值 |
|------|------|-----------|--------|
| `f43` | 最新价 | **需 ÷100**（原始值为厘） | `4984` → 49.84元 |
| `f44` | 最高价 | 需 ÷100 | `5010` → 50.10元 |
| `f45` | 最低价 | 需 ÷100 | `4711` → 47.11元 |
| `f46` | 开盘价 | 需 ÷100 | `4841` → 48.41元 |
| `f47` | 成交量 | 手 | `166398` 手 |
| `f48` | 成交额 | **元**（不需换算） | `811665061` 元 ≈ 8117万 |
| `f57` | 股票代码 | 字符串 | `002812` |
| `f58` | 股票名称 | 字符串 | 恩捷股份 |
| `f60` | 昨收 | 需 ÷100 | `4800` → 48.00元 |
| `f170` | 涨跌额 | 需 ÷100 | `179` → 1.79元 |
| `f169` | 涨跌幅(%) | **原始值为百分比×100**，需 ÷100 | `373` → 3.73% |

> **⚠️ 关键坑**：f43/f44/f45/f46/f60/f170 的单位都是"分/厘"（百分之一或千分之一元），**必须 ÷100** 才是元。f48（成交额）的单位是元，不需换算。f169（涨跌幅）是百分比×100，需 ÷100。

## Python 解析示例

```python
import urllib.request
import json

def get_stock_quote(secid: str) -> dict:
    """获取单只个股实时行情
    secid: '0.002812' 或 '1.600519'
    """
    url = f"https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields=f43,f44,f45,f46,f47,f48,f57,f58,f60,f170,f169"
    with urllib.request.urlopen(url, timeout=15) as resp:
        data = json.loads(resp.read().decode('utf-8'))
    
    d = data['data']
    return {
        'code': d['f57'],
        'name': d['f58'],
        'price': d['f43'] / 100,       # 最新价（厘→元）
        'prev_close': d['f60'] / 100,   # 昨收
        'open': d['f46'] / 100,         # 开盘
        'high': d['f44'] / 100,         # 最高
        'low': d['f45'] / 100,          # 最低
        'volume': d['f47'],             # 成交量（手）
        'amount': d['f48'],             # 成交额（元）
        'change': d['f170'] / 100,      # 涨跌额
        'change_pct': d['f169'] / 100,  # 涨跌幅（%）
    }

# 使用
quote = get_stock_quote('0.002812')
print(f"{quote['name']}: {quote['price']} ({quote['change_pct']:+.2f}%)")
print(f"  成交{quote['amount']/1e4:.0f}万, 量{quote['volume']}手")
print(f"  高{quote['high']} 低{quote['low']} 开{quote['open']}")
```

## 与 `clist/get` 批量模式的对比

| 维度 | `api/qt/stock/get`（本参考） | `api/qt/clist/get`（批量模式） |
|------|-----------------------------|-------------------------------|
| 查询主体 | 单只标的（按 secid） | 批量列表（按 fs 条件） |
| 字段精度 | 含涨跌额(f170)、涨跌幅%(f169) | f3=涨跌幅%、f4=涨跌额 |
| 字段单位 | **f43等价格字段÷100**，f48(成交额)为元 | **f2价格字段直接为元**，f20(成交额)为元 |
| 盘口数据 | 不含5档买卖盘 | 不含 |
| 适用场景 | 精准分析单只标的 | 板块排名/全市场扫描 |
| 限流风险 | 低（单个请求） | 中（全市场5000+条可能超时） |
| 价格字段 | 厘为单位(÷100) | 元为单位 |

**推荐做法**：
- 板块排名/全市场涨跌比 → `clist/get`
- 单只标的精准分析（含涨跌幅%、涨跌额） → `stock/get`

## 已知限制

| 能力 | 状态 |
|------|------|
| A股个股实时行情 | ✅ |
| 指数实时行情（上证/深证/创业板等） | ✅（secid=1.000001 等） |
| 科创/创业/主板统一字段 | ✅ 字段一致 |
| 北向资金 | ❌ 不支持 |
| 主力资金流向 | ❌ 需不同端点 |
| 港股/美股 | ❌ 不支持 |
| 非交易时段 | ⚠️ 返回静态数据（昨收值） |
