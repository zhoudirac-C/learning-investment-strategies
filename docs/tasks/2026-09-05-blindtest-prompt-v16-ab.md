# 盲判 prompt 压缩（v16）+ A/B 回放检验

日期：2026-09-05

## 背景

`src/investment_engine/blindtest/replay.py` 的 SYSTEM_PROMPT（v15）为 37 条经验补丁
规则（9.7K 字符），编号断裂（无 26、23b 乱序）、同义规则成组重复（10/12、15/20、
17/28b、24/30/31、21/32、23/23b/36），且混入会过期的经验快照与数据表（规则27 的
C1-C7 分簇 id 表）。user 数据包约 166K 字符（≈76K tokens，09-04 实测台账 76,878）。

## 设计

1. **v15 原样冻结**为 `SYSTEM_PROMPT_V15`，新压缩版为默认 `SYSTEM_PROMPT`，
   `PROMPT_VERSION = "v16"`。生产（shadow/predict.py）自动跟随默认版本。
2. **压缩原则：经验规则 → 推理链 + 元原则**。37 条归并为 17 条：
   推理链五步（定位置 → 定归因（先外后内） → 定结构（价格优先于宽度） →
   定量价（双口径） → 定方向（催化溯源/同簇限选/战绩/失效条件）） +
   特殊盘面（极端日三信号/连板梯队/调整终局） + 输出纪律。
3. **校验锚点全保留**：`validate_result` 的机械校验（规则15/18/24/25/27/28/31/
   5b 等）依赖输出中的关键词，v16 条文逐一保留对应锚点（补跌/多杀多/流动性/
   机构/梯队/宏观三条件/冲量滑落/盘前/同簇…），校验层代码不动。
4. **双版本可回放**：`build_messages`/`run_replay` 增加 `system_prompt`、
   `prompt_version`、`use_validation` 参数（默认行为不变）。

## A/B 检验

- 脚本：`scripts/blindtest_prompt_ab.py`（仿 `blindtest_lp_ab.py`）。
- 窗口：2026-08-17 ~ 2026-08-28（10 个交易日，T+5 至 09-04 全部到期；
  truth 标签含 震荡×8 + 调整×2）。
- 两臂同数据包（本地落盘文件，逐日确定），唯一变量 = system prompt；
  两臂均走 `run_with_validation`（与生产一致），可对比重试率。
- 产物：`evals/blindtest/ab-prompt/{v15,v16}.jsonl`。
- 指标：阶段一致率（参考，n=10 区间宽）、方向/标的 5 日超额命中率（主指标）、
  校验重试率（成本指标）。

## 通过标准

v16 的方向/标的命中率不显著低于 v15（差距 ≤ 5pp 视为噪声内），
重试率不明显升高 → 保留 v16 为默认；否则回退（默认版本改回 v15 一行改动）。

## 检验结果（2026-09-05 收官，报告见 reports/blindtest-prompt-ab-20260905.md）

- 阶段一致率：v15 50% vs v16 70%（n=10，噪声内，v16 偏多）
- 方向/标的命中率：v16 低 14-17pp（n=10-24，噪声内但方向为负）
- 校验重试：v15 4 天 vs v16 8 天（翻倍；总 token 成本 v16 反 +26%）
- **裁决：未通过，生产默认回退 v15**（`SYSTEM_PROMPT = SYSTEM_PROMPT_V15` 一行别名），
  v16 保留为 `SYSTEM_PROMPT_V16` 迭代基线；后续优化主战场转至 user 数据包
  （占输入 ~94%，system prompt 压缩收益上限仅 2-3%）。

## 二轮（v15 vs v17，20 日窗口，报告见 reports/blindtest-prompt-ab-v17-20260905.md）

- v16 归因修复版 v17：direction_pool 回 pack + 引用清单 + 硬门槛逐条。
- 池归位生效（两臂池 id 占比 100%）；标的选择 v17 +14pp（噪声内偏好）；
  阶段/方向持平。
- 但重试率未修复（v17 18/19 vs v15 8/20）：主犯规则15（首版 37 次 vs 6），
  机制 = 压缩删掉了冗余强调（v15 规则15+20 双处）与「守住/跌破」豁免词汇；
  同簇限选语义化也变弱（规则27 首版 6 vs 0）。
- **裁决：v17 仍未通过，默认维持 v15。** v18 处方：规则15 双处强调 +
  JSON 契约字段内联提示；direction_pool 带 cluster 字段（数据层）。

## 三轮（v15 vs v18，20 日窗口）——v18 = v15 + 规则28(c)「调整需结构确认」

- 动机：v15 的 7 个阶段错判中 5 个为「震荡误判调整」（系统性悲观偏置）。
- 结果：**阶段一致率 65% → 50%，否决**。翻转 5 天中 4 天从对的震荡翻成错的
  调整（08-17/18/26/28），仅 1 天修对（08-21）。机制：门条件引用的结构信号
  （顶部 forming/破位/窗口到期）在弱势市场几乎天天在场，门常开、无判别度。
- 教训：**用"常有信号"做门槛没有区分度**；阶段微调继续对着机械真值尺
  调参的边际收益已很低。
- 实验污染备注：本轮 v18 臂 pack 已含 volume_anchor 块（v15 基线不含），
  阶段归因不受影响（锚点块不碰阶段逻辑），但规则15 违规数两臂不可比——
  由 Round B（v15+锚点 pack vs 既有 v15 基线）单独归因。

## 四~五轮（B/C/C2，2026-09-06 凌晨收官，终审见 reports/blindtest-prompt-adjudication-20260905.md）

- **B**：volume_anchor 块否决并拆除（规则15 首犯 6→14：给现成数字反而诱发阈值，
  且 20 日均值不在校验器豁免口径内）。
- **C→C2**：包瘦身四刀中 index 60→20 根是阶段回归主嫌疑（破位观感放大），
  回滚后保留其余三刀（sectors≤8 / chains 活跃过滤 / lhb 12+席位3），
  pack -9%（166K→151K 字符），阶段 70% vs 基线 65%，方向/标的噪声内持平。
- **最终**：生产 = v15 prompt +（direction_pool + 瘦身三刀）pack。
- **元结论**：n=20 窗口的扰动噪声底约 ±10pp 阶段 / ±4 重试日；更精细的裁决
  需要同配置重复跑测纯噪声或 40+ 日窗口。
- **40 日复验（2026-09-06）**：07-06~08-28 双臂重跑（base vs 三刀），阶段
  +5pp（两段市况一致）、方向/标的噪声内、重试不升——三刀无损成立。
  数据 `evals/blindtest/ab-40d/`，开关 `BLINDTEST_PACK_SLIM`。
