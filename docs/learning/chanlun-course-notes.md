# 三、第三部分讲义：走势终完美 · 中枢 · 级别（第17-22、35、38-40课）

> 进度：2026-08-23 开讲。缠论真正的骨架。学完本部分，均线系统退居辅助，一切概念获得严格定义。
> 用户前置疑问（已在此部分得到回答）：①级别是什么 ②60min反弹为何只有几天 ③为什么日线没背驰就只能当反弹仓。

## L17：走势终完美——哲学基石

**原理一**：任何级别的任何走势类型终要完成。两个方面：①任何走势最终都要完成；②完成后必然转化为其他类型（下跌完成只能转上涨或盘整）。
- 当下"延续还是转折"是无解的两难——理论不预测，只提供分类框架+转折关节点识别。
- **直接推出两类买卖点**：
  - 一买 = 下跌走势完成的关节点（下跌后只能转上涨/盘整，都对多头有利）；
  - 二买 = 一买后第一次次级别回调低点。安全性证明：上涨/盘整须含≥3段次级别运动（分解定理二），一买后已走两段，后面必然还有一段向上——安全性由逻辑保证非概率。
- **买卖点定律一**：任何级别二买由次级别一买构成（claim-20061205-001-a 出处）。
- **趋势转折定律**：任何下跌转折都由某级别一买构成（可能是多级别共振，不只次级别）。

**中枢首次定义**：某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。
- **盘整** = 完成走势只含 1 个中枢；**趋势** = 含 ≥2 个依次同向、互不重叠的中枢。中枢上移=上涨，下移=下跌。
- **原理二**：任何完成走势必含 ≥1 个中枢（无中枢=一次单向永动，仅退市可能）。

## L18：中枢的生住坏灭

- **延伸难题**：盘整可围绕中枢无限震荡，趋势可不断出新中枢（600519式长牛）。抓不住牛股=在第一个中枢被震下马；抄底噩梦=下跌延伸。根源都是不懂延伸何时结束。
- **判别唯一关键 = 是否产生新中枢**：盘整延伸=不产生新中枢；趋势延伸=同向新中枢不断产生；新中枢不再同向→趋势结束。
- **定理一**：趋势中连接两个同级别中枢的必然是次级别以下走势（可以是缺口；连接段级别越低力度越大——缺口技术含义的理论依据）。
- **定理二**：盘整中离开/返回中枢必为次级别以下——推论：真高低点总在盘中一闪而过，挂单必须提前挂。
- **定理三（破坏）**：次级别离开中枢后回抽不回中枢区间 = 破坏。最有力的破坏="趋势+盘整"（突破后盘整回抽确认，其后上涨有力）——"突破回踩确认"的严格化。

## L19：学习的关键

1. 推导如几何，从原理一二逐级证明，无先验假设（对比波浪理论5浪3浪的拍脑袋）。
2. 其他技术分析现象都能被解释并给出成立边界；庄家逃不掉基本结构。
3. 技术分析只是三大独立系统之一（技术面+比价+基本面），但是散户唯一公开、第一手、无先后差的信息。
4. 最终意义：不是预测市场要干什么，而是看清正在干什么——当下的直观。

## L20：中枢级别扩张与第三类买卖点

中枢后三种演化：①延伸 ②新生（新同向不重叠中枢→趋势）③扩张（波动区间重叠→更高级别中枢）。
- **级别延续定理一**：更大级别中枢产生前，该级别走势类型将延续。
- **级别延续定理二**：更大级别中枢产生 ⟺ 连续两个同级别中枢的波动区间重叠。
- 大白话：趋势/盘整要"真的结束"，看到更大级别中枢形成才算数；级别不可跳跃。
- **第三类买卖点定理**：次级别向上离开中枢+次级别回试低点不跌破ZG（中枢区间上沿）=三买；向下镜像=三卖。纪律：必须是第一次回试；三买后不必然是趋势（可能更大级别盘整），不出趋势就在盘整高点兑现。

## L21：买卖点完备性

- 三类之外无其他被理论保证的买卖点（claim-20070109-001-a）。论证：任一点只有延续/转折两种可能→延续买点在中枢上方（三买）、转折买点在中枢下方且只在下跌确立后（一买及派生的二买）。
- **上涨趋势确立后不可能再有一买二买，只可能有三买**——牛市回调买入的正确姿势=等中枢上移后的回踩。
- "人使理论，而非理论使人"。

## L35：级别的递归本质

- 解决循环定义（走势类型↔中枢互相定义）：最低级别锚定（实操=1min或5min K线，三根重叠=最低级别中枢）→ 逐级"三个连续次级别走势重叠=高一级中枢"上推。
- 实操简化口径（缠师钦定）：三个1min走势重叠≈5min中枢，三个5min≈30min……1/5/15/30/60min、日、周、月、季、年。
- 回答用户"级别是什么"：级别=递归结构层级；周期表是工程近似；相邻级5~6倍时长感来自"三个次级单位合成一个本级单位"。

## L38-39：同级别分解——机械化操作

- 选定固定级别把所有走势切成该级别走势类型连接，分解唯一。规则：只做上涨+盘整段、回避下跌段；永远只盯当前正在完成的一个中枢；该级别允许盘整+盘整（非同级别分解视角不允许，勿混）。
- 不问牛熊："30min上涨就是牛市，否则熊市"。机械化利润与时间成正比。
- 韵律纪律：向上段先买后卖、向下段先卖后买；一步错了唯一正确选择=停止操作调好韵律再来。
- L39后半a+A序列Ai/Ai+2盘整背驰法：全书最难啃段落，初学允许跳过，实战需要再精读。
- 用户skill映射："60min定入场时机"本质=同级别分解视角；P3后可升级为显式"中枢标记→分类状态→预案"流程。

## L37：背驰的成立前提——"没有趋势没有背驰"的严格版本

- 对典型形式 **a+A+b+B+c** 谈背驰有三条前提：
  1. **A、B 必须是同级别中枢**——否则只是较大中枢的震荡，谈不上背驰
  2. **c 必然是次级别**，且至少包含一个对 B 的第三类买卖点
  3. **上涨 c 一定要创新高、下跌 c 一定要创新低**（P6 讲过笔图的"未创新低不构成比较"就是此处的雏形）
- **背驰不会发生在第一个中枢之后**：趋势至少两个同级别中枢，背驰一般出现在第二个中枢后
  （日线以上级别第二个中枢后出背驰占 90% 以上，课27）——这是"伪背驰"的第一道滤网

## L24：MACD 辅助判断（实战主工具）

- 标准结构：两段同向趋势 **A、C** 之间有中枢 **B** 连接，**B 的级别比 A/C 里的中枢都大**，
  一般会把 MACD 黄白线（DIF/DEA）**回拉到 0 轴附近**
- **标准背驰**：C 段走势类型完成时对应的 MACD **柱子面积**（向上看红柱、向下看绿柱）
  比 A 段对应的面积小 → 动能衰竭
- 技巧：柱子伸长力度变慢时，把已出现面积 ×2 估算全段面积，可卖在最高、买在最低附近
- 准确性：光用 MACD 分清 A/B/C 三段 >90% 准确；配合中枢结构 = 100% 绝对
- **口径纪律（用户已拍板）**：背驰面积用 **|hist|（DIF−DEA 柱）累加求和**，不是 DIF 面积，
  也不是均线面积；判定阈值 a2 < a1×0.9（10% 以上萎缩才算背驰）

## L25/27/43：背驰三定理

- **背驰-买卖点定理**（L24）：任一背驰必然制造某级别的买卖点；出现背驰后必然有逆转，
  逆转的幅度 = 重新出现新的次级别买卖点为止；趋势中产生的背驰，回跌至少重新回到 B 的中枢里
- **背驰-转折定理**（L29/43）：某级别趋势的背驰将导致——①该趋势最后中枢的级别扩展
  ②该级别更大级别的盘整 ③该级别以上级别的反趋势。**分辨关键**：反弹第一个次级别走势
  能否回抽到最后一个中枢（回不去=至少扩展/盘整，站得稳=可能反转）
- **背驰的级别一定不小于转折的级别**（L52）——这是"60min 顶背驰最多引发日线回调，
  不会直接制造周线大顶"的理论依据（skill 输出惯例"防守线=最近底背驰低点"由此而来）

## L44：小背驰-大转折（小转大）——只有必要条件，没有充分条件

- 小级别顶背驰引发大级别向下的**必要条件**：该级别走势**最后一个次级别中枢出现第三类卖点**
  （底背驰反之必出第三类买点）
- **没有充分条件**：小级别背驰后能在最后次级别中枢正常震荡的，都不可能转化成大级别转折
  ——冲顶赶底阶段对"小背驰大转折"要格外警惕（常是主力借小级别背驰洗盘）

## 盘整背驰：背驰力度分析在盘整中的推广

- **C 段不破中枢** 而 MACD 面积小于 A 段 → 其后必有回跌
- **C 段上破中枢** 但面积小于 A 段 → 先出来；回跌**不跌回中枢**则构成第三类买点
- 多数第二、三类买点由盘整背驰构成，第一类买点多数由趋势背驰构成
- 盘整背驰在**大级别（周线以上）**最有用——发现的往往是历史性大底部
- 操作思维：理论只保证回拉原中枢，其后完全分类、预设对策（"对真正的操作者没有任何情况是意外的"）
- **口径红线**：盘整背驰 ≠ 一买（一买只属于趋势背驰）——报告必须标注背驰类型
  （skill 强制 trend_div/consolidation_div 标签）

## 四个关键词带走

**前提（同级别中枢+c含三买+创新高）→ 面积（MACD柱 |hist| 累加）→ 类型（盘整vs趋势）→ 传导（小转大看级别）**

## 0. 中枢记号系统（L20，先补工具箱——后面全部用这套语言）

L20 首次给出严格记号，之后所有定理都用它表述：

- 中枢区间由与中枢方向一致的次级别走势段（**Z 走势段 Z1, Z2, …**）的重叠确定；
  每段高点 gn、低点 dn。
- **ZG = min(g1, g2)，ZD = max(d1, d2)**，**[ZD, ZG] 就是中枢区间**（只用前两段定区间，
  后续段是延伸）。
- 四个辅助极值：**GG=max(gn)（波动最高）、G=min(gn)、D=max(dn)、DD=min(dn)（波动最低）**。
- **中枢中心定理一**：延伸 ⟺ 任意 [dn, gn] 与 [ZD, ZG] 有重叠。某段 dn > ZG（整个跑到上面）
  或 gn < ZD（整个跑到下面）→ 延伸被打破，必然产生高级别中枢或趋势。
- **中枢中心定理二**（两中枢关系三分类，背驰 A-B-C 结构的严格版本）：
  后 GG < 前 DD ⟺ 下跌延续；后 DD > 前 GG ⟺ 上涨延续；
  后 ZG < 前 ZD（或镜像）⟺ 形成更高级别中枢（= P3 讲的"扩张"）。
- 恒星-行星比喻（L20 原文）：中枢=恒星，围绕波动的极值=行星；两个同级别恒星系统
  要合成更大系统，**必须至少行星之间先发生关系**（波动区间重叠）——级别不可跳跃。

## 1. 第三类买卖点定理（L20，定理原文口径）

> 一个次级别走势类型向上离开缠中说禅走势中枢，然后以一个次级别走势类型回试，
> **其低点不跌破 ZG**，则构成第三类买点；向下镜像（回抽高点不升破 ZD）=第三类卖点。

- **三买的结构本质**：次级别离开 + 次级别回试，回试低点站在中枢区间上沿 ZG 之上
  ——中枢的"离开"被确认为有效（对照 L18 定理三"破坏"：回抽不回中枢区间）。
- **两条铁纪律**（L20 原文明确）：
  1. **必须是第一次回试**——不是任何回调回抽都算三买，第二次回试已经不是三买结构；
  2. **三买后不必然是趋势**——也可能进入更大级别盘整（中枢扩张）。但两类情况都必然赢利：
     即使是盘整也有高点，**操作策略=一旦不能出现趋势，就在盘整的高点出掉**。
- 特点：三买比一买二买**后知后觉**，但不用浪费盘整时间，适合短线技术较好的资金。
- P3 讲中枢演化时已提前引用过三买定义（course-notes P3 节），本部分补足其定理地位与记号口径。

## 2. 买卖点完备性定理（L21，理论巅峰的核心论证）

> **缠中说禅买卖点完备性定理：市场必然产生赢利的买卖点，只有第一、二、三类。**

**论证（逐级收紧，注意每一步的排他性）**：

- 前提：走势中任何一个点，只面临两种可能——**延续或转折**（走势必完美的直接推论）。
- **买点必对应与该级别最靠近的一个中枢的关系**：
  - **中枢上的买点 = 延续**（上升趋势中）→ 只能是三买（中枢扩张或新生产生）；
  - **中枢下的买点 = 转折**，且只可能存在于**下跌与盘整**确立后的中枢下方 → 一买
    （盘整的中枢扩张/新生可以向下发展，不保证向上转折，所以"盘整中中枢下方"不必然是买点）。
- **关键推论（L21 原文）**：**一个上涨趋势确定后，不可能再有一买二买，只可能有三买**
  ——牛市回调买入的唯一正确姿势 = 等中枢上移后的回踩（三买），不要幻想"再等一个大回调抄底"。
- **二买的结构性安全**：一买后只能走盘整或上涨，两者都需 ≥3 段次级别运动（分解定理二）；
  一买后第二段次级别回调的低点 = 二买，其后**必然**还有第三段向上——安全由逻辑保证，
  不是概率。二买位置三分法（L21）：中枢下出现→力度可疑（大概率扩张性中枢）；
  中枢中→扩张/新生对半；**中枢上→新生（趋势）机会很大**。
- **二三买重合**（L21 思考题一的答案，唯一可能重合的组合）：一买后次级别**凌厉地直接上破
  前面下跌的最后一个中枢**，其上的次级别回抽不触及该中枢——此时二买与三买重合。
  实战含义：这种回洗（常很恐怖，如 1994 年 325 点后 8 月 1 日案例：一天半涨 50% 又半天回 15%）
  恰是**最好的补进机会**，其后往往是大级别上涨。
- **升跌完备性定理**（L21）：市场中任何上涨与下跌，都必然从三类买卖点中的某一类开始并结束
  ——整张走势图就是"端点为某级别三类买卖点"的线段连接。这是"完备"二字的最终含义：
  **不是三类之外还有别的点，而是除了这三类，理论上没有任何点被保证赢利。**
- "100% 安全"的准确理解：指**该点之后必然发生（对持仓方向有利的）转折/延续**，且理论给出
  预设退出机制（三买不出趋势→盘整高点出；一买失败→破位走人）。不是"买了就涨不停"。

## 3. 三类买卖点的再分辨（L53，把三类放回一张图里看）

**显微镜原则**（L53 前半，级别操作的元规则）：
- 用某级别（如 30min）观察操作时，**等于先把所有完成的次级别（5min）走势当成无结构的线段**
  ——次级别不在该级别的观察中。看 30min 三买涉及次级别判断时，才换 5min 显微镜。
- 与区间套不冲突：区间套是"背驰段内换大倍数精确定位"，显微镜原则是"平时只看一个倍数"。
- 知道**该在什么时候用什么倍数**，否则一下 30min 一下 1min 一下年线，把自己换晕。

**三类买卖点的分工与归结**（L53 核心）：
- **归根结底三类都可归到一买上，只是级别不同**——大级别二买=次级别一买（买点定律，
  P3 已引），三买在次级别图上同样是某个更低级别的背驰/转折结构。之所以不直接只说一买，
  是因为那样会同时混用多级别显微镜，实际操作更乱；**同一级别上三类各有意义，不能偏废**。
- **一买 = 该级别背驰点**（动力学出口，应付最大多数情况）；
- **二买 = 补充**，专门对付**小转大**（P4 L44）：小级别背驰不触及该级别一买时无须操作，
  等次级别向下后再向上的不创新高/低点（或盘整背驰）——小转大情况下二买就是最佳买点；
- **三买 = 对付中枢结束**：中枢结束后只有两条路（更大中枢 / 趋势直到新同级中枢），
  三买就是宣告"中枢结束了"的信号；
- **二三买之间 = 中枢震荡，没有该级别买卖点**（claim-20070523-001-a）——参与其中用的全是
  低级别买卖点。最干脆的做法：**不参与中枢震荡，只在预设的买卖点上买卖**；
  中枢震荡可参与但属于进阶（大资金/熟练者，利润大且稳），初学不碰。

# 六、第六部分讲义：分型 · 笔 · 线段（L62-83, 54-61）

> 进度：2026-08-31 已授（SKILL.md 进度记录同步更新）。
> 衔接自 P5：P5 讲完"买卖点完备性"，但此前所有讨论里的"中枢""走势类型"都建立在
> **"次级别走势"**之上——次级别走势在图上到底长什么样？P6 正面回答这个工程问题：
> 分型→笔→线段，把任意级别 K 线图**唯一、客观、当下**地分解成可逐笔核对的折线。
> 这是 P3 L35 所说"最低级别锚定"的完整落地，也是整个递归体系的地基。

## 0. 为什么 P6 是地基

- P1-P5 一直在讲"中枢=三段次级别走势重叠""走势类型递归"，但次级别走势本身长什么样是悬空的。
- L35 说最低级别用 1min/5min 三根重叠=中枢；P6 把这条补完：**任何级别的 K 线图，都能从分型开始唯一分解为 笔→线段→走势类型**。
- 一句话：**分型定转折点，笔连接相邻转折点，线段是构成中枢的最小走势单元**。

## 1. 分型（L62）

- **顶分型**：第 2 根 K 线的高点是相邻三根中最高的，低点也是相邻三根中最高的。
- **底分型**：第 2 根 K 线的低点是相邻三根中最低的，高点也是相邻三根中最低的。
- 顶分型的最高点=顶，底分型的最低点=底。**以后说"顶""底"专指分型的顶/底**——
  顶分型的底、底分型的顶无意义，不参与任何结构。

## 2. K线包含关系处理（L62/L65）—— 分型最大的麻烦

- **包含关系**：一根 K 线的高低点全在另一根 K 线的范围里。
- **处理规则**（只取极值，方向由前后走势定）：
  - **向上**时：高点取两K线最高者，低点取两K线低点中**较高者** → 合并（向上取"高"）
  - **向下**时：低点取两K线最低者，高点取两K线高点中**较低者** → 合并（向下取"低"）
- **顺序原则（L65 重点）**：包含关系**不符合传递律**——第1、2包含且第2、3包含 ≠ 第1、3包含。
  必须顺序处理：先用第1、2根确认新K线，再用新K线和第3根比……不能跳跃。
- 处理完，任何 K 线图都变成无包含关系的标准图形 → 分型定义才能唯一应用。

## 3. 笔（L62/L65）

- **定义**：相邻顶和底之间的连接 = 一笔。一定是**相邻**的顶和底（隔几个就不是）。
- **基本要求（结合律，L62 图3/4/5）**：
  - 顶和底之间**至少有一根 K 线**（最简笔 = 底分型+上升K线+顶分型）；
  - 顶底**共用一根 K 线**（图3）= 违反结合律，不算一笔；
  - 只有顶和底、中间无其他 K 线（图4），一般也不算一笔。
- **一顶一底原则（L65）**：从分型到笔必须一顶一底。
  - 两顶/底中间还有别的顶/底 → 只是把好几笔当一笔，按一顶一底原则继续拆；
  - 两顶/底中间没有别的顶/底 → 第一个顶/底转折级别太小，忽略。
- **唯一性**：所有图形唯一分解为上下交替的笔连接。比喻：**分型=膝盖，笔=大腿和小腿**。

## 4. 线段（L62/L65）—— 最小走势单元

- **定义**：至少由三笔组成；**且前三笔必须有重叠部分**（L65 特别强调——不是连续三笔就构成线段）。
- 线段只有两种：从向上笔开始的、从向下笔开始的。
- **笔破坏（L65 定义，用分型序列写）**：
  - 向上线段（d1g1d2g2…dngn）：存在 i、j，j≥i+2，使 **dj ≤ gi** → 向上线段被笔破坏；
  - 向下线段（g1d1g2d2…gndn）：存在 i、j，j≥i+2，使 **gj ≥ di** → 向下线段被笔破坏。
- **线段分解定理（L65）**：线段被破坏 ⟺ 至少被"有重叠部分的连续三笔"的其中一笔破坏。
  线段破坏的充要条件 = 被另一个线段破坏（破坏可以逆时间传递，L78）。

## 5. 线段划分标准（L67，最精确版本）

- S=向上笔、X=向下笔。
- **特征序列**：向上线段考察 X1X2…Xn（向下笔序列）——因 Xi 与 Xi+1 间不一定有重合，
  更能代表线段性质。特征序列相邻两元素间**没有重合区间 = 缺口**。
- **标准特征序列**：把特征序列元素当 K 线做包含处理后的序列。
- **分型两种情况（线段结束判据）**：
  - **第一种情况**：特征序列顶/底分型中，**第一、第二元素间不存在缺口** → 线段在该分型处结束；
  - **第二种情况**：存在缺口 → 必须再从分型最高/最低点开始的下一笔序列出现**反向分型**，线段才结束。
- 强调：出现特征序列分型是线段结束的**前提条件**；这是对"线段破坏=被另一线段破坏"的精确化。

## 6. 线段的标准化（L78）

- 线段有方向：以向上笔开始的一定结束于向上笔，**不可能从底到底或从顶到顶**；两端一顶一底，顶必高于底。
- 任何线段都是被后一线段破坏的（破坏可逆时间传递，L78）。
- **标准化**：把线段当无内部结构的基本部件，只看高低点——所有向上线段=最低点开始最高点结束，
  向下线段=最高点开始最低点结束。标准化后线段首尾相连成折线 → 为中枢/走势类型提供最标准构件。

## 7. 古怪线段（L78）

- 古怪的唯一原因：线段出现**第一种情况的笔破坏**后，最终没在该方向由该笔发展成线段破坏。
- 例：向上破坏笔完成后必接向下笔——若这个向下线段**破了**向上笔的底 → 原线段 B 未结束、在延续；
  若**没破** → 向上笔延伸成线段，线段 B 被破坏。
- 线段不可能被同方向线段破坏（同方向=延续或无关）。

## 8. 实战：L54 当下分解（小学毕业题）

L54 从 g0=18.5 逐点分解，示范"当下分解"全流程：
- 走到 g1：只有两段不成中枢 → 分笔操作者可视为**二卖**；
- 走到 d2：形成 1 分钟中枢 **[d1,g1]**，后续以该区间判断中枢震荡 or 三卖；
- g3 触及不到 [d1,g1] → **g3 = 三卖**；
- **分解多样性**：同一走势可有多种合法分解，选"当下有明确操作意义"的（中枢震荡 or 三类买卖点）；
- **纪律**：两个同级别中枢之间必须有次级别走势连接（不能直接拼两个同级别中枢）；
  三个次级别中枢重叠 = 高一级中枢（级别递归的落地）；
- 结论：能熟练对任何图形当下快速分解指导操作 = 缠论"小学毕业"。**分解必须符合规范，不能胡乱分解**。
