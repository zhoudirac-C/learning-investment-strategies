【分析前必须执行】按以下 UP 方法论六步检查清单逐项分析，不要跳过：

## 六步分析检查清单（UP 方法论）

### Step 1: 全A趋势结构（唯一锚）
- 全A指数处于趋势上涨/震荡/趋势下跌？
- 全A中阳线 = 唯一建仓确认信号，在此之前所有操作都是存量博弈
- 下跌模式：台阶式（有休整平台）vs 温水煮蛙式（连续阴跌无平台）

### Step 2: 大盘多级别顶底结构（空间判断）—— 仅用于大盘，不用于个股
- ⚠️ **MACD/九转/斐波那契数据只用于大盘（全A指数/上证指数）顶底判断，严禁用于个股分析**
- 从高级别到低级别检查：日线→120分钟→90分钟→60分钟→30分钟
- 使用 `macd_multi_tf_report` 中的实时MACD数据进行大盘顶底判断（见下方MACD判断规则）
- 使用 `td_sequential_report` 中的九转序列辅助大盘判断（见下方九转规则）
- 使用 `fibonacci_time_report` 中的斐波那契时间窗口辅助大盘判断（见下方斐波那契规则）
- 大级别优先：日线/周线顶部压制下，小级别底部只是反弹窗口
- 级别→时间对照：30min底=3天反弹，60min底=2天，90min顶=8天调整，120min双顶=4-6天
- **个股技术分析用：成交量、换手率、支撑位、压力位、K线形态、分时图——不要用MACD！**

**【MACD判断规则——本质是"价格和MACD谁先到顶/底"——仅用于大盘】**
核心：价格创新高但MACD（DIF）没跟上 → 顶背离（钝化）→ 结构可能形成
```
价格创阶段新高 + DIF未同步新高 → 顶背离（钝化中）→ 警惕，不操作
顶背离后 DIF下穿DEA（死叉）   → 顶部结构形成 → 减仓
钝化后 DIF重新上穿DEA         → 钝化消失 → 纠错买回
价格创阶段新低 + DIF未同步新低 → 底背离（钝化中）→ 观察
底背离后 DIF上穿DEA（金叉）   → 底部结构形成 → 可试错
```

**【九转序列判断规则——本质是"数数计数器"——仅用于大盘】**
定义：连续9根收盘价比4根前高=高9（超买），连续9根比4根前低=低9（超卖）
关键：**九转只告诉你涨/跌了多久，不告诉你方向变了没有。方向靠MACD判断。**
```
九转信号的有效性取决于大趋势方向（用MACD日线+全A趋势判断）：

| 大趋势方向 | 出现信号 | 含义 | 操作 |
|-----------|---------|------|------|
| 上升趋势 | 高9 | 容易失效 | 别追高，但别卖光。调几天可能继续上 |
| 上升趋势 | 低9 | 有效 | 回调到位，可作为买入标准 |
| 下跌趋势 | 高9 | 有效 | 反弹到位，应该卖出 |
| 下跌趋势 | 低9 | 容易失效 | 只是反弹不是反转，别抄底 |

高9+顶部钝化/结构 → 顶部确认，执行减仓
低9+底部钝化/结构 → 底部确认，可试错
双低9（90分钟低9+日线低9）→ 见底概率大
```

**【斐波那契数列判断规则——本质是"数天数闹钟"——仅用于大盘】**
定义：8,13,21,34,55——从关键高点/低点数到这些天数时注意变盘
```
- 距最近高点/低点接近8/13/21/34/55交易日 → 进入斐波那契时间窗口，变盘概率增大
- 两个以上斐波那契数同时到达（如21和55同时到期） → 双窗口共振，信号加倍
- 斐波那契时间节点 + MACD多级别结构 → 共振确认，最可靠
- 时间和空间只需确定一个：能确定空间（点位）就用空间，确定不了就确定时间
```

### Step 3: 三指数共振（广度验证）
- 检查主线指数、微盘股、全A三者是否同步？
- 微盘股/全A破位→会反压上涨板块→收缩战线

### Step 4: 量能验证
- 量能水平：>3.5万亿顶部 → 3万亿警戒 → <2万亿底部区域
- 首次地量≠地价，等第二只脚确认
- 量能新低+振幅新低=变盘临近

### Step 5: 情绪指标
- 跌停阈值：>50=恐慌 → <10=修复 → <5且无异常=做空释放完毕
- 双冰点（昨日恐慌+今日低开红盘<1000）→可基础仓位试错
- 情绪滞后：指数高点后情绪有2天滞后性
- 假摔判断：今日不强修复+明日强修复=假摔确认（两日组合判断）

### Step 6: 底部确认条件（仅当处于底部区域时）
- 真底部需满足两条件：①板块阵型完整（中军+先锋）②大资金进攻强度足够
- 底部构造节奏：急跌→反抽（2-3天）→第二只脚→底部确认

【以上六步分析完成后，按以下结构输出，不要省略：】
1. 综合判断：基于六步分析的综合结论（例如"日线顶部第N天+全A趋势下跌+微盘破位→调整未结束，等全A中阳线确认"）
2. 周期定位：当前处于冰点/回暖/高潮/退潮的哪个阶段？依据是什么？
3. 主线识别：当前市场核心主线是什么？支线有哪些？
4. 板块结构地图：把市场拆成三层——
   - 主攻层（科技算力硬件：光互连/CPO/PCB/半导体/存储等）
   - 上游层（涨价链：铜材/陶瓷基板/硫磺/存储等）
   - 防御层（电力/煤炭/红利等）
   - 其他题材（机器人/海风/军工等）
   板块 MUST 基于 external_sector_boards（东方财富/新浪等行情源的板块涨跌）构建，不能凭记忆编造。如果外部板块数据不可用，请明确说明并停止该部分分析。
5. 题材落地（针对当前阵眼的1-3个题材，每个写清楚）：
   - 催化：产业/政策/海外映射
   - 风险：内部分流、高位兑现、机构吹高
   - 相关标的：只列名称和逻辑角色，不给操作建议
6. 【机会扫描】基于当前市场阶段和方向优先级，扫描观察池中哪些标的出现买入信号：
   - 检查：价格接近entry_zone / 板块异动 / 技术面确认 / claims支持
   - 给出"今日最值得关注的3-5只标的"，按赔率排序
   - 每只必须包含：触发条件、赔率分析（错了亏多少/对了赚多少/赔率比）
   - 【强制规则】每个标的必须附带具体的介入价格区间（从watchlist的entry_zone中提取），禁止使用"等回踩""等分歧""逢低关注"等模糊表述。例如：❌"等分歧回踩" → ✅"回踩73-76区间可试探"
   - 如果标的已偏离entry_zone（如涨停已超区间上限），需明确说明"当前价格XX已超出介入区间XX-XX，等回踩后再评估"而非只说"不追"
7. 指数纪律：关键点位（如4033/4130）、突破/跌破条件、仓位纪律
8. 量能观察：成交额变化、缩量/放量含义、增量资金信号
9. 情绪指标：涨停家数、连板高度、跌停家数、炸板率
10. 明日推演/跟踪重点：明早可能的走势、需要盯住的变量
11. 持仓操作计划（仅当 positions 非空时）：针对每只持仓给出触发条件、失效条件、仓位控制建议，使用具体价格位
    - 特别注意：价格下跌到add_zone且逻辑没变 → 建议加仓，不是只写"持有"
12. 风险提示：当前最大风险点、仓位控制建议

**【大盘顶底数据（MACD/九转/斐波那契）使用规则——严格执行】**
- MACD/九转/斐波那契分析结果**不是独立段落**，必须融入【综合判断】和【指数纪律】中
- 例如：Step 2 分析得出"60分钟底背离+日线低9+21天斐波那契窗口共振"→ 写在【综合判断】里，不要另起"MACD结构"标题
- **个股分析（持仓/观察池）严禁使用MACD/九转/斐波那契**——个股技术看 成交量/换手率/支撑位/压力位/K线形态/分时图
