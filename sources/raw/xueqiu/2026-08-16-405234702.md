一、运价跟踪 （注意表中CCFI季度均值橙色之前是前推一个月均值，黄色为当季均值，7月开始切换成6月至今均值计算) 德鲁里全球集装箱指数上升了1%，达到每40英尺集装箱4,339美元。这一上升趋势是由于跨太平洋贸易路线的运费上涨所导致的。 在跨太平洋贸易路线上，本周的即期运价再度上涨。从上海到纽约的40英尺集装箱运费上升了10%，达到了8,706美元/箱；而从上海到洛杉矶的40英尺集装箱运费则上升了6%，为6,244美元/箱。各航运公司通过安排空舱来限制运输运力。据Drewry的统计在过去的两周里，每周都有10趟航次被取消，而下周还有7趟航次预计会被取消。德鲁里预计，由于运力得到控制，下周的运费波动幅度将会较小。 此外，多家船运公司宣布，自9月起，针 对亚洲至美国东部沿海以及亚洲至墨西哥湾沿岸的航线将收取巴拿马运河附加费 。 在亚欧贸易路线上，本周的运价有所下降。从上海到热那亚的40英尺集装箱运输费用下降了8%，现为5,080美元/箱；而从上海到鹿特丹的运费则下降了5%，为4,425美元/箱。据Drewry的统计下周只有三班空船航班，这一数字与上周相同，反映出运力依然紧张。与此同时，一些航运公司宣布了亚洲到地中海航线上的新运费标准：40英尺集装箱的运费在6,700美元到7,100美元之间，该标准将于8月15日起实施。不过，由于需求疲软，这些价格的持续性值得怀疑。Drewry预计下周的运费仍将保持稳定。 东西方集装箱运输市场依然波动不定： 苏伊士运河和霍尔木兹海峡的安全问题持续存在，巴拿马运河的通行也受到限制；“海豚”台风过后，亚洲港口出现拥堵状况；莱茵河水位过低，进而影响了整个欧洲的内陆运输。这些因素继续影响着船舶的航行计划以及供应链的稳定性。 各航运公司则通过控制运力以及收取附加费来试图维持自己的利润。建议托运人尽早预订，并留出更多准备时间，以此降低货物倾覆及运输延误的风险。 CCFI本周小幅上涨0.4%至1846.96 ， SCFI本周继续上涨2.41%至3355.24.今年SCFI二次上涨并突破前高的走势确实有点超预期了，看看会不会超过24年最高点3733.8（240705）. 2406-08月CCFI均值1988,2407-09月CCFI均值1990.87,24Q3归母净利润212.54亿 2409-11月CCFI均值1541.4,2410-12月CCFI均值1445.24,24Q4归母净利润109.76亿（Q4向来偏低） 2412-2502月CCFI均值1458.31,2501-03月CCFI均值1350.44,25Q1归母116.95亿 2603—05月CCFI均值1210.65, 2604-06月CCFI均值为1350.28。 2606至今CCFI均值为1749.19。 二、出口货量跟踪 全国重点港口上周的集装箱吞吐量（8.3-8.9日，每周一更新）环比下降9.04%至626.7万TEU.白海豚它来了。。 三、 德鲁里停航数据 东西向航运市场正处在转折点 旺季上涨势头开始有所放缓，但港口拥堵、天气扰动以及地缘政治风险，仍持续影响东西向集装箱航线市场的运力与运价水平。 在主要东西向航线上，预计第 34 周（8 月 17‑23 日）至第 38 周（9 月 14‑20 日）期间将执行 49 班空航取消（停航） ，取消率为 7%，仍有 93% 的计划航次正常运营。航次调整扰动主要集中在跨太平洋东行航线（占全部取消航次的 59%），其次是亚洲‑北欧 / 地中海航线（27%）以及跨大西洋航线（14%）。即便做出上述运力调整，船公司班期整体稳定性尚可；在各大航运联盟中，双子座联盟的空航取消率最低，仅为 1%。 受天气扰动持续影响亚洲枢纽港、港口拥堵进一步收紧运力、安全风险持续左右关键海上航道等多重因素，最新一期集装箱运力指数分析了上述因素对东西向集装箱市场造成的影响，以及未来数周内这些变化对货主托运人可能带来的启示。 四、 网页链接 { Linerlytica Week 2632（20年以后港口拥堵情况） } 港口拥堵的逻辑已经体现在了图上。。货量连年增长不说欧洲连兔子都已经开始要拥堵了 未来随着港口和陆侧达到容量瓶颈这里或者那里的拥堵是常态 这两天又看到论坛上某个大V拿着集运前十几年的利润率数据来证明集运的强周期，疫情后的这些利润都是狗屎运，呵呵一笑了之都没有争论的意义，再次提醒自己不在自己能力圈之内的东西不要妄加评论。 就算是狗屎运能连续踩到六七年那也绝对是祖上烧高香了。。。 网页链接 { 长滩港发布报告：7 月吞吐量创历史第二高水平 } 网页链接 { 闪耀的马士基与暗淡的赫伯罗特 -
