摘要 传统的 股息折现模型 假设折现率为常数。本文 提出一个修正框架：折现率不是常数，而是一条随时间变化的时间序列，反映各年社会平均收益率的真实波动。 未来某年股息的折现，需沿这条曲线逐年折现。基于这一修正，本文 引入“尺缩效应”概念——社会平均收益率在繁荣期升高、衰退期降低，导致所有资产的相对价值系统性重构 。本文进一步揭示，在投资收益率的三成分中，增长率是时间轴上最不稳定的变量，股息率是最稳定的锚，估值变化率是前两者的被动因变量。最后，本文论证 内在价值具有“时空二象性”——在时间轴上是全生命周期增长曲线的积分，在空间轴上是公司在社会经济坐标系中的比较优势 。 一、传统DDM模型的数学表达 传统股息折现模型假设折现率r为常数，股票的内在价值V等于未来所有股息的折现值之和： 四、投资收益率三成分的稳定性差异 4.1 增长率的波动 增长率在时间轴上极其不稳定 。公司的增长曲线g_t受行业渗透速度、竞争格局变化、宏观经济周期三重不可控因素的影响，任何公司都无法永续维持高增长。增长率的剧烈波动，使其成为投资收益率三成分中最不可靠的变量。 企业生命周期分为孕育期、婴儿期、学步期、青春期、盛年期、官僚期和死亡期，每个阶段的增长特征截然不同。内在价值的增长率不能线性外推，而必须考虑公司全生命周期增长曲线的变化。 4.2 股息率的稳定性 与增长率形成鲜明对比，股息率可以通过调整分红比例来主动管理。只要盈利和现金流不遭受毁灭性打击，稳定的分红政策能使股息率保持高度稳定。这是 “存量”思维 ——衡量的是公司已实现盈利的分配能力。 4.3 估值变化率的被动性 估值变化率ΔPE并非独立的自变量，而是被股息率和增长率的变化所驱动的因变量。 估值的变化，本质上是市场对“股息率+增长率”这个组合的重新定价。 此外，社会平均收益率 { r_t } 的变化—— 尺缩效应 ——也会直接影响ΔPE，因为 折现率的每次波动都重新定义所有资产的相对价值。 五、内在价值的时空二象性 5.1 时间轴：全生命周期增长曲线的积分 在时间轴上，内在价值是公司全生命周期增长曲线的积分，不是当前增长率的线性外推。 一个生命周期T年的公司，其内在价值由这T年间每一年的增长率和股息率共同决定 其中， 分子上的g_j序列构成公司的增长率曲线，分母上的r_i序列构成折现率曲线。两者交织，共同决定了内在价值在时间轴上的轨迹。 5.2 空间轴：比较优势的凝结 在空间轴上，内在价值是公司在整个社会经济坐标系中比较优势的凝结。即公司各年“增长率+股息率”与社会平均收益率的比值的加权积分： 比较优势越强、持续时间越久，内在价值越高。这就是价值投资“护城河”的数学表达。 六、结论 本文构建的变折现率DDM框架，将传统模型中的常数折现率替换为随时间波动的折现率曲线 { r_t } ，实现了 三个理论突破： 揭示了内在价值因折现率波动而剧烈变化，即使业绩稳定也不例外；提出了“尺缩效应”的数学表达——折现率下降时稳定回报资产的内在价值系统性提升；论证了股息率是时间轴上最稳定的锚，增长率是最不稳定的变量，估值变化率是被动因变量。
