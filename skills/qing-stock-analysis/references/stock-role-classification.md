# 个股板块地位判断机制与角色分类体系

> 记录 Qing Agent 如何判断个股在板块内的地位（龙头/中军/情绪载体等），
> 以及当前系统的数据能力边界和与通用"龙头战法"理论框架的对比映射。

## 一、核心结论（必读）

**当前 Qing Agent 判断个股地位的方式是：基于 UP 的历史观点（Neo4j 知识库），而非实时从网络获取板块数据计算。**

这是两种完全不同的逻辑：

| 维度 | 用户期望（实时计算） | 当前 Qing Agent 实际做法 |
|------|---------------------|------------------------|
| **数据来源** | 实时获取板块内所有股票数据，计算谁是龙头 | 查询 Neo4j 中 UP 对该股票的历史定位 |
| **判断逻辑** | 量化指标（涨幅、换手率、封板时间等） | 语义匹配（UP 曾经说它是"龙头""中军""情绪载体"） |
| **时效性** | 实时 | 历史（基于 UP 过去的观点） |
| **覆盖范围** | 板块内所有个股 | 只有 UP 提到过的个股 |

## 二、UP 知识库中的个股角色分类体系

通过 Neo4j 查询，UP 确实有一套完整的个股角色分类，但这些是**人工标注的定性标签**，不是算法计算的：

### UP 的个股角色词典

| 角色 | 含义 | 示例 |
|------|------|------|
| **龙头** | 板块内最强、带动效应最大 | 豫能控股（电力行情龙头）、盛美上海（半导体清洗设备龙头） |
| **中军** | 板块内大市值核心，稳定板块阵型 | 长电科技（先进封装中军）、长飞光纤（光纤中军）、拓普集团（机器人中军） |
| **情绪载体** | 短线资金聚焦的涨停标的，带动情绪 | 亨通光电（光纤情绪载体核心）、利仁科技（机器人情绪） |
| **趋势** | 机构主导的慢牛标的，非短线爆发 | 澜起科技（半导体趋势） |
| **活口** | 板块调整时唯一涨停或抗跌的标的 | 纬达光电（玻璃基板活口） |
| **铲子** | 卖铲人逻辑，受益行业扩产 | 盛剑科技（半导体铲子）、盛美上海（存储扩产铲子股） |
| **锚点** | 观察板块强弱的参照标的 | 江海股份（超级电容龙头锚点） |
| **先锋** | 率先启动的领涨标的 | 鹏鼎控股（PCB人气先锋） |
| **补涨** | 龙头涨完后跟涨的低位标的 | （无具体个股标注，但有"补涨分支"概念） |

### 关键方法论：地位是"打出来的"

UP 最核心的观点：

> **"自己打出来的地位"** —— 市场地位是资金持续进攻的结果，不是消息催化的一次性反应。

这意味着 UP 判断地位的标准是：
1. **持续主动引领**（非被动跟随）
2. **恐慌调整后继续进攻**（抗跌性）
3. **带动板块联动**（带动效应）

## 四、与"板块玩法+龙头战法"理论框架的对比

### 已覆盖的部分（UP 知识库中已有）

| 概念 | 通用理论框架 | UP 知识库覆盖 | 匹配度 |
|------|------------|-------------|--------|
| **板块分类** | 政策驱动/产业周期/顺周期/防御性/主题概念 | ✅ 有（AI算力、半导体、存储、电力等） | 80% |
| **板块轮动** | 经济周期驱动/资金流向/情绪周期 | ✅ 有（主线→分歧→一致→高潮→退潮→新主线） | 85% |
| **龙头定义** | 板块核心/资金共识/情绪引领/流动性 | ✅ 有（中军、辨识度、地位、卡位、情绪载体） | 75% |
| **龙头类型** | 总龙头/板块龙头/补涨龙头 | ✅ 有（龙头、补涨、中军、情绪载体） | 70% |
| **分歧/一致** | 分歧转一致是最佳买点 | ✅ 有（分歧后主动修复验证主线资格） | 85% |
| **买点** | 分歧转一致/低吸/买阴不买阳 | ✅ 有（买阴不买阳、等待分歧后的低吸机会） | 70% |
| **离场纪律** | 跌破均线/爆量跌停/题材退潮 | ✅ 有（纪律线清仓、破位减仓、不追高） | 80% |
| **仓位管理** | 单龙头≤30%/止损5%/退潮期空仓 | ✅ 有（5-7成仓位、清仓线、控制仓位） | 75% |

### 缺失/薄弱的部分

| 缺失概念 | 说明 |
|---------|------|
| **连板数体系** | 通用框架强调"首板→二板→三板成妖→五板定龙"，UP 很少用连板数定义龙头 |
| **龙虎榜分析** | 通用框架强调"龙虎榜机构+游资联手"，UP 几乎不分析龙虎榜数据 |
| **换手率量化** | 通用框架提到"换手率15%-50%"，UP 没有这种量化指标 |
| **涨停时间排序** | 通用框架强调"最早封板、封单量最大"，UP 更关注"竞价表现"和"盘中承接" |
| **监管停牌应对** | 通用框架提到"监管停牌核查"，UP 知识库中未涉及 |
| **板块成分股实时排名** | 系统无法获取板块内所有个股实时数据并排序 |

## 五、关键差距示例

### 当前 Qing Agent 的做法

```
用户问："中国长城在板块内是什么地位？"

系统查询 Neo4j：
- 找到 claim-20260426-012：润和软件是 CANN+鸿蒙+国产算力的软件机会
- 找到 claim-20260521-003-i：5月22观察池（没有中国长城）
- 结论：知识库中没有 UP 对中国长城地位的明确标注

→ 回答："知识库中没有 UP 对中国长城地位的明确标注"
```

### 用户期望的做法

```
用户问："中国长城在板块内是什么地位？"

系统：
1. 获取"国产算力"板块今日所有个股涨跌幅
2. 计算：中国长城涨幅 vs 板块平均涨幅
3. 检查：是否涨停？封单量？换手率？
4. 判断：涨幅前3 → 日内龙头；涨幅中等 → 中军；涨幅落后 → 跟风

→ 回答："今日国产算力板块中国长城涨幅+5.01%，排名第2，
         但板块龙头是XXX（+10%），中国长城属于中军地位"
```

## 六、建议（如需实现实时计算）

如果未来需要实现**实时计算个股地位**，需要：

1. **获取板块成分股列表**（如"半导体"板块包含哪些股票）
   - 可用东方财富板块成分股接口
2. **批量获取成分股实时行情**
   - 已有 `fetch_stock_quotes(codes)` 能力，需扩展为批量获取板块内所有个股
3. **计算排名指标**
   - 涨幅排名、换手率排名、封单量排名等
4. **结合 UP 的方法论规则**判断角色
   - 涨幅第一 + 带动板块 → 龙头
   - 涨幅中等 + 大市值 + 稳定 → 中军
   - 涨幅落后 + 跟随上涨 → 跟风/补涨

## 七、向量库适配情况

**当前向量库（基于 claim 文本嵌入）对这种炒股思路的适配：**

| 能力 | 适配度 | 说明 |
|------|--------|------|
| **语义搜索** | ✅ 良好 | "龙头""补涨""分歧""退潮"等关键词能命中大量相关 claim |
| **概念关联** | ✅ 良好 | Neo4j 的 ABOUT 关系能关联到板块、方法论、宏观节点 |
| **时序追踪** | ✅ 良好 | 可以按时间追踪观点演变（如 MLCC 从"涨价链"到"最强分支"到"追涨是韭菜"） |
| **矛盾检测** | ✅ 良好 | SUPERSEDES/CONTRADICTS 能捕捉观点变化 |
| **量化信号** | ❌ 不足 | 无法处理"换手率>15%""连板≥3板"等量化条件 |
| **实时行情** | ❌ 不足 | 向量库只存历史观点，不存实时涨停家数、封单量等 |

## 八、用户交互规范

当用户问"XX股票在板块内是什么地位"时：

1. **先查询 Neo4j**：检查 UP 是否对该股票有明确的角色标注（龙头/中军/情绪载体等）
2. **如果有**：直接引用 UP 的历史定位，并说明这是基于历史观点的定性判断
3. **如果没有**：
   - 说明"知识库中没有 UP 对 XX 地位的明确标注"
   - 提供该股票所属板块的近期 UP 观点
   - 说明当前系统无法实时计算板块内排名（缺少板块成分股数据）
   - 如果需要实时判断，建议获取板块成分股列表后计算
4. **区分"历史定位"和"实时地位"**：明确告知用户当前回答基于 UP 历史观点，非实时市场数据计算
