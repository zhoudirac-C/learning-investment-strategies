## 背景与共性错因

4 份提案来自 3 个错判日（10-15/10-16/10-22，盘前轨 10-15/10-16/10-22 均
stage_miss_premarket，收盘轨 10-15/10-16 stage_miss），三日真值均为「恐慌」，
而 v23 重跑（宏观簇 LLM 回归，见 macro-shock-adjudication 文末）仍未达真值。
剔除各案特异错因（cycle_state 单点锚定已由 v20 规则40 + 09-18 归因审计项 +
v23 规则40「无有效反弹周期」增补覆盖；10-15「外力扰动归因缺外盘数据支撑」
已由 v23 规则46(a) 覆盖）后，三案收敛为**同一个机制缺口**：

**market_stage 枚举含「恐慌」（truth.py STAGES 四选一、parse_result 合法值），
但全体系没有「恐慌」作为独立阶段值的正向判别口径。**

- 规则18（情绪极端日反向检验）管的是「判调整前必须回答三信号见底清单」——
  它是反向否决清单，只防「把该判震荡的极端日判成调整」，不回答「什么证据
  组合应从调整升级为恐慌」；
- 规则31 管 nature 归因三证据（外力/内生），不管 stage 二分；
- 规则28(c) 管「调整」需价格结构确认，方向是防「震荡误判调整」；
- glossary 无「恐慌」词条，sentiment_cycle 阶段模型（冰点/修复/高潮/退潮）
  没有「恐慌」位置——「恐慌」在概念层不存在。

三日的盘面证据各异（10-15 放量破位+无差别下跌 5107:430；10-16 封板率 55.45%
降 28pct+炸板 138 家；10-22 地量+破位+融资净流出被读成「存量调仓」），但
真值全部由**冻结阶段口径的价格幅度分支**命中：沪深300 20 日累计跌幅
10-15 = -8.89%、10-16 = -8.31%、10-22 = -9.91%（均 ≤ -8%）。三个输出的
共同点是**从未计算 20 日累计跌幅**，只用当日情绪/宽度读数在「调整」内部
消化（10-15 用「承接失败但接近极限」、10-16 用「情绪退潮」、10-22 用
「存量调仓」叙事缺省）。10-22 收盘轨当日判对「恐慌」（stage_reason 用
「主要指数收盘=区间低点破位+情绪极端」完成升级），证明判别可行——缺的
是步骤，不是能力。

**二分缺口的裁决答案**（什么证据组合从「调整」升级/区分为「恐慌」）：
判「调整/震荡」前先做恐慌候选检验，价格幅度口径优先——20 日累计跌幅
（收盘 vs 20 个交易日前收盘）≤ -8%，或「5 日跌幅 ≤ -4% 且量能趋势
（近 5 日均量/前 20 日均量）≥ 1.5」时，价格幅度已达恐慌口径，「恐慌」为
必选候选、默认判恐慌（除非当日放量强修复并写明不升级理由）；幅度未达标时，
情绪/宽度极端只作恐慌佐证特征，不得单独升级（单维度情绪恶化归「情绪退潮」，
极端日反向检验走规则18）。该口径与 truth.py 冻结阶段标签完全一致——这不是
新设阈值，是把评分所用的冻结 spec 写回 prompt（校准而非自拍阈值，区别见
「要点说明」）。

4 份提案证据支持同一机制（3 个独立错判日 ≥ 2 样本采纳标准）：
10-15-glossary 与 10-16-pattern/glossary 与 10-22-pattern 的归因分析文本
均指向「缺恐慌升级判别步骤 + 术语词典缺恐慌阶段」；10-22 提案的「并列候选」
表述与 10-15 提案的「强制升级」表述是同一机制的正反两面，合并为规则47
一条两段式（候选检验 + 升级默认 + 佐证边界）。

## 要点说明

### 规则47 恐慌阶段判别（10-15-glossary applied；10-16-pattern merged；10-22-pattern applied）

落点：`replay.py` _V24_RULE47 尾部追加 + validate_result 机械校验。结构：

- **恐慌候选检验前置**：判 market_stage=「调整」或「震荡」前，必须以 index 块
  收盘价序列计算两个幅度读数（①20 日累计跌幅；②5 日跌幅+量能趋势）。
- **幅度口径锚定沪深300（IDX000300）**：创业板指/科创50 属高波动成长宽基，
  20 日跌幅天然深于沪深300，单独不作恐慌口径依据。此锚定是回归实测教训——
  v24 初版未锚定指数时，10-14 对照日（沪深300 -7.48% 未达标、创业板 -14.7%）
  被模型取最深指数误升「恐慌」，同日修订规则47/盘前规则43/glossary 条文。
- **幅度达标默认恐慌**：20 日累计跌幅 ≤ -8%，或「5 日跌幅 ≤ -4% 且量能趋势
  ≥ 1.5」时「恐慌」为必选候选，默认判恐慌；唯一出口是当日放量强修复
  （收复 5 日均线/关键波段位）并在 stage_reason 写明不升级理由。
- **佐证不单独升级**：幅度未达标时，跌停扩散/无差别下跌/炸板率飙升/昨日涨停
  今收益深度为负只作恐慌佐证特征，不得单独升级恐慌——单维度情绪恶化归
  「情绪退潮」（glossary 既有定义），情绪极端日反向检验走规则18 三信号清单。
- **stage/nature 分层**：判「恐慌」日 nature 仍按六选一归位（恐慌阶段内可对应
  外力扰动/内生瓦解/方向转折/主动降速——nature 管当日性质、stage 管阶段
  位置），operation 按「趋势下跌」谨慎档处理、禁止左侧抄底。
- 与规则18 边界：18 管情绪极端日判调整前的反向否决清单（情绪口径），本条管
  阶段二分的价格幅度口径，**幅度达标时本条优先**——10-15 案例正是规则18
  「仅缺流动性见底→按接近极限磨窗口」的基准情形把恐慌日锁进「调整」的，
  规则18 的「很难比前一日更差」基线不适用于幅度已达标日。

### 机械校验（validate_result 规则47）

pack index 块含 IDX000300 且 bar 数足够（r20 分支 ≥21 根、r5/vol 分支 ≥24 根）
时，按与 truth.py 冻结 spec 完全一致的公式计算：r20 = 收盘/20交易日前收盘-1，
vol_trend = 近5日均量/前20日均量。幅度达标而 market_stage=「调整」即违规。
机械层只拦 stage=「调整」最高置信情形（沿用规则28「只拦最高置信」先例），
stage=震荡的候选检验由 prompt 条文约束。

**为什么是校准而非自拍阈值**（回应规则15 哲学）：-8%/-4%/1.5 不是从错判日
反推的——它们是 2026-08-08 冻结的 M1 盲测设计 spec
（docs/superpowers/specs/2026-08-08-m1-blindtest-design.md，truth.py 逐字
实现），market_stage 四个枚举值的评分依据本身就是该 spec；此前「震荡误判
调整」高发时，v18 规则28(c) 同样把「调整」的结构确认口径写进 prompt
（校准先例）。真正被挂起的是提案从单日盘面反推的情绪数值门（封板率<50%
等），那些既不在冻结 spec、也无多日样本支撑。

### schema 说明（任务关注点）

market_stage 的合法枚举 = （主升, 震荡, 调整, 恐慌）——「恐慌」本就是合法
stage 值（parse_result 硬校验通过），**不需要新增枚举值，也不需要 nature
新增「恐慌」值**（nature 六选一管当日性质，与 stage 分层，规则47 已写明
归位规则）。缺口纯在判别口径与概念层，故落点 = prompt 规则 + glossary 词条
