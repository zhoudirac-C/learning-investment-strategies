## 二、判据的正确理解

UP 原文最后六字是核心：「**二者缺一都只能算题材**」。

| | 国产化率低（空间） | 批量供货（时点） | 定性 |
|---|---|---|---|
| 有业绩支撑 | ✅ | ✅ | **可参与** |
| 题材 | 缺任一 | | 只作加分项 |

### 为什么在今晚提这个判据

```
风格切换完成（量价确认）→ 方向对了
    ↓
但级别只是「反弹不是反转」（无新叙事）
    ↓
∴ 只能用"个股业绩确定性"兜底
    ↓
国产化率低（空间）× 批量供货（时点）
```

**本质是"反弹级别"下的防御性选股工具**。
