# 模式提名：量能结构读法（不看总量看结构）

## 模式内容

1. **开盘半小时预估成交额**是全天的锚：预估打到 3 万亿后剩余时段缩了近 5000 亿，
   说明资金没有分析师乐观——结构比总量诚实。
2. 阈值框架：**3 万亿是反弹第一道坎（压力位），3.5 万亿是风险区**（逼近则风险倍数增长）；
   3 万亿以下待得越久，反弹时间跨度拉得越长。
3. 健康形态：从缩量启动走向温和放量；预估量急剧冲高后快速萎缩 = 密集抛压信号。

## 触发与动作

- 触发：每日 09:30-10:00 读取预估成交额与后续量能衰减速度。
- 动作：预估量触及 3 万亿 → 不追高；逼近 3.5 万亿 → 主动降风险；
  2 万亿附近的"整数关口企稳"需配合强势股补跌/多杀多观察，缺这两样关口不牢。
