# 2024-09-22 大杨能源笔记

本文是 山东黄金 上市以来数据分析系列文章的第二篇，即分析山东黄金A股股价与人民币金价（指上海黄金交易所Au9999的价格，以下相同）的相关性。 一、2003.8.28 ~ 2024.9.20 山东黄金 A股股价涨幅与人民币金价涨幅 二、股价涨幅/金价涨幅倍数计算方法1 股价涨幅/金价涨幅倍数（计算方法1）= 山东黄金 A股股价阶段涨幅 / 以产生股价最高点、最低点当天的金价最高点、最低点为准的人民币金价阶段涨幅 1、各阶段的股价涨幅/金价涨幅倍数计算表（未考虑产量增长，按计算方法1） 2、说明 山东黄金 A股股价最高点、最低点与人民币金价最高点、最低点通常不会产生于同一天，股价往往领先于人民币金价。 因此，计算方法1不能反映真实的涨幅倍数，逐调整为计算方法2重新计算。 二、股价涨幅/金价涨幅倍数计算方法2 股价涨幅/金价涨幅倍数（计算方法2）= 山东黄金 A股股价阶段涨幅 / 以产生股价最高点、最低点产生日期较近的金价阶段最高点、最低点为准的人民币金价阶段涨幅 1、各阶段的股价涨幅/金价涨幅倍数计算表（未考虑产量增长，按计算方法2） 2、说明 计算方法2能反映一个阶段的所有人民币金价涨幅，因此该方法比计算方法1更合理。但， 山东黄金 股价涨幅不仅仅与人民币金价相关，还与山东黄金的产量、利润等因素相关。 因此，逐再调整为同时考虑产量增长率的计算方法3重新计算。 三、股价涨幅/金价涨幅倍数计算方法3 - 最合理方法 股价涨幅/金价涨幅倍数（计算方法3）= 山东黄金 A股股价阶段涨幅 /（以产生股价最高点、最低点产生日期较近的金价阶段最高点、最低点为准的人民币金价阶段涨幅 *（1+产量增长率）） 1、2003~2024年 山东黄金 矿产金产量表 注1） 山东黄金 未披露2003~2007年的矿产金产量，因此我个人按如下方法推算2003年产量。 2003年矿产金产量 = 2003年矿产金营业收入 / 2003年人民币均价 ≈ 3吨 注2）2024年含按权益计算的 山金国际 产量的 山东黄金 矿产金产量预计数的计算公式如下： 山东黄金 2024年自身产量预计数39吨 + 山金国际 2024年产量预计数8.5吨 * 28.89% = 41.46吨。 2、各阶段的股价涨幅/金价涨幅倍数计算表（考虑产量增长，按计算方法3） 3、说明 （1）除现阶段之外的其他阶段的考虑产量增长的股价涨幅/金价涨幅倍数，相差不是很大，具体如下： 股价上一轮第1波上涨阶段（首日开盘~2008.1.9）的股价涨幅/金价涨幅倍数（考虑产量增长）：3.91 股价上一轮第2波上涨阶段（2008.9.11~2010.11.5）的股价涨幅/金价涨幅倍数（考虑产量增长）：4.76 股价上一轮整个上涨阶段（首日开盘~2010.11.5）的股价涨幅/金价涨幅倍数（考虑产量增长）：3.39 股价这一轮第1波上涨阶段（2014.7.9~2020.8.7）的股价涨幅/金价涨幅倍数（考虑产量增长）：2.06 股价这一轮第2波上涨阶段（2022.9.27~2024.9.21）的股价涨幅/金价涨幅倍数（考虑产量增长）：0.74 （2）以上能看出，2022.9.27~2024.9.21的股价涨幅/金价涨幅倍数（考虑产量增长），远远低于 山东黄金 上市以来其他各阶段的数据，让人深思。 造成这个结果的原因里面可能有大盘环境很差、资金面紧张、金矿股的估值普遍下降等等因素。但，需要思考的是，这种局面会一直持续下去吗？ 我觉得不会，从2022.9.27到未来 山东黄金 股价顶部之间的股价涨幅/金价涨幅倍数（考虑产量增长），我个人认为达到与这一轮第1波上涨阶段相同的2左右是比较合理的。 注）本文是 山东黄金 A股股价与人民币金价的相关性分析文章。实际上我个人是认为，山东黄金市值与利润的关联性更加重要，具体内容可阅读我在2024.4.24发表的 “ 山东黄金和紫金矿业历年利润与市值的关系 ” 文章。该文章的结论为，山东黄金2023年利润除以2003年上市首年利润的倍数，与2023年末山东黄金A股市值除以2003年上市首日开盘市值的倍数，刚好相同。 延伸阅读： 山东黄金和紫金矿业历年利润与市值的关系 $山东黄金(SH600547)$ $紫金矿业(SH601899)$ $山金国际(SZ000975)$ #黄金# 说明：以上都是对个人思考过程的记录，难免有差错和遗漏，不作为投资建议。
