# 修订'主动降速'术语适用边界

## 分析

错因核心在周期分歧的裁决环节与'主动降速'概念边界两处。具体数据项：(1) cycle_state 内部已存在三重警示——科创50 第9天超6-8天窗口、上证第17天严重超窗、上证/科创50 60min顶部divergence（09-04形成），仅创业板指第6天在窗口内；AI 依据规则28(b)以锚定指数（创业板指）在窗口内为由直接判'震荡/主动降速'，方法论缺少'多指数超窗+顶部背离时如何裁决'的环节——2/3指数超窗+双指数顶背离已是多数证据指向调整，却无加权、降级或强制预警步骤，规则28(b)的优先级被机械执行。(2) 情绪数据已被错误解读：涨停93→73家（-21.5%）、封板率83.04%→66.36%（单日-16.68pct）、炸板106家、连板高度6→4、龙版传媒断板未封——这5项中至少3项同时触达，AI 将其归因为'内生换龙'（结构内换龙头），而非'亏钱效应启动/退潮'，缺少'换龙假设与退潮假设的显式竞争检验'步骤。(3) 概念误用：'主动降速'被用于存在双指数60min顶背离+炸板激增量价背离的场景；主动降速的前提是结构完好、资金仅节奏性撤离，但 fund_flow 显示半导体-41.21亿净流出、工业金属+47.09亿的对冲性流入本质是高位兑现，属'被动调整'特征，术语适用条件（无顶部结构、无亏钱效应扩散）当时已不满足。(4) invalidation 条件（如'半导体净流出延续=主动降速未改'）被设为次日观察项，但盘前判断时半导体当日已净流出-41.21亿，缺少'失效条件反向预检'步骤——若预检就会发现部分失效条件已部分满足，应降级处理。信息差维度：宏观数据（美联储/油价）缺失属已知能力边界，AI 已在 stage_reason 中标注，非本次判错主因，仅作边界记录。

## 处置建议

在术语词典中为主动降速增加负面清单：存在指数级60min顶部divergence、≥2指数超周期窗口、炸板>100家或封板率单日降>15pct时，该术语禁用，统一改判'调整'；同时补充'主动降速'与'调整'的判别矩阵（资金性质=节奏撤离vs高位兑现、结构=完好vs顶部结构形成）。
