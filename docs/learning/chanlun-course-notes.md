# 三、第三部分讲义：走势终完美 · 中枢 · 级别（第17-22、35、38-40课）

> 进度：2026-08-23 开讲。缠论真正的骨架。学完本部分，均线系统退居辅助，一切概念获得严格定义。
> 用户前置疑问（已在此部分得到回答）：①级别是什么 ②60min反弹为何只有几天 ③为什么日线没背驰就只能当反弹仓。

## L17：走势终完美——哲学基石

**原理一**：任何级别的任何走势类型终要完成。两个方面：①任何走势最终都要完成；②完成后必然转化为其他类型（下跌完成只能转上涨或盘整）。
- 当下"延续还是转折"是无解的两难——理论不预测，只提供分类框架+转折关节点识别。
- **直接推出两类买卖点**：
  - 一买 = 下跌走势完成的关节点（下跌后只能转上涨/盘整，都对多头有利）；
  - 二买 = 一买后第一次次级别回调低点。安全性证明：上涨/盘整须含≥3段次级别运动（分解定理二），一买后已走两段，后面必然还有一段向上——安全性由逻辑保证非概率。
- **买卖点定律一**：任何级别二买由次级别一买构成（claim-20061205-001-a 出处）。
- **趋势转折定律**：任何下跌转折都由某级别一买构成（可能是多级别共振，不只次级别）。

**中枢首次定义**：某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。
- **盘整** = 完成走势只含 1 个中枢；**趋势** = 含 ≥2 个依次同向、互不重叠的中枢。中枢上移=上涨，下移=下跌。
- **原理二**：任何完成走势必含 ≥1 个中枢（无中枢=一次单向永动，仅退市可能）。

## L18：中枢的生住坏灭

- **延伸难题**：盘整可围绕中枢无限震荡，趋势可不断出新中枢（600519式长牛）。抓不住牛股=在第一个中枢被震下马；抄底噩梦=下跌延伸。根源都是不懂延伸何时结束。
- **判别唯一关键 = 是否产生新中枢**：盘整延伸=不产生新中枢；趋势延伸=同向新中枢不断产生；新中枢不再同向→趋势结束。
- **定理一**：趋势中连接两个同级别中枢的必然是次级别以下走势（可以是缺口；连接段级别越低力度越大——缺口技术含义的理论依据）。
- **定理二**：盘整中离开/返回中枢必为次级别以下——推论：真高低点总在盘中一闪而过，挂单必须提前挂。
- **定理三（破坏）**：次级别离开中枢后回抽不回中枢区间 = 破坏。最有力的破坏="趋势+盘整"（突破后盘整回抽确认，其后上涨有力）——"突破回踩确认"的严格化。

## L19：学习的关键

1. 推导如几何，从原理一二逐级证明，无先验假设（对比波浪理论5浪3浪的拍脑袋）。
2. 其他技术分析现象都能被解释并给出成立边界；庄家逃不掉基本结构。
3. 技术分析只是三大独立系统之一（技术面+比价+基本面），但是散户唯一公开、第一手、无先后差的信息。
4. 最终意义：不是预测市场要干什么，而是看清正在干什么——当下的直观。

## L20：中枢级别扩张与第三类买卖点

中枢后三种演化：①延伸 ②新生（新同向不重叠中枢→趋势）③扩张（波动区间重叠→更高级别中枢）。
- **级别延续定理一**：更大级别中枢产生前，该级别走势类型将延续。
- **级别延续定理二**：更大级别中枢产生 ⟺ 连续两个同级别中枢的波动区间重叠。
- 大白话：趋势/盘整要"真的结束"，看到更大级别中枢形成才算数；级别不可跳跃。
- **第三类买卖点定理**：次级别向上离开中枢+次级别回试低点不跌破ZG（中枢区间上沿）=三买；向下镜像=三卖。纪律：必须是第一次回试；三买后不必然是趋势（可能更大级别盘整），不出趋势就在盘整高点兑现。

## L21：买卖点完备性

- 三类之外无其他被理论保证的买卖点（claim-20070109-001-a）。论证：任一点只有延续/转折两种可能→延续买点在中枢上方（三买）、转折买点在中枢下方且只在下跌确立后（一买及派生的二买）。
- **上涨趋势确立后不可能再有一买二买，只可能有三买**——牛市回调买入的正确姿势=等中枢上移后的回踩。
- "人使理论，而非理论使人"。

## L35：级别的递归本质

- 解决循环定义（走势类型↔中枢互相定义）：最低级别锚定（实操=1min或5min K线，三根重叠=最低级别中枢）→ 逐级"三个连续次级别走势重叠=高一级中枢"上推。
- 实操简化口径（缠师钦定）：三个1min走势重叠≈5min中枢，三个5min≈30min……1/5/15/30/60min、日、周、月、季、年。
- 回答用户"级别是什么"：级别=递归结构层级；周期表是工程近似；相邻级5~6倍时长感来自"三个次级单位合成一个本级单位"。

## L38-39：同级别分解——机械化操作

- 选定固定级别把所有走势切成该级别走势类型连接，分解唯一。规则：只做上涨+盘整段、回避下跌段；永远只盯当前正在完成的一个中枢；该级别允许盘整+盘整（非同级别分解视角不允许，勿混）。
- 不问牛熊："30min上涨就是牛市，否则熊市"。机械化利润与时间成正比。
- 韵律纪律：向上段先买后卖、向下段先卖后买；一步错了唯一正确选择=停止操作调好韵律再来。
- L39后半a+A序列Ai/Ai+2盘整背驰法：全书最难啃段落，初学允许跳过，实战需要再精读。
- 用户skill映射："60min定入场时机"本质=同级别分解视角；P3后可升级为显式"中枢标记→分类状态→预案"流程。
