# 2026-05-26 宁静的冬日M

我们于5月19日在亚洲沟通与科技平台上接待了长城汽车股份有限公司管理层。讨论的主要议题包括:1)新产品发布规划;2)销售目标保持不变，即2026年实现180万辆的交付量;3)预计毛利率将环比上升，同时有多种方法可优化成本;4)海外扩张计划。 关键要点: 新车型发布计划: 公司计划今年推出11款新车型，其中大部分为基于成本效益高的归元平台开发的新车。魏牌品牌V9X已于5月18日正式发布，公司预计月销量为5000辆。 销售目标: 公司计划在2026年实现总计180万件的销售额，其中120万件为国内市场销售，60万件为出口。1至4月份的出口量为18万件，全年出口目标进展顺利。然而，国内需求明显疲软，公司销售额同比下降了约10%，据管理层表示，这主要是由于行业整体需求放缓以及去年同期基数较高所致。到2030年，公司目标实现总计300万件的销售额，其中100万件将来自海外市场。 毛利率展望: 公司预计在 2026年第二季度和第三季度毛利率将逐季改善 ，随后在第四季度出现下降。 成本优化策略 :为减轻原材料价格上涨带来的影响，公司今年推出了基于归元平台的新车型。该车型的设计 旨在实现显著的成本降低与高一致性 ，相较于非归元车型， 有望将成本降低50% 。公司还通过在单一基地集中生产来优化成本，从而实现了供应链本地化，并由此实现了约30%的成本削减。此外，公司还将共用零部件的比例从50-60%提升至80% 海外扩张: 公司预计今年在俄罗斯将实现两位数的增幅，这主要得益于市场复苏和市场份额的扩大。同时，公司预期欧洲销售额将从较低水平实现十倍的增长。此外，右舵车市场(涵盖东南亚、澳大利亚和新西兰等地)占出口总量的25%。其他关键地区还包括南美(巴西)以及中东地区。 海外库存水平依然较低，大约为两个月的量(包括途中车辆) 。根据公司所述， 海外单车利润范围在人民币10000至人民币20000之间 ，这受到汇率和产品组合波动性的影响。截至当前时间的出口数据显示动力系统组合中ICE车辆占比60%至70%、HEV占比20%至30%、NEV占 比 10%至20%。 $长城汽车(02333)$
