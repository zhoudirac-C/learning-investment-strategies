# 2025-05-23 大杨能源笔记

“矿产金毛利占总毛利比率”，代表一家金矿股的矿产金业务在整体业务当中所占比重大小，也同时代表黄金价格的变动对利润的弹性大小。 矿产金毛利占总毛利比率（以下简称为“矿产金毛利占比”） =（矿产金营业收入 - 矿产金营业成本）/（总营业收入 - 总营业成本）* 100% 一、14家金矿股的2024年度矿产金毛利占比统计表 二、对9家金矿股矿产金毛利占比情况的说明 1、 山东黄金 （1） 山东黄金 的矿产金毛利占比（含 山金国际 数据），2024年为86.48%，2023年为88.81%，2024年同比下降2.33个百分点。 （2） 山东黄金 2024年自身（不含 山金国际 数据，但含因无法准确计算而不能去掉的存货评估增值的摊销）的矿产金毛利占比为89.21%，去掉存货评估增值摊销后的自身矿产金毛利占比肯定会超过90%。 （3） 山东黄金 的2022年矿产金毛利占比为92.74%，在2023年收购 山金国际 的控股权后，后面年度的矿产金毛利占比因受到山金国际的合并影响小幅下降。 2、 山金国际 （1） 山金国际 的矿产金毛利占比，2024年为80.04%，2023年为77.16%，2024年同比上升2.88个百分点。 （2）2024年黄金价格涨幅超过银、锌等金属的价格涨幅，因此 山金国际 的2024年矿产金毛利占比同比上升。 3、 紫金矿业 （1） 紫金矿业 的矿产金毛利占比，2024年为31.78%，2023年为26.33%，2024年同比上升5.45个百分点。 （2）2024年黄金价格涨幅超过铜的价格涨幅， 紫金矿业 的2024年矿产金毛利占比同比上升。 4、 赤峰黄金 赤峰黄金 的矿产金毛利占比，2024年为94.67%，2023年为95.94%，2024年同比下降1.28个百分点，变动幅度不大。 5、西部黄金 （1）西部黄金的矿产金毛利占比，2024年为27.88%，2023年为-28.16%，2024年同比上升56.04个百分点，变动幅度很大。 （2）西部黄金的2023年矿产金毛利为负数，因此2024年矿产金毛利占比同比上升很多是没有什么意义。 （3）西部黄金的2024年矿产金毛利占比27.88%，与2022年矿产金毛利占比26.52%相比较变动不大。 6、 中润资源 （1） 中润资源 的矿产金毛利占比，2024年为98.88%，2023年为-240.78%。 （2） 中润资源 的2023年总毛利和矿产金毛利均为负数，因此2024年矿产金毛利占比同比大幅上升没有分析的意义。 7、 四川黄金 四川黄金 的矿产金毛利占比，2024年为99.72%，2023年为99.998%，一直保持非常高的水平。 8、 灵宝黄金 灵宝黄金 虽然披露矿产金营业收入，但未披露矿产金营业成本。按採礦分部溢利占採礦分部和冶煉分部溢利合计的比率，2024年为95.84%，2023年为101.36%（2023年冶炼业务亏损）。 9、万国国际矿业 万国国际矿业的矿产金毛利占比，2024年为66.30%，2023年为53.91%，2024年同比上升12.39个百分点，变动幅度较大。 三、总结 1、2024年报上的矿产金毛利占比披露情况 14家当中，根据已披露数据可自行计算矿产金毛利占比的是，上面“二、说明”中列出的9家公司（即， 山东黄金 、 山金国际 、 紫金矿业 、 赤峰黄金 、西部黄金、 中润资源 、 四川黄金 、 灵宝黄金 、万国国际矿业）。 14家当中，无法根据已披露数据自行计算矿产金毛利占比的是， 中金黄金 、 湖南黄金 、 招金矿业 、 中国黄金国际 （只披露了長山壕礦的黄金毛利，未披露甲瑪礦區的黄金毛利）等4家公司。 恒邦股份 ，因尚未投产，无矿产金相关数据。 2、矿产金毛利占比高低排名 根据已披露数据可自行计算矿产金毛利占比的9家当中，数据最高的是 四川黄金 （99.72%），第二名是 中润资源 （98.88%），第三名是 灵宝黄金 （95.84%），第四名是 赤峰黄金 （94.67%）。 说明：我是从2022年开始写14家金矿股的系列文章，当时找到了14家。后面发现我漏掉了 鹏欣资源 ， 白银有色 ， 晓程科技 、 玉龙股份 等几家金矿股。但由于这个系列文章一般包含跟以前年度的比较分析内容，后面也没有把这几家公司包含进来。 延伸阅读： 1、 网页链接 { 14家AH金矿股比较系列1 - 矿产金单位销售成本 （2024年度及2025年Q1） } 2、 网页链接 { 14家AH金矿股比较系列2 - 矿产金毛利率（2024年度） } $山东黄金(SH600547)$ $四川黄金(SZ001337)$ $赤峰黄金(SH600988)$ #黄金# 说明：以上都是对个人思考过程的记录，难免有差错和遗漏，不作为投资建议。
