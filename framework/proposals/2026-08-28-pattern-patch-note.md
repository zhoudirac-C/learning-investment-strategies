# 增加隔夜映射的竞价验证步骤

## 分析

预判基于隔夜NVDA+8.74%、费半+2.33%正面映射，以及昨日成交额21259亿环比+17.5%、涨停77家封板率81.9%等数据，但实际芯片当日收益-5.74%、基准-1.33%，说明推理链条缺失两个关键步骤：一是未验证隔夜利好是否在A股竞价/开盘后真实承接，二是未设置盘中量能持续性的再确认阈值。同时概念上出现冲突：既称'放量攻击'又称'存量调仓（银行流出流向科技）'，存量调仓意味着无增量资金，量能放大不可持续，放量攻击定义被误用；且将上证已反弹9天与科技主线刚启动简单锚定，未将高位品种补跌风险纳入推演。

## 处置建议

在'外部链条检验'后，加入开盘前15分钟竞价量价与板块资金流向验证；若高开低走或净流入转净流出，则推翻原判。
