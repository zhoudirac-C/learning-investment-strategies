### 二、方法论（可复用判据）

| # | 观点 |
|---|---|
| 002-c | **放量有效性三重验证**：放量只有与**价格承接、板块广度同时改善**才更接近有效突破。观察基准=上周五同时段成交节奏，看**高开首次回落是否缩量、回升是否有主动成交、成交是否扩散到领涨板块**。反例：早盘预估量很高随后持续下修 + 指数反复冲高回落 = 震荡市典型特征 |
| 002-d | **区分盘中预估与收盘实际**：前者反映当时节奏，后者才是全天结果，不能把不同时点的预估值当成已成交金额 |
| 002-e | **权重支撑 ≠ 整体赚钱效应**：银行/券商/保险与科技配合 → 上行基础更完整；只靠少数权重拉升而多数个股、涨停数、科技核心同步转弱 → 指数表面强势要打折看待。**材料不足以确认券商保险强弱时，不预设它们已领涨** |
| 002-f | **情绪修复质量看个股参与家数**：价格上涨能否伴随更多个股参与，比指数单独抬升更能说明修复质量。情绪改善可作为**提高关注度**的理由，不能直接视为全面主升确立 |
| 002-g | **震荡环境中的趋势信号纪律**：趋势信号易反复上穿下穿，执行上要**接受信号可能失败**，同时避免因担心失败就随意改动事先确定的确认标准 |
| 002-i | **盘中与收盘两个层次不混用**：盘中观察用于**识别领涨方向**，收盘结果用于**触发仓位纪律**；量价质量不能被临时改成另一套仓位触发标准 |
| 002-m | **情绪指标分母口径须一致**：不同晋级率的分母、统计时点、新股纳入口径应保持一致，不能简单混为一个市场强弱指标 |
| 002-q | **人民币贬值受益不能推广到所有医药纺织企业**：9/18 人民币即期汇率盘中双双升破 6.70，与机械套用贬值逻辑不一致。各公司结算币种、海外成本、套保安排、汇兑损益不同，须回到实际敞口 |
| 002-t | **海外科技上涨不能直接折算为 A 股必然补涨**：不同市场估值、资金结构、产业映射有差异。存储链/算力硬件/光互连若开盘联动并在第一次分歧维持承接，外部映射才有交易意义；只有少数个股高开随后迅速回落 → 先按消息兑现观察 |

| # | 观点 |
