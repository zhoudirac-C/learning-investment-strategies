## 自查

- [ ] 每个假设能被明确回答"对或错"，不是"可能吧"
- [ ] 每个假设至少有 1 个一级信息 + 1 个二级信息支撑（三级信息只能用于情绪判断）
- [ ] 置信度有基准率支撑（查了历史类似案例，不是拍脑袋）
- [ ] 写完置信度后反问："100 次类似情况会对 __ 次——我真的相信吗？"
- [ ] 每个假设有明确的兑现时间窗
