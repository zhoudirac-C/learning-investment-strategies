## 二、三类核心图型（8/26 已验证的参数）

### 1. 中枢图解（用户拿 512400 实测纠错过）
- K线用细线表示高低点即可，叠加中枢 Rectangle + 笔折线
- **中枢严格口径**：ZD=max(三段低点)、ZG=min(三段高点)。512400 手算 [1.753,1.851]，
  但算法输出 [1.849,1.851]（相邻笔重叠分组不同）——图上必须标注用的是哪种口径，
  且强调"中枢边界附近不作精确挂单依据，位置和方向才可靠"
- **陷阱**：矩形不要框进"离开段"（曾把 [1.75,2.03] 整个框进去被用户抓错）。
  中枢矩形只覆盖三段走势的公共重叠区，离开段单独标注
- 教学标注序列：①下跌结束→②回抽不创新低（ZD）→③离开（ZG 上方）→④第一次回试不回中枢
  （=破坏，定理三，画星号强调）→⑤再离开

### 2. 背驰图解（A-B-C 结构 / 实战案例）
- 面板3 用真实案例最有说服力：517520 日线 8/24 顶背驰（价格新高 2.36 + 红柱面积
  0.28 < 0.90×0.9）——红线画价格(右轴)、柱画 MACD(左轴)
- **双轴箭头坐标换算（本次最大坑）**：annotate 的 xy 用的是主轴(ax)坐标系，
  但价格曲线画在 twinx (ax3b) 上。直接传价格数值 → 箭头指到 0 轴附近而不是价格高点。
  必须换算：
  ```python
  ylo, yhi = ax.get_ylim(); plo, phi = axb.get_ylim()
  def to_ax(y): return ylo + (y-plo)/(phi-plo)*(yhi-ylo)
  ax.annotate(txt, xy=(x, to_ax(price_high)), ...)
  ```

### 3. 笔区间面积图解（用户问"背驰的笔区间怎么算"时用）
- 用 axvspan 给两段同向笔加底色带（绿=前段、红=后段），白底数值框标注各自 |hist| 面积和
- **必须演示"未创新低 ⇒ 不构成比较"的反例**：512400 的 7/23→8/3(0.14) vs 8/11→8/14(0.22)
  面积不萎缩但价格未创新低——两个条件缺一不可，这是教学重点

## 三、标注布局通用纪律（v1 全踩过，v2 才修好）

1. **标注文字必须收进轴内**：xytext 用数据坐标时要留足 ylim 空白；标题用 `pad=12`，
   标注 y 值超出 ylim 会直接压/顶到标题上（面板1/2 的错）
2. **白底框隔离背景**：标注压在 MACD 柱/密集K线上时加
   `bbox=dict(boxstyle='round', facecolor='white', alpha=0.9, edgecolor=...)`
3. **多面板用 gridspec + hspace=0.4+**，防止相邻面板标题与标注互撞
4. **合成数据面板**（A-B-C 示意、小转大示意）用 `rnd=random.Random(seed)` 生成，
   但面板3 必须换真实数据——用户对"教学用你的持仓真实数据"有明确偏好

## 四、交付前强制视觉自检（用户 8/26 明确要求"检查你画的图"）

先自检再发 MEDIA:，检查清单：
- 标注与标题/图例是否重叠、是否越界
- **双轴图箭头是否命中正确位置**（最常见错误）
- 中枢矩形是否精确覆盖公共重叠区（不含离开段）
- 有无承诺但没画出来的元素（v1 的面板3 面积框就缺了）

自检用 vision_analyze；**注意 stealth/ox-alpha 上游 429 限流**——失败后
`sleep 90-180` 重试，偶发 JSON 解析错误同样重试；同一张图改完要二次自检。
