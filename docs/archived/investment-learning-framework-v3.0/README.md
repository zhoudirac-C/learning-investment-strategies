# investment-learning-project

投资学习项目：从产业链分析到落地执行的学习框架与配套模板。

## 定位：与仓库其他体系的分工

本仓库有两套互补的体系：

| 体系 | 管什么 | 位置 |
|---|---|---|
| **本目录（学习框架）** | "人"的学习路径与交易纪律：32 周学习计划、双路径隔离、仓位规则、交易日志、复盘、校准 | `investment-learning-project/` |
| **skill/知识管线** | "机器"的知识管理：raw 文档入库、claim 观点卡、wiki、方法论复盘自动化 | `skills/qing-learning*/`、`knowledge/`、`framework/` |

两者通过一条桥连接：学习框架中的手工"假设清单"验证结束后，可转写为 `knowledge/claims/` 的 claim 卡进入机器可审计体系（映射关系见框架 3.5 节）。

框架正文第〇节列出了各模块与仓库深度方法论资产（`methodology/`、`framework/`、`docs/`）的引用关系。

## 文件索引

- `investment-learning-framework.md` — 框架正文 v3.0（项目目标、双路径原则、三大模块、32 周学习路径、校准机制、工具包、红线）
- `templates/` — 可直接复制填写的产出物模板：
  - `hypothesis-list.md` — 假设清单（数值置信度 + 基准率 + 时间窗）
  - `trade-plan-path-a.md` / `trade-plan-path-b.md` — 双路径交易计划
  - `trade-log.md` — 交易日志（含仓位/止损/单笔风险三数值与情绪自评）
  - `weekly-brief.md` — 周度产业跟踪简报（30 分钟时间盒，1 页约束）
  - `premortem.md` — 事前验尸（建仓前）
  - `monthly-review.md` — 月度复盘（过程/结果双评分 + 错误分类统计）
  - `calibration-tracker.md` — 季度校准跟踪表

## 快速开始

1. 读 `investment-learning-framework.md` 第〇–二章；
2. 按第六章"阶段一"逐周执行，产出物直接复制 `templates/` 对应模板填写；
3. 每周末 30 分钟写周简报，每月末写月度复盘，每季度做校准统计。

**免责声明**：本目录全部内容仅用于学习投资研究方法，不构成任何投资建议。
