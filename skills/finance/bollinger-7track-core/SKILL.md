## 核心框架（先看这个）

1. **与标准布林带的唯一区别**：DEV 用 **5 日标准差均值** `MA(STD(C,N),5)` 替代原始 STD——平滑极端波动。轨道扩到 ±3×DEV 共七层。

2. **七轨定义**（N=20 缺省）：

| 轨道 | 公式 | 含义 | UP 操作口径 |
|------|------|------|------|
| 顶轨 | MID+3×DEV | 极端超买/超强 | 大概率回调；顶出上轨后炸板=止盈离场（claim-20260521-002 北方华创案例） |
| 一轨 | MID+2×DEV | 中度超买 | 考虑减仓 |
| 二轨 | MID+1×DEV | 强势股调整位 | **核心介入位**："回调到二轨可再次介入"（磨底期强势科技股做二轨接，跌破就走，claim-20260604-004） |
| MID | MA(C,20) | 趋势分水岭 | 强势股沿中轨持有，破2-3天不拉回离场 |
| 四轨 | MID−1×DEV | 弱势调整位 | 偏弱股回调到此，观望 |
| 五轨 | MID−2×DEV | 中度超卖 | 分批建仓 |
| 底轨 | MID−3×DEV | 极端超卖 | 大概率反弹 |

3. **三种实战打法**：
   - **强势股打法**：底轨冲到顶轨→自然调整→回踩**二轨不破**继续持有/加仓；回到四轨则定性偏弱改观望
   - **收敛股打法**：长期横盘波动收敛（约20%内），突破顶轨放量跟进
   - **N字启动**（主流）：首板涨停→次日不板则等回踩二轨→做第二波
   - 纪律：**二轨接过必须有失效条件**（跌破二轨即走/破位清仓），价格给具体区间

4. **配合信号**（单独布林信号不下结论）：高档长红线+摸顶轨=减仓；低档长红线+底轨/五轨=试探建仓；收敛后放量长红线破顶轨=跟进

5. **与缠论联动**（claim-20071203-001 / claim-20071227-001，缠师原文口径）：
   - 上/下轨之外运行=超强状态；涨回轨内再创新高但不回超强区 → 中阴 → 第一类买卖点辅助判断
   - **布林收口预判中阴结束**：某级别收口 = 低一级别中阴将结束，对应三类买卖点；技巧是看大一到两级的通道（5min 中阴看 30min 布林）

## UP 实战案例（claim 编号索引）

- claim-20260521-002：北方华创顶出上轨炸板止盈、回二轨再接——趋势龙头技术交易模板
- claim-20260604-004：磨底期科技方向"二轨接"选股法（前提有利润垫）
- claim-20260827-001：原油破中轨 + 恐贪指数 → 追空赔率框架（中轨作为趋势参考的例子）

## 算法管线（scripts/boll7.py 已实现）

1. 取K线（日线/分钟线，降级链同 chan_analysis.py：新浪/腾讯 → TDX → stale）
2. MID=MA(close,N)，STD0=STD(close,N)，DEV=MA(STD0,5)
3. 七轨 = MID ± {3,2,1}×DEV
4. 信号判定（最新 bar）：
   - 位置归类：超买区(>一轨)/强势区(顶~二)/中轨带/弱势区(<四)/超卖区(<五)
   - 二轨测试：近 K 根 low 触及二轨但 close 收回 → "二轨支撑有效"
   - 破位：close 连续 M 日 < 二轨 → 二轨失守（强势股打法失效条件触发）
   - 收敛度：带宽 (顶轨−底轨)/MID 百分位 → 收敛/常态/发散
   - 输出各轨具体价位（precision：给区间不给"附近"）
5. 打法标签：结合位置+收敛度提示适用打法（强势/N字/收敛/超卖反弹）

## 用法

```bash
python3 boll7.py sh512400 sz159381            # 日线七轨
python3 boll7.py --30m sh512400               # 30分钟
python3 boll7.py --n 20 --fresh sh512400      # 自定义周期参数
```

输出：七轨价位表 + 最新收盘所处轨道区 + 二轨/中轨测试结论 + 收敛度 + 适用打法标签。
所有结论附数据基准时间；盘中 stale 缓存时打警告。

## 坑位

- DEV 是平滑后的 STD（MA5），比原始 STD 滞后但稳——勿改成纯 STD 复现不出 UP 口径轨道值
- 二轨"跌破就走"以 close 为准，影线刺穿不算破
- 分钟线用七轨意义弱于日线（UP 打法默认日线级别），分钟线只做入场时机微调
