## 验证优先级（从高到低）

1. **B站动态标题**（当天同期）— UP 经常在股票异动时发单独动态（如「XX拉直线的原因」），这是最高置信度来源
2. **本地知识库交叉引用**（claims/wiki/raw）— 搜索 UP 之前视频中提及的方向/标的来反推
3. **腾讯财经API**（`qt.gtimg.cn`）— 用疑似股票代码查询，确认名称是否存在
4. **逻辑一致性检查** — 若转录语句逻辑不通，反向思考正确含义，向用户确认

## 常见逻辑反转案例

- ❌ 「外盘不崩则国内好不到哪去」 → ✅ 「外盘崩了则国内更扛不住」
- 原因：UP 论点链是「国内估值 > 外盘估值 → 外盘崩 → 高估值国内先跌」，语音转录的「不」字可能是误识别

## 充电视频处理流程

1. 读取录音转录全文，逐段标记疑似错误
2. 并行执行三条交叉验证路径（B站索引 / 本地知识库 / 术语体系）
3. 输出「转录纠错对照表」追加到 raw 文档末尾
4. 走完整 qing-learning ingestion 流程
