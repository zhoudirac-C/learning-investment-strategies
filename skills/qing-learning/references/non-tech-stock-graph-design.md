# Neo4j 非科技方向股票图谱设计

> 适用场景：将研报中的机构推荐股票入库，使 Qing-Agent 能通过图遍历检索特定方向的全部标的。
> 会话来源：2026-06-06，UP 6/4 充电视频要求整理1-5月非科技方向机构推荐股票。

## 图结构

```
┌──────────────────────────────────────────────────────────┐
│                   ResearchReport (研报)                    │
│  研报：26-04-20：旭创Q1超预期、大金重工全链条...           │
│  共约15篇非科技方向研报                                     │
└──────┬──────────────────────────┬────────────────────────┘
       │ COVERS                   │ RECOMMENDS
       ▼                          ▼
┌──────────────┐          ┌──────────────────┐
│  Theme/方向   │◄────────│     Stock/个股     │
│  燃气轮机     │ BELONGS │  杰瑞股份(002353)  │
│  储能/六氟     │ _TO     │  大金重工(002487)  │
│  风电         │         │  天赐材料(002709)  │
│  消费         │         │  ...~80个标的      │
│  创新药       │         └────────┬─────────┘
│  出海链       │                  │ MENTIONED_IN
│  商业航天     │                  ▼
│  蓝筹         │          ┌──────────────────┐
│  新能源装备   │          │     Claim          │
│  航运         │          │  claim-20260604   │
└──────┬────────┘          │  -004-f: 燃气轮机  │
       │ DISCUSSES           │  -004-e: 储能六氟  │
       └───────────────────►│  -004-g: 消费      │
                            └──────────────────┘
```

## 四种节点

| 节点类型 | 关键属性 | 来源 |
|---------|---------|------|
| `Theme` | name, priority(🔥🔥🔥/🔥🔥/🔥/⚠️) | 从 claims/wiki 提取方向名称 |
| `Stock` | code, name, market(sh/sz/hk) | 研报原文中的推荐标的 |
| `Claim` | id, subject, claim_type | 已存在于 Neo4j（migrate_claims_to_neo4j.py） |
| `ResearchReport` | path, date, title | `sources/raw/财经/研报：*.md` |

## 五种关系

| 关系 | 方向 | 用途 | 关键查询 |
|------|------|------|---------|
| `BELONGS_TO` | Stock → Theme | 个股所属板块 | "储能有什么标的" |
| `RECOMMENDS` | Claim → Stock | claim 推荐哪些标的 | 从 claim 找到具体股票 |
| `RECOMMENDS` | ResearchReport → Stock | 研报原文出处 | 追溯推荐依据 |
| `DISCUSSES` | Claim → Theme | claim 讨论哪个方向 | "UP 说过燃气轮机吗" |
| `COVERS` | ResearchReport → Theme | 研报覆盖方向 | 查找方向对应的研报 |

## Agent 检索路径

```
用户问"储能有什么标的"
  → Qdrant 召回 claim-20260604-004-e（储能六氟方向）
  → Neo4j 遍历: Claim -[DISCUSSES]-> Theme(储能)
  → Theme ←[BELONGS_TO]- Stock(天赐材料/恩捷股份/鹏辉能源...)
  → 同时可查: ResearchReport -[COVERS]-> Theme 获取原文依据
  → 返回完整标的列表 + 研报出处
```
