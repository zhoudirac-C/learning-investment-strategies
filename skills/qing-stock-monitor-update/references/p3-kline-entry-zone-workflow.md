# P3-观察标的 介入区间计算工作流

## 场景

用户要求为 P3-观察标的（仅方向扩散确认，不主动买入）填充基于 K 线技术位的介入区间，供 poll 检测候选。

## K线数据源

使用新浪财经 `getKLineData` API：
```python
scale=240  # 240分钟 = 日K
datalen=30 # 最多30个交易日
```

注意：`scale=30` 返回的是30分钟K线，不是日K。

## 介入区间计算策略

| 均线排列 | 计算方法 | 公式 |
|---------|---------|------|
| 多头（MA5>MA10>MA20） | 均线法，等回踩MA5~MA10 | `[MA10-3%, MA5+2%]` |
| 空头（MA5<MA10<MA20） | 低点法，基于20日最低 | `[20日低, 20日低*1.08]` |
| 交叉/震荡 | 均线法+低点法取交集 | 均线的下沿和低点的上沿 |

## P3-观察的约束条件

- P3 标的买入只用于方向扩散确认，不是主动建仓
- `position_ratio` 统一 ≤ 0.3 成
- `hard_stop` 必须有（即使不买也要知道哪里止损）
- `confirm_signal` 必须含方向联动条件（如"昊华科技先企稳"、"隆基+爱旭同步走强"）
- `price_range` 不设 null 而是计算数字区间，poll 才能检测到候选
