# 14:00 Afternoon Monitoring Methodology

A 股 14:00 午盘监控 — 独立于晨盘/收盘复盘的盘中实时分析。定时触发，无用户交互，全自动生成。

---

## 数据采集管线（已实战验证，2026-07-27）

### 1. 指数/个股实时行情 — Tencent qt.gtimg.cn（最可靠）

**Endpoints:**
```
# 基础格式（GBK编码，需iconv）
curl -s "http://qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000688,sh000300,sz002812" | iconv -f GBK -t UTF-8

# 批量查询，逗号分隔多个code
# 前缀: sh=上交所, sz=深交所
```

**返回格式解析（36个`~`分隔字段）：**

```
v_sh000001="1~上证指数~000001~3835.61~3814.20~3808.90~410103074~0~...
```

| 索引(0-indexed) | 字段 | 说明 |
|:---:|:-----|:-----|
| 1 | 名称 | 如"上证指数" |
| 2 | 代码 | 如"000001" |
| 3 | **最新价** | 实时价格 |
| 4 | 昨收 | 昨日收盘价 |
| 5 | 今开 | 今日开盘价 |
| 6 | 成交量(手) | 整数 |
| 17 | 涨跌额 | 小数 |
| 18 | **涨跌幅** | 百分比，如0.56表示+0.56% |
| 19-20 | 最高/最低 | 日内高低 |
| 30 | 时间戳 | 如20260727141006 |
| 46 | 成交额(亿) | 如673447.91 |

**涨跌幅来自字段18**（无需自行计算），成交额使用字段46（单位亿）。

> **⚠️ 关键差异 vs Sina API**：Tencent qt.gtimg.cn 的字段18是**预计算涨跌幅**，而Sina API需要`(当前价-昨收)/昨收`自行计算。

### 2. 历史日K线/昨日量能 — Tencent ifzq

用于获取昨日成交量作为量能同比基准。

```
curl -sL "http://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh000001,day,,,5,qfq"
# 必须加 -L 跟随302重定向！
```

**返回格式：**
```json
{
  "data": {
    "sh000001": {
      "day": [
        ["2026-07-24","3853.630","3814.200","3861.040","3808.640","508203905.000"],
        ["2026-07-27","3808.90","3833.49","3841.49","3793.45","412756276"]
      ]
    }
  }
}
```
- 每个数组: [日期, 开盘价, 收盘价(实时/日终), 最高价, 最低价, 成交量(手)]
- 今日数据在K线最后一条，可以用来推算量能同比
- ⚠️ 不加 `-L` 会收到 302 跳转页面

**量能同比计算：**

| 时间点 | 全天预估系数 | 说明 |
|:------:|:----------:|:-----|
| 14:00 | ×1.2-1.3 | 通常达全日75-85% |
| 14:30 | ×1.1-1.15 | 通常达全日85-90% |
| 14:50 | ×1.02-1.05 | 接近收盘 |

公式：`预估全日 = 当前成交额 × 预估系数`

### 3. 板块强弱排名 — EastMoney push2（需要正确参数）

**两个关键参数：`fltt=2&invt=2`** 用于格式化输出，缺省或错误的参数会导致json解析失败或空响应。

```
# 行业板块涨幅TOP10
curl -s "http://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=10&po=1&np=1&fid=f3&fs=m:90+t:2&fields=f2,f3,f12,f14&fltt=2&invt=2"

# 行业板块跌幅TOP10（po=0=降序）
curl -s "http://push2.eastmoney.com/api/qt/clist/get?pn=1&pz=10&po=0&np=1&fid=f3&fs=m:90+t:2&fields=f2,f3,f12,f14&fltt=2&invt=2"
```

**参数说明：**
| 参数 | 值 | 含义 |
|:---:|:---|:-----|
| fs | `m:90+t:2` | 行业板块 |
| fs | `m:90+t:3` | 概念板块 |
| po | 1 | 升序（涨幅榜） |
| po | 0 | 降序（跌幅榜） |
| fid | f3 | 按涨跌幅排序 |
| fltt | 2 | 数值格式化为可读小数 |
| invt | 2 | 同上 |

**返回格式：**
```json
{
  "data": {
    "total": 496,
    "diff": [
      {"f2": 765.34, "f3": 9.66, "f12": "BK1458", "f14": "个护小家电"},
      ...
    ]
  }
}
```
- `f2`=最新价, `f3`=涨跌幅(%), `f12`=板块代码, `f14`=板块名称

**⚠️ 已知陷阱：**
- EastMoney有时返回 `exit=52`（空响应），这是限流信号。此时降级到从个股涨幅榜推断板块方向
- 避免15秒内重复调用同一API
- `fltt`和`invt`参数必须同时设置

### 4. UP最新观点 — Neo4j MCP

```python
# 获取最近7天所有claims
mcp__neo4j__get_recent_claims(days=7)
# 返回含 claim_type、subject、confidence、source_date

# 按类型过滤可快速定位
# claim_type: market-cycle / sector-theme / methodology / operation / risk / catalyst
```

**交叉验证方法：**
1. `market-cycle` 类 claims → 判断大盘阶段（底部/磨底/上升/退潮）
2. `sector-theme` 类 claims → 与当日板块涨跌榜对照（预期vs实际）
3. `operation` 类 claims → 操作纪律（如"不追涨"、"三步走"）
4. 偏差分析：如果UP预判"半导体回流"但实际-2.75%，说明回流尚未兑现

## 14:00 分析框架（4章）

### 第一章：全天走势回顾

**核心问题：下午在加速还是衰减？**

方法：对比 cron 启动时间（约14:01）的快照与当前（14:10-14:12）的快照。

| 模式 | 信号 | 结论 |
|:----|:-----|:-----|
| 上升加速 | 14:10涨幅 > 14:01涨幅 | 下午买盘持续涌入 |
| 冲高回落 | 14:10涨幅 < 14:01涨幅 | 早盘获利盘出货 |
| 指数分化 | 科创独跌+主板小涨 | 结构性轮动，非系统性风险 |

### 第二章：量能同比昨日

**核心问题：今天的量比昨天大还是小？**

使用 ifzq 获取昨日日K线成交量，与今日当前成交量对比。

```
量能同比 = 今日当前成交量 / 昨日全日成交量
```

| 同比 | 解读 |
|:---:|:-----|
| >100% | 放量，市场活跃度上升 |
| 80-100% | 持平或略缩量，正常 |
| <80% | 明显缩量，动能不足 |

### 第三章：板块轮动方向

**核心问题：今天钱在往哪跑？**

从 EastMoney push2 获取领涨/领跌行业板块TOP5-10。

**14:00特有的轮动判断：**
- 消费类板块（化妆品/纺织/酒店）集体大涨 → 资金从科技切消费，短期风格切换
- 半导体板块领跌 + 油气领跌 → 科技与周期双杀，市场偏好防御
- 涨幅>5%的板块数量 > 5个 → 热点扩散但次日容易分歧

**与UP观点交叉验证：** 当日实际轮动 vs claims预判方向，判断偏差。

### 第四章：尾盘操作建议

**核心原则：条件性建议，非买卖指令。**

始终包含：
1. **大盘条件**：不上触/不破位 + 量能状态
2. **持仓条件**：持仓盈亏、振幅、与今日风格的匹配度
3. **明日轮动预判**：涨幅过大板块次日常有分歧
4. **失效条件**：什么情况下建议不成立

## 已知陷阱

| 陷阱 | 表现 | 规避方法 |
|:-----|:-----|:---------|
| EastMoney空响应 | exit=52 或json解析失败 | 切换到Sina API板块排行降级 |
| ifzq 302 | 收到HTML而非JSON | 加 `-L` 参数跟随重定向 |
| Tencent GBK编码 | 中文字符乱码 | `iconv -f GBK -t UTF-8//IGNORE` |
| qt.gtimg.cn字段索引偏移 | 不同code使用的字段索引不同 | 上交所股票/指数用sh前缀字段18为涨跌幅 |
| akshare连接断开 | `RemoteDisconnected` | 直接切换Tencent/Sina API，勿重试 |
| Qdrant huggingface-hub冲突 | `huggingface-hub>=1.5.0 required` | 降级到Neo4j MCP + 文件系统 |
