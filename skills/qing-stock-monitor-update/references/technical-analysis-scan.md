## 技术分析维度（6个）

### 1. 均线系统

| 信号 | 条件 | 评分影响 |
|------|------|---------|
| 多头排列 | 价 > MA5 > MA10 > MA20 | +2 |
| 短期多头 | 价 > MA5 > MA10 | +1 |
| 空头排列 | 价 < MA5 < MA10 < MA20 | -2 |
| 短期空头 | 价 < MA5 < MA10 | -1 |
| 均线缠绕 | 其他情况 | 0 |

**关键判断**：
- 价格在 MA20 上方 5% 以上 → 中期偏强
- 价格在 MA20 下方 5% 以上 → 中期偏弱
- MA5 上穿 MA10（金叉）→ 短期转强信号
- MA5 下穿 MA10（死叉）→ 短期转弱信号

### 2. 回撤幅度

| 回撤幅度 | 含义 | 评分影响 |
|---------|------|---------|
| > 15% | 调整充分，可能反弹 | +1 |
| 5-15% | 正常调整 | 0 |
| < 5% | 仍在高位，追高风险 | -1 |
| < 0%（创新高） | 强势但需等回踩 | -1 |

**注意**：回撤为负表示当前价高于近期高点（创新高），不是"调整充分"。

### 3. 量价关系

| 量能 | 条件 | 评分影响 |
|------|------|---------|
| 放量 | 量比 > 1.5x | +1 |
| 正常 | 量比 0.5-1.5x | 0 |
| 缩量 | 量比 < 0.5x | -1 |

**关键判断**：
- 上涨 + 放量 = 资金认可，健康
- 上涨 + 缩量 = 跟风不足，可能回落
- 下跌 + 放量 = 抛压重，规避
- 下跌 + 缩量 = 抛压减轻，可能止跌

### 4. K线形态

| 形态 | 条件 | 评分影响 |
|------|------|---------|
| 长下影线 | 下影线/总振幅 > 40%，实体小 | +2 |
| 阳线反包 | 今日阳线覆盖昨日阴线实体 | +1 |
| 大阳线 | 阳线实体 > 5% | +1 |
| 大阴线 | 阴线实体 > 5% | -1 |
| 十字星 | 实体/总振幅 < 10% | 0（变盘信号）|
| 连续下跌后收阳 | 连续2天阴线后今天阳线 | +1 |

**注意**：
- 长下影线需结合位置：低位 = 止跌，高位 = 诱多
- 大阳线若出现在高位 + 放量 = 可能是出货
- 冲高回落（高开低走）= 大阴线信号，即使相对昨收是涨的

### 5. 支撑位/压力位

| 位置 | 判断 | 评分影响 |
|------|------|---------|
| 接近支撑位（< 3%） | 可能反弹 | +1 |
| 接近压力位（< 3%） | 可能受阻 | -1 |
| 在支撑和压力中间 | 方向不明 | 0 |

**支撑位来源**：
- 近期20日低点
- MA20 均线
- 前期平台低点

**压力位来源**：
- 近期20日高点
- 前期高点
- 整数关口

### 6. 涨幅适中度

| 涨幅 | 含义 | 评分影响 |
|------|------|---------|
| > 8% | 追高风险 | -1 |
| 3-8% | 温和上涨，健康 | +1 |
| 0-3% | 波动小，可观察 | +1 |
| -3-0% | 温和回调，可观察 | +1 |
| < -3% | 跌幅较大，等企稳 | 0 |

## 综合评分体系

| 总分 | 信号 | 操作建议 |
|------|------|---------|
| >= +3 | strong_buy | 强烈建议买入 |
| +1 ~ +2 | buy | 建议买入 |
| 0 | neutral | 观望 |
| -1 ~ -2 | sell | 建议卖出/规避 |
| <= -3 | strong_sell | 强烈建议卖出 |

**注意**：
- 评分高 ≠ 一定买，还需结合博主观点、介入区间、市场环境
- 评分低 ≠ 一定卖，可能是洗盘，需结合板块和持仓成本
- **博主明确不介入的方向，评分再高也不买**（如 MLCC 已提前提示）

---

## 输出分类

脚本输出分为5类：

1. **STRONG BUY（评分>=+3）**：技术信号极强，但需人工过滤已大涨的票
2. **BUY（评分+1~+2）**：技术信号积极，结合博主观点判断是否买入
3. **NEUTRAL（评分0）**：方向不明，观望
4. **SELL（评分-1~-2）**：技术信号偏空，持仓需谨慎
5. **STRONG SELL（评分<=-3）**：技术信号极弱，考虑减仓

**特殊分类**：
- **潜在机会**：评分>=0 + 涨幅<5% + 未大涨 → 今天值得关注
- **风险提示**：涨幅>5% 但评分<=0 → 可能追高，规避

## 与博主观点的交叉验证

扫描结果必须与 claims 交叉验证：

| 场景 | 处理 |
|------|------|
| 技术评分高 + 博主明确看好 | ✅ 可买入 |
| 技术评分高 + 博主明确不介入 | ❌ 不买（如 MLCC） |
| 技术评分低 + 博主明确看好 | ⏳ 等回踩，不追高 |
| 技术评分低 + 博主明确不介入 | ❌ 不买 |
| 技术评分高 + 博主未提及 | ⚠️ 可小仓位试探，写 inference_note |

## 常见陷阱

1. **新高票评分虚高**：回撤为负（创新高）时评分会+1，但这表示"仍在高位"不是"调整充分"
2. **涨停票评分高**：涨幅>8%会-1，但多头排列+放量可能抵消，导致涨停票评分仍高
3. **板块联动忽略**：单票技术好但板块走弱时，实际风险大于评分显示
4. **历史数据不足**：新上市票或数据缺失票无法分析，需标注"数据不足"

## 数据源

- **实时行情**：腾讯财经 API（`https://qt.gtimg.cn/q=`）
- **历史K线**：腾讯财经前复权K线（`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`）
- **字段顺序**：`[日期, 开盘, 收盘, 最高, 最低, 成交量]` — 注意 k[3]=最高, k[4]=最低
