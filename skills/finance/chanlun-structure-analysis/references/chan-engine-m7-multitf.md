# chan_engine vs skill 算法对比与 M7 多周期升级（2026-08-28）

## 两套引擎的口径差异（同数据实证，sh512400 2026-08-28）

| 维度 | chan_analysis.py (skill) | chan_engine (src/chan_engine/) |
|---|---|---|
| 笔 | 旧笔/宽松（异型分型间隔≥3 合并K线） | 新笔（ADR-002，课77原文） |
| 中枢 | 裸笔三三重叠，窄震荡出"线状伪中枢"（512400 [1.849,1.851] 宽0.002） | 段中枢（ADR-010），挂 L0 线段，拒绝伪中枢 |
| 背驰 | MACD柱面积，0.9 阈值 | Σ\|Δc\| 面积代理（校准门口径）+ 结构内区间套 L1/L2 |
| 买卖点 | 一/二/三买简版 | 1/3类多级（二买缺失→M7-3 补） |
| 级别 | 时间周期分别跑（日/60m/30m）人肉对齐 | 结构递归（笔→段→中枢 L1/L2），单周期输入 |
| 未来函数防护 | 无 | is_sure 全程透传 |

## 三周期 spike 关键结论（M7 立项依据）

同一引擎跑三周期（2026-08-28 收盘，512400）：
- 日线 8 月哑火（最新笔 sure=False，无中枢无买卖点）
- 60m: 中枢上移 [1.860,1.960]，1类卖 L2@8/11 + 3类买@8/19 价1.864
- 30m: 1类买 L1+L2 共振@8/19 价1.864
- **日线一笔内部，次级别已走完完整走势并给明确买卖点**——次级别是操作时机刚需

## 理论 Gap 清单（代码×课程对照，grep 实证）

已实现：分型/笔/中枢/一买一卖/三买三卖/多级中枢/区间套/is_sure（M1–M5 扎实）。
缺失（M7-3 归属，用户已拍板）：G1 走势类型状态机（盘整=1中枢/趋势=≥2同向不重叠）、G2 中枢三演化（延伸/新生/扩张）、G3 背驰前提校验（没有趋势没有背驰）、G4 二买二卖（bstype=2 全库无）、G6 recursion 九段升级。
欠缺：G7 双口径背驰（已拍板以校准门 Σ|Δc| 为准）、G8 同级别分解视角、G9 分类状态→预案、G10 小转大。
不进引擎：均线系统/吻三分类（课程P3明确"退居辅助"）、心法/韵律纪律（不可计算）。

## 教学风格（用户验证有效）

- 讲概念时先答"为什么"再展开机制（用户会连环追问 EMA→MACD面积→笔区间→次级别）
- 区间差/结构差异类问题：逐层拆解归因（笔口径→中枢哲学→趋势定性），不用"精度差异"含糊带过
- 校准门讲解模式：一句话定义 → 为什么必须有（社区难题+两库缺陷）→ 三层结构图 → 现状数字 → 与用户拍板项的关联
