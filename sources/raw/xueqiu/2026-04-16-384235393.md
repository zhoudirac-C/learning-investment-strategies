# 2026-04-16 养叔的猫

华友钴业 的一季报，很亮眼。这个一季报验证了猫叔选择持有华友钴业的中长期逻辑（价格+产能+一体化）。虽然因为霍尔木兹海峡，短期硫磺/地缘仍有扰动，但基本面已显著改善，估值仍具安全边际。 图1：镍价近十年走势（2017-2026） 图2：镍价走势（1980-2026） 这个镍价的走势图，是猫叔买入 华友钴业 的一个立足点。 从1987年看，镍价有明显的 15~20年超级周期 ： 1988小高峰 → 2001低谷； 2003启动 → 2007高峰 → 2009崩落； 2016启动 → 2022次高峰（挤仓）→ ？ 历史大底部区间是 $5K~15K ，当前 $16K~$18K 处于历史中位数偏上。镍的两个超级大牛市都和中国需求有关。 2003~2007：中国重工业化。 2016~2022： 新能源 （电池）需求预期，叠加俄乌战争。 镍的下一波大机会，核心逻辑也是中国 新能源 +印尼冶炼一体化。 这也正是 华友钴业 的核心赛道。 当前，猫叔对镍价的判断，它可能处于2016超级周期的回调消化期。 如果新能源需求逻辑持续，$15K~18K 可能是未来几年的底部支撑区。 艾略特说，四月是残忍的季节，荒地上开满丁香…… 但猫叔 相信，人间四月芳菲尽，山寺桃花始盛开。 言归正传，接下来简单说下 华友钴业 的一季报。 一、先看看核心财报数据 成绩单非常亮眼！ 综合而言， 华友钴业 的一季度利润翻倍的驱动因素有三： 1、镍、钴、锂等金属价格回升（镍价从底部$14k涨至$35k附近）； 2、产品销量增加； 3、印尼镍湿法冶炼产能持续释放（一体化的规模优势）。 非经常性损益4.27亿，最大项是非流动性资产处置损益 4.805亿（卖资产一次性收益），这是管理层在高景气期“卖资产降负债”的主动操作，属于理性风险管理。 其他诸如政府补助+0.197亿、公允价值变动-0.363亿等扣非后真实经营增长仍达68.76%。真实经营改善同样强劲。 印尼湿法项目（华越、华飞等）权益产能已释放，MHP出货持续高位。 经营现金流11.75亿正增长，销售商品现金流入294.78亿（同比大增），说明回款良好。 资产端，货币资金223.35亿（较年初+56.7亿），在建工程160.25亿（较年初+23.3%），产能扩张仍在加速。 总之，Q1利润翻倍是价格周期回暖 + 印尼一体化规模效应落地 + 销量放量的必然结果。扣非68.76%已把一次性收益剔除，含金量极高。 三、丰收下的隐忧，三个不让人放心的地方 1. 成本传导压力 财报必须看毛利率，这是猫叔一直强调的。 华友钴业 2026年Q1的毛利率 20.7%， 2025毛利率14.9%。 同比来看，毛利率改善了，但 营业成本增速（34.8%）几乎追上了营收增速（44.6%） 。 类似 华友钴业 这样的资源一体化企业，它们的命门在于： 赚的钱，有多少是被上游成本吃掉了？ 硫磺是 MHP（氢氧化镍钴）生产的关键原料，占生产成本的 30%-44%。霍尔木兹海峡封锁短期无解，4月中下旬部分工厂的硫磺库存可能面临见底。这是悬在成本端的一把刀。 猫叔判断 短期成本压力仍然存在，金属价格必须维持在当前位置，才能覆盖走高的成本！因为 大宗商品 公司，成本控制才是真正的大考，一旦金属价格回调弧度加大，利润弹性会非常大。 2. 高杠杆+高Capex 总负债： 1110亿 （+12.6%）； 资产负债率： 63.6% （相当重）； 在建工程： 160亿 （+23.3%）——印尼镍冶炼产能还在大力扩张； 本季度融资现金净流入： 79亿； 华友钴业 正在用高杠杆押注镍钴景气周期。其实这不是华友的个例——印尼镍湿法冶炼是典型的资本密集型赛道，所有人都知道高负债是常态。但问题是，如果金属价格中期回落，能不能扛过去？ 成则龙头，败则深渊。这是资源一体化企业的必然特征，但必须承认风险，这是我们持仓必须想清楚的问题。 3. 金属价格波动是双刃剑 公司镍业务收入占比近50%，利润对镍价高度敏感，弹性大，波动也大。 这既是华友的魅力，也是它的风险。 目前LME镍约18200美元/吨（4月中旬），国内沪镍14.1万/吨左右，短期受印尼HPM政策+硫磺扰动支撑，但供给压力始终存在。钴去钴化趋势长期压制钴价。 接下来，印尼持续放量，供给压力不小，能否守住是问号。 刚果（金）钴的供给波动+新能源电池去钴化趋势，长期来看会压制钴价。 公司利润对金属价格高度敏感，弹性大、波动也大！ 华友钴业 PE 12.5x 其实不算不贵，一体化资源股里属于偏低的了。 低 PE + 高杠杆 + 强周期 = 需要对金属价格中周期有信仰才能持有。 但不宜买成重仓股，高负债率+capex大，单独押注风险高，可以在投资组合中占15%左右。 关于那个非经常性损益，处置资产拿了4.8亿，这说明公司也在“趁景气高点卖资产降负债”，管理层不是纯乐观——这是好事，说明他们知道风险。 财报是后视镜，股价反映的是未来。 猫叔建议大家接下来跟踪三个关键变量： 首先，4 月底的镍钴价格走势 ，是否在当前位置企稳。 其次，硫磺到港动态 ，霍尔木兹封锁的实际影响何时能边际缓解。 第三，二季度在建工程进度 ，产能释放节奏是否符合预期。 人间四月芳菲尽，山寺桃花始盛开。 当市场对周期板块充满疑虑时，基本面的改善其实往往已经悄然发生。 华友钴业 一季度的利润翻倍就是最好体现。 但我们也必须清醒认识到，负债率 63.6%、160 亿在建工程、79 亿融资净流入——这是一艘高速行驶的大船，转向慢，刹车也慢。 猫叔投资华友，本质上是押注镍钴的中期价格中枢（ 新能源 大趋势），以及管理层能否在景气高点成功降杠杆。 这是中长期逻辑，不是短线博弈的筹码。 $华友钴业(SH603799)$ $上证指数(SH000001)$ 猫叔注：本文所有数据均来自 华友钴业 官方一季报，仅供参考，不构成投资建议。投资有风险，决策需结合自身情况，独立判断。
