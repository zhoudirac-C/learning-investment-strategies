# 无 UP 观点时的技术分析推断规则

> 当博主近期未明确提及某标的的操作建议时，基于技术框架和市场数据推断合理操作。
> 所有推断必须标注来源，禁止伪装成 UP 原话。

---

## 推断触发条件

满足以下任一条件时，启动技术推断：

1. `up_mention_status.last_mentioned_date` 距今 > 3 个交易日
2. `up_mention_status.explicit_operation` 为 null
3. 用户主动要求"看看某标的是否能买/卖"

---

## 推断流程

```
Step 1: 读取技术数据
  └─ K线：MA5/10/20、RSI、MACD、成交量
  └─ 分时：开盘位置、盘中高低、收盘位置、量能分布
  └─ 板块：组内联动、相对强弱、资金流向
  └─ 【新增】板块定位：通过 stock_sector_mapper 获取个股在板块内的实时排名和量化地位

Step 2: 匹配技术框架
  └─ 读取 framework/technical-analysis-framework.md
  └─ 匹配当前形态属于哪种 playbook

Step 3: 生成推断
  └─ 观察池 → 推断买点区间 + 触发条件 + 失效条件
  └─ 持仓 → 推断持有/做T/减仓 + 触发条件 + 失效条件

Step 4: 标注推断
  └─ 写入 inference_note 字段
  └─ confidence 根据形态清晰度评定
```

---

## 观察池推断规则

### 趋势判断

| 形态 | 推断买点 | confidence |
|------|---------|------------|
| 5/10/20 多头排列，缩量回踩 MA5 | 回踩 MA5 附近 | 高 |
| 突破平台后首板，封单坚决 | 等分歧回踩平台上轨 | 中 |
| 长下影线 + 放量，测试支撑有效 | 下影线低点附近 | 中 |
| 长上影线 + 放量，抛压明显 | 暂不买，等缩量整理 | 低 |
| 跌破 MA20，无修复 | 不买，观察 | 高（不买） |

### 板块联动判断

| 场景 | 推断 |
|------|------|
| 龙头涨停 + 跟风同步上涨 | 板块健康，可观察龙头分歧买点 |
| 龙头涨停 + 跟风大跌 | 板块分化，降低预期或规避 |
| 组内全部缩量整理 | 等待方向选择，不提前介入 |

### 无 UP 标注时的板块定位（三层定位法）

当 `up_mention_status` 显示 UP 近期未提及该标的时，使用 `stock_sector_mapper` 获取实时板块定位：

```python
from qing_investment.agent.tools.stock_sector_mapper import get_stock_positioning, to_agent_format

result = get_stock_positioning("002892")
print(to_agent_format(result))
# 输出包含：板块内排名、涨幅、市值、换手率、量化标签（日内龙头/中军/趋势/跟风）
```

**量化标签规则**（与 `stock_analyst` 节点一致）：

| 标签 | 判定条件 | 推断影响 |
|------|---------|---------|
| 日内龙头 | 板块前3 + 涨幅>5% | confidence 升一级，trigger 条件放宽 |
| 前排强势 | 板块前5 + 涨幅>3% | confidence 不变，正常观察 |
| 中军/板块稳定器 | 市值>500亿 + 排名前30% + 涨幅>0% | 持有信心增强，波动预期降低 |
| 趋势/趋势容量票 | 市值>300亿 + 涨幅>0% + 换手<8% | 适合持股，trigger 以均线/趋势为主 |
| 跟风 | 排名后50% + 涨幅>0% | confidence 降一级，不单独介入 |
| 弱势 | 涨幅≤0% | 不买，若持仓则触发风控检查 |

**使用原则**：
- UP 有标注 → 优先采用 UP 定位，用实时数据验证
- UP 无标注 → 完全依赖量化标签，但必须在 `inference_note` 中注明"无 UP 观点，基于实时板块排名推断"
- 量化标签与技术面矛盾时（如量化标签为"日内龙头"但 K 线形态为长上影线），以技术面为准，confidence 降级

## 持仓推断规则

### 持有判断

| 条件 | 动作 |
|------|------|
| 价格在成本上方 + 趋势 intact + 板块健康 | 持有 |
| 浮盈 > 10% + 出现长上影线 | 考虑做T（减仓一半） |
| 浮亏 < 5% + 趋势未破 | 持有观察 |

### 减仓/风控判断

| 条件 | 动作 |
|------|------|
| 触及 risk_line 且 30 分钟不能收回 | 减仓或清仓 |
| 板块龙头大跌 + 自身同步走弱 | 减仓 |
| UP 明确规避该方向（如半导体） | 清仓 |

### 做T判断

| 条件 | 低吸区间 | 高抛区间 |
|------|---------|---------|
| 大盘企稳 + 个股缩量回踩 MA5 | MA5 附近 | 前高或长上影线高点 |
| 板块早盘分歧 + 个股跟随回调 | 分时均线下方 1-2% | 分时均线上方 2-3% |

---

## confidence 评定标准

| confidence | 标准 | 仓位建议 |
|------------|------|---------|
| 高 | 多周期共振（日线+分时+板块），形态清晰 | 正常仓位 |
| 中 | 部分共振，有少量矛盾信号 | 半仓试探 |
| 低 | 信号混乱，方向不明 | 只观察不买 |

---

## 推断禁忌

- ❌ 不推断"UP 会怎么看"——只基于技术框架推断
- ❌ 不给出无条件买卖指令——必须写触发和失效条件
- ❌ confidence 虚高——形态不清晰时强制降级
- ❌ 忽略板块风险——单票技术好但板块走弱时降低 confidence
- ✅ 推断必须写 inference_note
- ✅ 推断失效条件必须明确
- ✅ 与 UP 原话冲突时，优先 UP 原话
