# 模式提名：尾盘抢筹分支选择（强势分支的次日预期差）

## 模式内容

1. **前一日尾盘被抢筹的强势分支，次日往往难以维持**——抢筹把当日回流预期提前兑现，
   次日变成"利好出尽"。
2. 反过来，**当日分歧充分、尾盘没有被抢筹的分支，次日回流预期更强**——
   筹码在分歧中沉淀，预期差留给了明天。
3. 科技分歧期选分支：看抗跌领涨，而不是抄跌得最多的那一支。

## 触发与动作

- 触发：分歧日的尾盘（14:30-15:00），观察各强势分支是否出现尾盘集中抢筹。
- 动作：尾盘被抢筹的分支次日不追；分歧充分未抢筹的分支列入次日回流观察。
