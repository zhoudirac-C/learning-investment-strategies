# 2025-06-25 炼金女王

股息投资的核心是股息可持续，未来分红比当下多（至少持平），换句话说就是：要找到一只下蛋的母鸡，尤其是一只永远下蛋的母鸡，并且产蛋率高于大多数的鸡。 上篇文章我已围绕高股息投资策略进行了一些分析，提醒不要只看当前的股息率，投资是投未来。以前我还写过《 港股是地狱也是天堂——我的低估值高股息投资思路 》《 网页链接 { 央企收息的 “三个代表” } 》，系统阐述了股息投资的底层逻辑与实践路径。 当我们考虑到利润和分红可持续性，方能体会弱周期优质标的的稀缺性。 这类企业不仅有持续充沛的现金流、连续性的分红政策，还有穿越经济周期的抗风险能力，市场中看似符合标准的公司众多，但真正能将稳定转化为长期价值的“常青树”，实则凤毛麟角。本篇从弱周期这个点出发，来对比分析利润稳定、分红持续的重要性。 1、特许经营的高速公路 高速公路关系到居民出行以及物流运输，像 宁沪高速 和 粤高速 等企业，依托核心路产，车流量大且稳定，营收与利润有保障。在经济下行时，需求下滑幅度有限，关于高速公路的分析详见《 从商业模式看高速公路未来的投资要点 》。 宁沪高速 和 粤高速A 的的利润和分红都很稳定，且宁沪高速分红率持续保持在50%+，粤高速A的分红率持续在70%+。 高速公路赚钱能力毋庸置疑，但是在分红意愿上，不是每家公司都很慷慨，管理层需要根据公司实际发展情况来决定分多少。 在之前分析高速公路时，就曾挖掘出四川成渝提高了高分红比例，并且之后也有不错的回报。 四川成渝在2024年3月15日发布了2023-2025年股东回报规划，提出将分红比例提升至不低于60%（2022年分红率40%），公告至今A股涨幅35%，H股涨幅125%， 大涨之后H股市盈率还有6.6%，得到了市场的认可。 其控股股东蜀道集团还持有大量优质资产，未来有注入的预期，详见《 高速公路资产注入带来的投资机会 》。 2、永续的现金奶牛—水电 水电作为清洁能源，其成本低、业务可持续经营。即便在经济波动时，电力刚性需求使其受冲击小。且水电站折旧政策特殊，后期利润提升空间大，长期分红稳定，具体分析详见《 算一算长江电力利润增长空间 》。 下图是 长江电力 的归母净利润和每股分红变化，利润非常稳定，只有在来水偏枯的时候小幅下滑；在分红上也很慷慨，从2003年每股0.09元提高到2024年的每股0.943元，长期分红率保持在70%+，已经把70%的分红线写进了公司章程。 这样有赚钱能力又愿意分红的公司，在股价上也不会亏待投资者（如下图所示的 长江电力 年度走势，截图于雪球）。 假设20年前的今天买入长江电力，当天股价收盘于8.16元，按照每股分红0.943元，则股息率在不除权的情况下有11.56%；十年前收盘12.34元，股息率7.64% ，当前股价30.67元，股息率仍然有3.07%，未来利润还有一定的增长，每股分红也就有提升空间，若股价不涨的情况下，股息率会更高。 即便目前只有3.1%的股息，但是相较于十年期国债收益率1.7%左右，保险的预定利率也由2%下调至1.5%，稳定的长江电力仍然能获得机构的偏爱。 有句话叫“最好的投资是在十年前，其次是在当下”，站在当下看未来，市场也有一些标的是值得投资的。 3、现金流向好分红提升的绿色动力 绿色动力（A股绿色动力，H股绿色动力环保）是经营垃圾焚烧发电的，在特许经营权模式下其业务也能做到可持续经营。行业及个股的具体分析详见《 固废处理—垃圾焚烧发电投资拐点已至 》《 变废为宝的赚钱生意：垃圾焚烧发电这几家公司值得关注 》。 绿色动力是在2024年8月30日公布的《未来三年股东分红回报规划（2024-2026）》，明确提出未来三年每年以现金方式分配的利润分别不低于当年实现的可分配利润的 40%、45%、50%。从公布至今A股涨幅35%，H股涨幅78%，而实际上2024年分红率高达71%， 目前H股股息率仍有6.6%。至于提高分红的原因，我的看法是资本开支减少，自由现金流转正，项目运营利润提高。 该公司在规划未来的分红时，给投资者一个确定的预期，加上H股天然相较于A股存在折价，使得H股股息率更高，并且港股投资者更钟爱高股息，若分红能够持续的话就有一些不错的投资机会。 4、总结 A股有赚钱能力的公司非常多，但加上盈利的稳定性和分红的持续性这两个条件的话，站在高股息的投资视角绝大部分公司都会被筛掉。我个人一直在做高股息投资策略，这方面我会持续分享自己的观点，欢迎点赞关注。 $中国神华(SH601088)$ $长江电力(SH600900)$ $贵州茅台(SH600519)$ @ericwarn丁宁 @管我财 @丹书铁券 @大只若鱼 @czy710
