## 〇、两次分析错误（必须记录）

### 错误 1（第一版）：循环论证

用"半导体"关键词搜 ETF，然后从"半导体 ETF"里选，得出结论"ETF 只能覆盖半导体"。
**第一梯队环节横跨多个口径**（半导体设备/材料、光通信、模拟芯片），不能用一个行业词去搜。

### 错误 2（第二版）：只看标的质量，不看实际敞口

算出 588170 命中率 88% 就推荐它——但**用户实际只持有 200 股（约 177 元）**。
**命中率再高，仓位为零也无意义。**

**∴ 正确做法：标的筛选 × 实际敞口，两者都要看。**
**并且：positions.yaml 的 `etf_exposure_matrix` 早在 9/7 就做过同样的分析——先读它，不要重新发明。**

## 二、判据的正确理解

UP 原文最后六字：「**二者缺一都只能算题材**」。

| | 国产化率低（空间） | 批量供货（时点） | 定性 |
|---|---|---|---|
| 有业绩支撑 | ✅ | ✅ | **可参与** |
| 题材 | 缺任一 | | 只作加分项 |

### 为什么在今晚提这个判据

```
风格切换完成（量价确认）→ 方向对了
    ↓
但级别只是「反弹不是反转」（无新叙事）
    ↓
∴ 只能用"个股业绩确定性"兜底
    ↓
国产化率低（空间）× 批量供货（时点）
```

**本质是"反弹级别"下的防御性选股工具。**
