# 17:00 Daily Market Review Methodology

生成 A 股收盘复盘（17:00），当 UP 尚未发布复盘或需要独立交叉验证时使用。

## 数据管线优先级

| 优先级 | 数据源 | 用途 | 典型故障模式 |
|--------|--------|------|-------------|
| P0 | **Sina 基础行情 API** (`hq.sinajs.cn`) | 指数行情、个股实时价 | 极少故障。需 `-H 'Referer: https://finance.sina.com.cn'` |
| P0 | **Neo4j MCP** (`mcp__neo4j__*`) | 最新 claims、观点关系搜索 | 稳定 |
| P1 | **Sina 排行 API** | 个股涨跌排名（涨幅/跌幅 TOP20） | 需 `node=hs_a` 参数，最大 100 条 |
| P2 | **akshare** (`ak.stock_*`) | 板块强弱、资金流向 | EastMoney 后端限流，常返回空响应 |
| P3 | **EastMoney push2** (`push2.eastmoney.com`) | 龙虎榜、全市场统计 | 高限流，15s 内多次调用即空响应 |

> 详细降级路径见 `references/pipeline-fallback-data-gathering.md`

## 标准报告结构（6 章节）

| # | 章节 | 内容 | 关键操作 |
|---|------|------|---------|
| 1 | 核心结论 | 3-5 条高度凝练的判断 | 结论前置，每条含因果链 |
| 2 | 关键分析 | 指数、量能、板块、资金、持仓 | 分点展开，数据支撑 |
| 3 | 今日格局判断 | 周期定位、情景对比、偏差分析 | 必须引用 claims 做交叉验证 |
| 4 | 风险与不确定性 | 次日核心变量、失效条件 | 明确触发/失效边界 |
| 5 | 配置方向建议 | 情景推演、方向跟踪、操作纪律 | 分情景给出操作（A/B/C） |
| 6 | 监控系统复盘 | 提醒频次、误报漏报、配置检查 | 引用 Script Output 数据 |

## 数据采集清单（按顺序执行）

### 1. 大盘指数

```bash
curl -s 'https://hq.sinajs.cn/list=sh000001,sz399001,sz399006,sh000688' \
  -H 'Referer: https://finance.sina.com.cn' | iconv -f GBK -t UTF-8//IGNORE
```

关键计算：涨跌幅 = (当前价 - 昨收价) / 昨收价 × 100，成交额(亿) = 第9字段 / 1e8

### 2. 涨跌家数

**首选**：akshare `stock_zh_a_spot_em()` 全量统计
**降级**：从 Sina 排行 API 的涨幅榜/跌幅榜 TOP20 手工估测（标注"局部采样"）

### 3. 板块轮动

**首选**：akshare `stock_sector_spot()` 返回49个行业板块排名
**降级**：从个股涨幅/跌幅TOP20推断板块方向（见 pipeline-fallback-data-gathering.md §Step 3 降级策略）

### 4. 龙虎榜资金

**不要重查**——直接从 cron 上下文 `Script Output` 引用：
- 龙虎榜净买TOP5 → 方向确认（如盛屯矿业+4.82亿=有色吸筹）
- 持仓命中 → 标的验证（如通富微电-1.54亿=封测资金流出）
- 板块汇总 → 资金信号方向

### 5. 持仓复盘

直接从 cron 上下文引用：代码、成本、当前价、浮盈率。计算振幅和量比辅助判断。

### 6. 战略框架（Claims）

通过 Neo4j MCP 获取最近 7 天 claims，提取：
- `market-cycle` → 大盘阶段判断
- `sector-theme` → 板块方向锚定
- `operation` → 操作纪律
- `methodology` → 情景推演框架（情景A/B/C）
- `catalyst` → 当日催化剂（如谷歌财报）

### 7. 情景偏差分析

将 UP 前一日的情景推演（如 "情景A：谷歌超预期 → 海外链修复"）与当日实际走势对比：
- 兑现/未兑现 → 判断市场定价逻辑是否变化
- 偏差归因 → 如"谷歌利好但科技不涨=资金借利好出货，性质更差"

## 完整交叉验证流程

```
① 数据层（Sina API / akshare / Script Output）
    ↓
② 逻辑层（指数分析 + 板块推断 + 资金流向 + 情景推演）
    ↓
③ 验证层（Neo4j claims 数据 vs 今日实际走势 → 判断偏差）
    ↓
④ 输出层（核心结论→关键分析→格局判断→风险→配置→系统复盘）
```

## 常用风险核验清单

| 核验项 | 数据来源 | 信号 |
|--------|---------|------|
| 跌停家数是否扩散 | TOP20跌幅榜 | >30家→系统性风险 |
| 涨停家数/梯队完整性 | TOP20涨幅榜 | ≥10家20cm→方向确认 |
| 科创50是否止跌 | Sina指数 | 连跌2日→科技趋势破坏 |
| 量能是否维持 | 成交额>1.5万亿 | 低于1万亿→动能不足 |
| 龙虎榜机构净买方向 | Script Output | 连续3日同方向→趋势确认 |
