# 2026-08-19 老柏树也有春天

从 2026 年中开始，微信通过 A2A（Agent-to-Agent）智能体协作，把能力开放给手机厂商自带的语音助手——荣耀 YOYO、 小米 小爱、华为小艺、OPPO 小布、vivo Jovi 等。简单说，就是"喊一声手机助手 → 助手调起微信 → 发消息、打通话"。 消息刚出来时，我也吃了一惊：这不是妥妥把微信"管道化"了吗？以后大家都用手机助手调用微信来联系彼此，微信不就退居幕后、再也碰不到用户了？ 后来仔细复盘了一下历史，才恍然大悟——原来，我又被专有名词忽悠了。先说结论：微信与手机助手打通，并不是微信被管道化，只是外面套了件更漂亮的衣裳。它不仅没有被管道化，反而顺手堵死了竞品冲击社交关系链的路。 下面，请听我慢慢道来。 一、人们社交关系迁移的关键是什么？ 在拆解这个问题之前，不妨先抛开所有专有名词的干扰，直击底层逻辑的变化。 "人机交互界面""管道化"……人们为了解释现象，发明了一大堆专有名词。可有时这些词非但没把问题讲简单，反而让它变得似是而非。所以，我先把这些名词搁在一边，直接从社交关系的迁移史说起。 什么是社交关系？说白了，就是人与人之间的联系。一个人和亲戚、和朋友、甚至和一面之缘的陌生人建立联系，便织成了自己的社交关系网。 而这个关系网落到现实里，是什么？是通讯录。没错，就是各位手机里那串长长的名字列表。 自打电话被发明，人们的通讯录只经历过两次大迁徙。座机时代，它长这样：一个随身携带的电话本，密密麻麻记着熟人的姓名和号码。无论是拨盘电话还是按键电话，哪怕后来有了大哥大——早期大哥大虽能存号，却也只能存几十个纯数字、存不了名字——通讯录始终是那个纸质小本本。通信技术从有线到无线，场景从固定到移动，交互界面从拨盘到按键加 LED 数码管，可承载人际关系的那个本子，一直没变。 人们是什么时候丢掉它的？是大哥大的升级版——手机登场时。当大哥大越做越小、屏幕从数码管换成液晶，最关键的，是存储能力升级：不再只存号码，还能同时存名字。于是纸质小本本，才被存进手机内存的通讯录取代。此后相互联系，人们不再翻本子，而是直接从手机里调通讯录。这次改变的动机，叫"方便"。 顺带说一句，手机还干掉了一个"中间产物"——BP 机。BP 机当年也是重要的联络工具，却有个硬伤：两台 BP 机之间不能直接互发，信息必须经由寻呼台转接。发信人得先打电话给话务员，报上对方号码和要转达的代码（比如"01"代表"请回电"），寻呼台再把编码广播出去。既然无法直接通信，很快就被能双向互发短信的手机淘汰了。 手机作为主要通讯工具的地位，一直维持到微信出现。微信起初只抢了短信的活儿；待互联网技术成熟，语音、视频通话上线，才真正取代手机电话，成为人们日常联络的主通道。承载社交关系的通讯录，也从 SIM 卡里的电话通讯录，变成了微信里的微信号。人们见面不再交换号码，而是"加个微信呗"。而驱动这次迁移的，不是"方便"，是"免费"——发条短信几毛，通个电话几块到十几块，煲电话粥更贵；微信却全免费，文字免费、语音免费，最后还多了电话做不到的视频通话。这一下，彻底宣告了电话作为主通讯工具的落幕。 自电话发明以来，承载社交关系的通讯录只迁徙过两次：一次从纸质小本本迁到手机通讯录，一次从手机通讯录迁到微信号。无论过程是场景扩展、界面变化还是技术迭代，通讯录本身只动了这两次；而两次的理由各不相同——第一次是"更方便"（效率），第二次是"更便宜"（成本）。前提是体验能平替，不能明显降级，比如通话质量变差、短信延迟变长。 若把时间轴再往前拉到古代，同样会发现：社交关系媒介的演进，也只沿着"更方便""更便宜"两条路走，从没出现过第三条。书信从竹简到绢帛，是因传递"更方便"；从绢帛到纸张，是因"更便宜"。传递方式从马匹到汽车、再到电报，也无非是更快（效率）和更省（成本）。 所以，研究社交关系迁移，只要盯住通讯录就够了；而通讯录迁徙的驱动力，只有两个——"是否更方便"和"是否更便宜"。"人机交互界面的变化""管道化"这类术语，不过是浮在表面的壳，大可不必理会。 二、微信打通手机助手，究竟意欲何为？ 回过头看，微信于今年年中打通了与主流手机助手的通道，用户动动嘴就能唤起自己的手机助手去打开微信，联系父母、兄弟、朋友。这一招，图什么？ 通过手机助手打开 App，算不算"方便"了用户？显然是。在很多场景下，它确实更顺手。既然出现了迁徙驱动力之一——"方便"，就埋下了迁徙的风险。假设 腾讯 死守微信通道不开放，假以时日，市面上会不会冒出另一本承载社交关系的通讯录，主动去连各家手机助手？一旦用户觉得它"更方便"，会不会先安利亲戚、再安利朋友，把关系网迁过去？我认为，完全有可能。 而 腾讯 顺势打开通道、主动联通各大手机助手，"更方便"这个口子，是不是就被堵上了？答案显然。没好处，用户自然没动力迁徙。 那么，这一举措里，微信丢了什么、又得了什么？ 某些场景下，用户不再直接点开微信，而是经由手机助手调起，微信少了和用户"见面的机会"，退到了幕后。可这"面子"重要吗？其实没那么要紧——无非是少了用户点进微信、翻找联系人的那一下；而用户换来了"更方便"的体验。这买卖很划算：用户点进微信找联系人的过程，除了混个脸熟，以微信的克制，绝不会中途塞个 3 秒广告。所以，这是丢了面子、赚了里子，稳赚。 往后，手机助手 Agent 会不会顺带带来点 token 的生意？哈哈，未可知。但只要用户的通讯录不迁徙，哪怕再多开些通道——比如透过手机助手约朋友开黑王者——最后也是把朋友带进王者，而不是引去梦幻西游。让手机助手打开朋友圈、逛公众号、进搜一搜，甚至刷视频号，这些动作只是省了用户"点一下"，进去之后的事一样没省：朋友圈得自己刷，公众号得自己看，视频号得自己划，里面的广告、直播带货、皮肤售卖，一个不少。这难道不是"丢面子、赚里子"的生意？ 再说，微信也留了私心：除联系人外，其他功能暂时没开放，为什么？给"小微"留了后手。大家想想，微信本就常驻后台，倘若日后小微也能替代手机助手去呼叫联系人，直接调起游戏、视频号、公众号、朋友圈、支付、小程序等整条微信生态，用户会怎么选？ 而竞品想走到这一步，得先抢下"联系人列表"这座山头，才能垒起生态护城河。如今这条路由微信"让渡点面子"给堵死了。 三、结论 微信开通手机助手通道，护城河不仅没受损，反而更牢了些；竞品借手机助手侧翼偷袭社交关系的大门，也被关上。这分明是让渡点面子、赚足里子的交易，划算得很。而且，就这点让出去的面子，日后小微还有极大概率全找补回来。微信的社交关系护城河，非但没变窄，反而更宽广了。 这，就是微信这步棋背后的真正算盘。 你怎么看？欢迎在评论区聊聊——你平时会用手机助手发微信吗？
