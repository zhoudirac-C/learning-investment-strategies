# 大盘分析方法论

> 从 UP（青枫浦上Q）2026年1月至6月的 190 篇早盘/复盘中系统提取的大盘分析框架。
> 每条方法论对应具体 claim ID，可追溯原文。

---

## 一、多级别顶底结构分析（L1：指数结构）

UP 的大盘分析最核心的方法是**多时间维度级联递进**的顶底结构判断。

### 1.1 五级别递进体系

从低级到高级：**15分钟 → 30分钟 → 60分钟 → 90分钟 → 120分钟 → 日线 → 周线**

| 级别 | 底部信号 | 顶部信号 | 典型调整周期 |
|------|---------|---------|------------|
| 15分钟 | — | 钝化=禁追高 \[[60508](#claim-20260508-001-a)\] | 盘中级别 |
| 30分钟 | 结构形成→3天反弹 \[[60310](#claim-20260310-001-a)\] | 钝化+高9=小级别高点 \[[60113](#claim-20260113-001-a)\] | 3天 |
| 60分钟 | 结构形成→2天窗口 \[[60317](#claim-20260317-001-a)\]; 底部形态形成→买入窗口 \[[60202](#claim-20260202-001-a)\] | 钝化消失=无卖出理由 \[[60106](#claim-20260106-001-a)\] | 2天 |
| 90分钟 | — | 结构形成→8天调整 \[[60507](#claim-20260507-001-a)\]; 生死判定二元框架 \[[60508](#claim-20260508-001-a)\] | 8天 |
| 120分钟 | — | 钝化+顶背离→阶段性调整 \[[60225](#claim-20260225-001-a)\] | 4-6天 |
| 日线 | — | 顶部结构压制→反弹持续差 \[[60306](#claim-20260306-001-a)\] | 数周 |
| 周线 | — | 大级别顶部+月线高9→优先于小级别 \[[60226](#claim-20260226-001-a)\] | 数月 |

**级别权重原则**：大周期（周线/月线）的判断权重高于小周期（60/90/120分钟）。

### 1.2 钝化→结构→操作的完整链路

```
钝化出现（警惕）
  → 结构形成（执行减仓）
  → 钝化消失（纠错买回）
```

- **钝化** = 风险信号，只观察不操作 \[[60106](#claim-20260106-001-a)\]
- **结构形成** = 执行信号，减仓 \[[60226](#claim-20260226-001-a)\]
- **钝化消失** = 纠错信号，买回 \[[60303](#claim-20260303-001-a)\]

关键区分：纠错看的是"钝化消失"而非"结构消失"——两者有本质区别。

### 1.3 多级别级联操作

UP 的分层操作节奏：

- **60/90分钟顶部结构消失** → 纠错买回（小级别解除警报）
- **日线+120分钟顶部结构形成** → 再次减仓（大级别风险确认）\[[60303](#claim-20260303-001-a)\]

核心节奏：**买在小级别解除，卖在大级别形成**。

### 1.4 九转序列（TD Sequential）

九转序列是 UP **从 1 月初就开始持续使用的技术工具**，贯穿日线、90分钟、60分钟等不同级别。

**核心规则**：拿当前收盘价，与 **4 根K线前**的收盘价比较。
- 连续 9 根更高 → **高9**（超买）
- 连续 9 根更低 → **低9**（超卖）

**关键判断——趋势方向决定信号有效性（UP 核心金句）**：

| 大趋势方向 | 出现信号 | 有效性 | 操作含义 |
|-----------|---------|--------|---------|
| 📈 上升趋势（主级正向波） | 高9 | **容易失效** | 别追高，但别卖光。调几天可能继续上 |
| 📈 上升趋势（主级正向波） | 低9 | **有效** | 回调到位，可作为反弹标准 |
| 📉 下跌趋势（主级逆向波） | 高9 | **有效** | 反弹到位，应该卖出 |
| 📉 下跌趋势（主级逆向波） | 低9 | **容易失效** | 只是反弹不是反转，别抄底 |

> UP 原话： 「大趋势向上时，高9代表的含义很明确：今天别追高。阶段性偏高，后面可能走震荡，也可能小幅下探，但调整幅度不一定会大。」 \\[[周复盘-0415](#sources/raw/财经/周复盘：26-04-15：节奏预期，日线高9，算力租赁生死考验，趋势中做短线.md)\\]

**多级别九转的配合规则**：

| 组合信号 | 含义 | 来源 |
|---------|------|------|
| 日线高9→高10区间 | 信号生效概率增大，不宜追涨 | \\[[60105](#claim-20260105-001-a)\\] |
| 90分钟高9+MACD顶部钝化 | 顶部风险加剧 | \\[[60113](#claim-20260113-001-a)\\] |
| 90分钟低9+日线低9（双低9） | 见底概率大 | \\[[60609-c](../claims/claim-20260609-001-c.yaml)\\] |
| 高9+MACD顶部结构 | 确认顶部，执行减仓 | 后续演进 |
| 低9+MACD底部结构 | 确认底部，可试错 | 后续演进 |

**九转的局限性**：九转是**计数器**而非趋势判断工具。它只告诉你"涨/跌了多久"，不告诉你"方向变了没有"。方向判断要靠 MACD 多级别结构和全A指数。

### 1.5 斐波那契数列时间窗口

UP 使用斐波那契数列主要做 **时间推算**——从关键高点/低点起算，数到特定天数时注意变盘。

**关键数字**：8, 13, 21, 34, 55（斐波那契数列：每个数=前两个相加）

**使用方法**：
1. 找到近期明显的**高点或低点**
2. 数到今天经过了多少个**交易日**
3. 看是否接近 8/13/21/34/55 这些数字
4. 如果接近（误差≤3天），说明进入**斐波那契时间窗口**，变盘概率增大

**UP 的使用案例**：

| 时间 | 事件 | 斐波那契依据 | 来源 |
|------|------|------------|------|
| 5月14日日线顶部结构 | 预计调整约16个交易日 | 介于13和21之间（斐波那契数列经验值） | \\[[60526-a](../claims/claim-20260526-025.yaml)\\] |
| 抄底方法论 | "时间和空间只需确定一个" | 时间维度用斐波那契推算周期更易确定 | \\[[60526-c](../claims/claim-20260526-025.yaml)\\] |

> 解释：5月14日顶部结构→预计调整16天。16介于13和21之间（正好是斐波那契数的"中间区域"）。实际到6月3日（第15天）UP 说"调整临近尾声"——在13-21天窗口内。

**斐波那契的用法规则**：
- **时间窗口**：接近 8/13/21/34/55 交易日时注意方向选择
- **双窗口共振**：两个以上斐波那契数同时到达（如55和21同时到期），信号强度加倍
- **时间+结构共振**：斐波那契节点 + MACD 多级别结构 → 信号最可靠
- **时间和空间只需确定一个**：能确定空间（点位）就用空间，确定不了就确定时间

> 参考：UP 原话「你在空间和时间上确定一个就好。你如果能确定空间，那么就用空间。你如果确定不了空间，那么确定时间。」 \\[[60526-c](../claims/claim-20260526-025.yaml)\\]

### 1.6 关键点位体系

| 点位 | 含义 | 来源 |
|------|------|------|
| 4095点 | 趋势重新成立的确认线（收盘突破才算） | \](claim-20260203-001-b) |
| 4033点 | 清仓线（跌破趋势确认破坏） | 后续演进 \](claim-20260603-001-b) |
| 4130点 | 满仓线（趋势确认主升开启） | 后续演进 |
| 4120点 | 趋势买点（突破后上涨具持续性） | 后续演进 |

### 1.7 支撑确认方法

同一价位多次长下影线（如3次）= 强支撑确认。每次触及该价位都有资金强力承接，支撑可信度随触及次数递增 \](claim-20260316-001-a)。

### 1.8 底部构造的节奏

1. **急跌→反抽（2-3天）**：缩量反弹、无强扩散主线
2. **二次回踩（第二只脚）**：反抽后的再次回落确认底部
3. **底部确认**：第二只脚不破前低+核心主线抗跌 \[[60326](#claim-20260326-001-a)\]

真底部需满足两条件：
1. 共振领涨板块具备完整阵型（中军+先锋主升结构）
2. 大资金进攻强度足够（成交额前20有主动强势品种）\[[60324](#claim-20260324-001-a)\]

## 二、全A广度与量能分析（L2：市场广度）

### 2.1 全A指数的核心地位

全A指数是 UP 大盘分析中**唯一需要重点盯住的确认指标**。全A中阳线企稳 = 建仓信号。全A处于趋势性下跌中时，一切局部热点都是存量博弈下的腾挪，情绪周期也难有清晰结构。

> 详见已有 claim：`claim-20260608-004-b`（企稳三条件）、`claim-20260611-001`（全A趋势下跌23交易日）

### 2.2 量能阈值体系

| 量能水平 | 含义 | 来源 |
|---------|------|------|
| >3.5万亿 | 阶段性顶部（历史规律） | 后续演进 |
| 3万亿 | 警戒线：突破后警惕回调 | \[[60107](#claim-20260107-001-a)\] |
| 2.7-3万亿 | 恐慌换手降温，可考虑低吸 | 后续演进 |
| <2万亿 | 底部区域（需配合其他条件） | \[[60212](#claim-20260212-001-a)\] |

从放量峰值缩量至近腰斩→时间窗口临界值接近。但**首次地量 ≠ 地价**，缩量见底是一个过程 \[[60122-a](#claim-20260122-001-a)\]。

### 2.3 量能+振幅双维度变盘信号

成交额创年内新低 + 振幅创阶段新低 = 变盘临近。此后：
- 持续缩量+大金融/情绪不失控 → 可积极试错
- 突然放量 → 先确认方向再行动 \[[60211](#claim-20260211-001-a)\]

### 2.4 量价关系

K线大幅抛离均线 + 量能萎缩 = 资金缺乏连续上攻动力。情绪高涨但量能跟不上=动能衰竭信号 \[[60109](#claim-20260109-001-a)\]。

### 2.5 大盘三要素框架

UP 的系统化大盘判断框架（2026年1月提出）：**量能 + 大金融 + 情绪**——三要素同时判断，缺一不可 \[[60120](#claim-20260120-001-a)\]。

## 三、微盘股联动分析（L3：市场结构）

### 3.1 三指数共振原则

健康的情绪周期需要**主线指数 + 微盘股 + 全A** 三者同步向上。可以一个涨得快一个涨得慢，但不能一个往上涨、一个往下哐哐掉——不同步时，下跌的那个会**反压上涨的板块**。

> 详见已有 claim：`claim-20260604-005-b`（大小盘同步方法）

### 3.2 历史验证

| 时间 | 状态 | 结果 |
|------|------|------|
| 3/24、4/8、4/29 | 三指数同步向上 | 健康完整情绪周期 |
| 5/22 PCB | 微盘股持续破位 | 未能走出完整主升 |

## 四、情绪判断体系（L4：市场情绪）

### 4.1 跌停阈值

| 跌停家数 | 信号 | 来源 |
|---------|------|------|
| 跌停开始减少 | 情绪修复启动 | 后续演进 |
| 10家以内 | 情绪修复确认 | 后续演进 |
| 5家以下+无异常波动 | **做空情绪释放完毕**，可进入试错期 | \[[60122-b](#claim-20260122-001-b)\] |
| 完全消灭 | 情绪出清完成 | 后续演进 |

修复路径：跌停减少 → 5家以内 → 完全消灭 \[[60203-a](#claim-20260203-001-a)\]。

### 4.2 双冰点结构

**量化定义**：昨日恐慌盘集中释放 + 今日低开且红盘家数 <1000 = **双冰点结构确认**。其他情景：
- 红盘 <1500 → 弱修复
- 红盘 >2000 → 修复偏快，警惕追高
- 冰点 = 新周期起点，但新主线需经历 2-3 方向竞争后分歧中持续走强才确立 \[[60203-a](#claim-20260203-001-a)\]

### 4.3 假摔与拐点的两日判断法

单日走势不能区分假摔还是真拐点，必须看**连续两日组合**：
- **假摔** = 今日不强修复（震荡/下跌）+ 明日强修复 → 拐点延后，今天尾盘/明天早盘布局
- **直接修复** = 今日强修复 → 拐点今日确认，盘中跟进
- **两种路径都指向拐点**，差异只在操作节奏。两天都不修复则重新评估 \[[60519-b](#claim-20260519-001-b)\]

### 4.4 情绪滞后规律

指数高点出现后，市场情绪存在约 **2天滞后性**——结构形成后短线仍有操作窗口，可"两天快跑"不恋战 \[[60507](#claim-20260507-001-a)\]。

## 五、综合判断框架

UP 的大盘分析是一个**从结构到广度再到情绪的多层验证体系**：

```
第一层（L1）：120分钟/90分钟/60分钟顶底结构走到哪？
  ├─ 顶部结构形成 → 减仓、不追高
  ├─ 底部结构形成 → 小仓位试错
  └─ 钝化消失 → 纠错买回

第二层（L2）：全A和量能怎么走？
  ├─ 全A趋势下跌 → 所有局部热点都是存量博弈
  ├─ 全A中阳线 → 唯一建仓确认信号
  └─ 量能靠近2万亿 → 底部区域，但等第二只脚

第三层（L3）：微盘股和主线是否共振？
  ├─ 三指数同步 → 健康周期
  └─ 微盘破位 → 压制主线，收缩战线

第四层（L4）：情绪数据验证了吗？
  ├─ 跌停 <5家 → 做空释放完毕
  ├─ 双冰点 → 可基础仓位试错
  └─ 假摔/拐点两日判断 → 确定操作节奏
```

### 级别冲突时的处理原则

- **大级别优先**：周线顶部 > 日线顶部 > 120分钟 > 90分钟 > 60分钟
- **上级别顶部压制下**：小级别底部信号只是反弹窗口而非反转
- **不预测只跟随**：在结构未明朗前不预判方向，等市场自己选择
