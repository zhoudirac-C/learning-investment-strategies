## 〇、上一版的口径错误（必须记录）

**第一版错误**：用"半导体"关键词搜 ETF，然后从"半导体 ETF"里选，得出结论说
"ETF 只能覆盖半导体"——这是**循环论证**。

**为什么错**：第一梯队环节横跨多个行业口径，不属于"半导体材料设备"指数：

| 第一梯队环节 | 实际所属行业口径 | 需要什么 ETF |
|---|---|---|
| 量测设备 / 静电卡盘 / 陶瓷加热器 | 半导体设备 | 半导体设备类 ✅ |
| ArF 光刻胶 | 半导体材料 | 半导体材料类 ✅ |
| **高端磷化铟 InP / 光芯片** | **光通信** | **通信/光通信类** |
| **AI 服务器电源芯片** | **模拟/电源芯片** | 需另找 |
| 重掺硅片 | 半导体材料 | 半导体材料类 ✅ |

**∴ 正确做法：按"环节"去反查"哪些 ETF 含这些成分股"，而不是按行业词去搜 ETF。**

## 二、判据的正确理解

UP 原文最后六字是核心：「**二者缺一都只能算题材**」。

| | 国产化率低（空间） | 批量供货（时点） | 定性 |
|---|---|---|---|
| 有业绩支撑 | ✅ | ✅ | **可参与** |
| 题材 | 缺任一 | | 只作加分项 |

### 为什么在今晚提这个判据

```
风格切换完成（量价确认）→ 方向对了
    ↓
但级别只是「反弹不是反转」（无新叙事）
    ↓
∴ 只能用"个股业绩确定性"兜底
    ↓
国产化率低（空间）× 批量供货（时点）
```

**本质是"反弹级别"下的防御性选股工具。**
