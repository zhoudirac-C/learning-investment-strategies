# 模式提名：两尺度仓位管理（短线按情绪、波段按结构）

## 模式内容

1. 仓位拆两个尺度独立管理：**短线仓位按情绪端信号**（高度宽度背离、晋级率、亏钱效应）；
   **波段仓位按结构信号**（浪型位置、顶底结构确认、量能承接前提）。
2. 禁止跨尺度指挥：「不要用一个尺度上的信号去指挥另一个尺度上的仓位」——情绪退潮只触发
   短线仓调整，不直接触发波段仓减仓；结构破坏才动波段仓。
3. 波段仓卖出纪律：上升趋势中卖出要慢——左侧逃顶被反复纠错的成本，高于右侧多让出的那一段
   （「卖出容易，原价买回来很难」）。触发器 = 60min MACD 柱转绿（顶部结构 100% 确认）；
   前置条件 = 量能不失守、承接不消失。前提破了，再慢就变成硬扛。
4. 单尺度合并输出是操作层温差的根因：情绪退潮（短线信号）被直接翻译成整体降仓位，
   导致比 UP 口径偏左一个身位。

## 触发与动作

- 触发：operation 输出时（盲判每日；qing 复盘持仓计划同理）。
- 动作：先声明本判断作用于哪个尺度；两尺度信号方向冲突时（如情绪退潮 + 结构未破坏），
  action 必须分尺度表述（短线降 / 波段持），禁止合并成单一的「降仓位」；
  position 定位涉及「反弹超预期/高位兑现」时，必须附带波段尺度的触发器与前置条件。
