# 2024-09-03 躺红利摊转债

在当前的A股市场上，市净率低于0.4倍的银行就有五家，分别是 民生银行 、 贵阳银行 、 郑州银行 、 华夏银行 和 浦发银行 ，估值数据如下： 这五家银行的平均市净率仅有0.34倍，几乎是四大行估值的一半，为什么会出现这么大的差异呢，我们可以从银行不良认定的角度来观察这五家银行与公认的优质大行 建行 的差距。 一般来说，不良贷款认定严格与否的标准可以观察逾期贷款/不良贷款的数据，这个数值越低、意味着不良认定越严格，如果用更严格的标准的话，可以再加上重组贷款，即（逾期贷款+重组贷款）/不良贷款。 先来看不良贷款和逾期贷款数据： 单看不良率的话其实很容易得出 民生银行 、 浦发银行 和 建设银行 资产质量接近的错觉，甚至不良率再高一些的 贵阳银行 和 华夏银行 也还凑合，但是一看逾期贷款的话，其他五家银行就原形毕露了，建行将所有逾期贷款都纳入了不良，而其他五家就几乎是放飞自我了，像 郑州银行 的的逾期贷款几乎达到了不良贷款的2.5倍，即很多的不良贷款被“藏”了起来。 如果把其他五家银行按 建行 的不良认定标准来划分不良贷款的话会如何呢？数据如下： 如果按照 建行 的不良认定标准，五家银行的不良率都超过了2%， 郑州银行 的不良率甚至接近5%......如果把用这套标准计算的不良减去原本不良的数据作为隐藏不良贷款的话，郑州银行的隐藏贷款已经超过当前总市值的70%了...... 如果再严格一点的话，把逾期贷款+重组贷款和不良贷款相比较，数据如下： 如果算上重组贷款的话， 民生银行 的不良认定标准就进一步弱化了，反倒是重组贷款不多的 浦发银行 和 华夏银行 与 建行 的差距拉近了，至于 郑州银行 ，我实在没有在中报的数据中找到重组贷款的数据，翻了翻23年年报，这个数据也没有披露，有知道的欢迎在评论区留言。 其实影响银行估值的因素有很多，像运营效率、收入结构、拨备储备、核充率都是重要因素，不过我个人最关注的还是资产质量数据，毕竟对于银行业这种超高杠杆的行业来说，资产质量的一点小波动被杠杆放大后都可能给股东带来重大损失，所以有些银行的估值明显低于同行也就不奇怪了，甚至我认为其中某几家银行的估值并没有反应其资产质量真实的糟糕程度........ 我个人喜欢用关注贷款、逾期贷款和重组贷款来辅助判断银行的资产质量，虽然说用这些数据去衡量不良认定有些不够准确，或者说不够合理，但是对于摊大饼的格式投资者而言却足够了，一眼能分辨出来的胖瘦才是真胖瘦。 好了，以上就是本文的全部内容了，非专业人士点评银行，欢迎各位大佬批评指正~ $民生银行(SH600016)$ $建设银行(SH601939)$ $浦发银行(SH600000)$ 风险提示： 本文所提到的观点仅代表个人的意见，所涉及标的不作推荐，据此买卖，风险自负。
