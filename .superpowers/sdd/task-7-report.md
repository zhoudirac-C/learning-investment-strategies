## 修复方法（seg-001..004 共用）

**故障确认**：原版 bars 以 `o=前一根收盘价` 生成，但 h/l 只包住 c 未包住 o
（如 seg-001 bar2 `[10.3, 11.6, 10.7, 11.4]`：l=10.7 > min(o,c)=10.3），
与诊断一致（seg-001: 8 根、seg-002: 6 根、seg-003: 8 根、seg-004: 9 根非法）。

**修复**：以文件头注释的设计意图为准整体重推 (o,h,l,c)——**pivot 极值价格与所在
bar 索引全部原样保留**，expect 全部未改（索引/方向/区间与新 bars 自洽）：

| 用例 | 保留的 pivot（价格@索引） |
|---|---|
| seg-001 | 10@1 / 14@5 / 12@9 / 16@13 / 13@17 / 15@21 / 11@25 |
| seg-002 | 16@1 / 12@5 / 14@9 / 10@13 / 13@17 / 11@21 / 15@25 |
| seg-003 | 10@1 / 14@5 / 12@9 / 17@13 / 15@17 / 16@21 / 13@25 |
| seg-004 | 10@1 / 16@5 / 12@9 / 15@13 / 11@17 / 14@21 |

**bars 生成模板**（BSP-001 风格，肩部 0.35）：上涨腿 bar `[l+0.105, l+0.35, l, l+0.245]`，
下跌腿镜像；腿内 l（上涨）/h（下跌）按 **ease-in-out**（(1−cos πt)/2）在两端 pivot
极值间插值，pivot 邻近步长仅 14.6% 腿幅。每根 bar 满足 `h≥max(o,c)` 且 `l≤min(o,c)`；
腿内严格单调 → 分型恰在 pivot 处、相邻无包含；pivot 间距 4（≥1 根独立 K 线，满足
ADR-002 暂定默认新笔口径）。

**为什么用 ease-in-out + 小肩部（重要设计决策）**：初版用肩部 0.7 + 线性插值，
机械校验全过，但 chanpy 适配器参考对照暴露问题——CChanConfig 默认
`bi_fx_check="strict"`（= ADR-001 口径 A 的强形式）：向上笔要求"顶中间 bar 高 >
底分型 3 根合并最高高"且"底中间 bar 低 < 顶分型 3 根合并最低低"。seg-003 的
bi 17→21（15→16，间距 1.0）处，底@17 合并区间上沿被前腿 bar16 高 16.025 顶到，
顶@21 高 16.0 不超 → chanpy 把 13→25 并成一笔，fx/bi 全部错位。这类
"口径 A/B 结论相反"的歧义样本属于 BI-003 的仲裁证据，不应污染线段/中枢用例。
改用 ease-in-out 后，分型 3 根合并区间紧贴 pivot 极值，**全部 9 条用例的每一笔在
口径 A（chanpy STRICT）与口径 B（中间 K 线）下同真**（校验器按生成 bars 数值逐笔
断言）。修复说明已写入各文件头注释。

**修复前后 bars 对照**：pivot bar 极值（h 或 l）逐一相等、位置不变；非 pivot bar 的
o/h/l/c 全部重推（原版非法 bar 的 l 不再简单贴到 o 上，而是按腿内插值重构走势，
保持腿内单调、无包含）。closes 序列相应微调（原 closes 只是生成的中间产物，
设计意图由 pivot 承载，全部保留）。

## 新写 5 条的设计要点

### SEG-005 古怪线段标准化（claim-20070906-001-c）
- 按课 78 原文"古怪线段唯一成因"构造：向下线段 B=bi0..bi8
  （20→16→18→14→21→15→17→13→16→12，pivot@1/5/9/13/17/21/25/29/33/37）。
- bi3 上（14→21）对 B 构成第一种情况笔破坏（21>bi1 高 18），但特征序列
  X1=bi1[16,18]、X2=bi3[14,21]：X2 低点 14<16 → 无顶分型 → B 未破坏；
  向下线段 bi4..bi6（21→15→17→13）跌破 bi3 底 14 → 按课 78"B 没结束，继续延续"；
  bi3 高 21>B 起点 20 → **"线段开始点不是最高点"的古怪情形**，标准化后按
  实际区间视为 21→12（claim 的标准化处理）。
- B 的终结：特征序列续 X3=bi5[15,17]、X4=bi7[13,16]、X5=bi9[12,15.5]、X6=bi11[14,16.5]，
  X5 高低点均最低成底分型、无缺口 → 第一种情况，seg0 在 bi8 底（bar37=12.0）结束。
- expect：seg `(0,8,down,sure=true)` + `(9,11,up,sure=false)`（seg1 首三笔重合
  [14,15.5] 成段未破坏）。注释注明：Segment 模型无区间字段，标准化区间不直接入
  expect，本用例以 seg0 覆盖 bi0..bi8（含内部最高点 21）钉住古怪结构。

### ZS-001 三段重叠区间公式（claim-20061218-001-b + claim-20061226-001-a）
- 段=笔（BSP-001 口径）：A=bi1 下[17,19]、B=bi2 上[17,20]、C=bi3 下[18,20]。
- 按 claim 公式：ZD=max(17,17,18)=**18**（来自 C 低点）、ZG=min(19,20,20)=**19**
  （来自 A 高点）——特意让 ZD/ZG 来自不同段以钉住 max/min 公式。
- expect zs `{zd:18, zg:19, start_idx:5, end_idx:17, level:1, sure:true}`；
  bi4 上（18→21）离开中枢。

### ZS-002 中枢延伸（claim-20061226-001-b）
- bi1..bi3 成中枢 [17,18] 于 bar17 确立（ZD=max(16,16,17)=17、ZG=min(18,19,19)=18）；
  延伸段 bi4[17,18.5]、bi5[17.2,18.5] 均与 [17,18] 重叠且不产生新中枢 →
  "盘整的延伸就在于不能产生新的中枢"，同一中枢延展至 bi5 终点 bar25（共 5 段，
  延伸 ≤5 段不升级，与 ZS-003 对照）；bi6 上（17.2→20）离开。
- expect zs `{zd:17, zg:18, start_idx:5, end_idx:25, level:1, sure:true}`。

### ZS-003 九段升级（claim-20070302-001-b）
- bi1..bi9 共 9 段连续重叠震荡（3 段成中枢 + 6 段延伸 → 构成更大级别中枢）：
  zs1=bi1..bi3 → [16,17]；zs2=bi4..bi6 → [16.5,18]；zs3=bi7..bi9 → [16.2,17.8]；
  三个本级别中枢重合 = [max(16,16.5,16.2), min(17,18,17.8)] = **[16.5,17]**。
- expect 只列升级后结果 `{zd:16.5, zg:17, start_idx:5, end_idx:41, level:2, sure:true}`
  （3 个 level=1 中枢为中间产物，注释中给出全部推导）；bi10 上（16.2→19）离开。

### ZS-004 趋势两中枢不重叠（claim-20061226-001-c）
- 向上趋势：中枢1=bi1..bi3 → [13,14]（bar5..17）；连接段 bi4 上（13→18，
  定理一"连接两个中枢的必然是次级别以下走势"）；中枢2=bi5..bi7 → [17,18]（bar21..33）。
- 两中枢依次同向且绝对不重叠（中枢2 ZD=17 > 中枢1 ZG=14）→ 趋势成立；
  bi8 上（17→20）离开。注："中枢绝对不重叠"明文另见 claim-20061226-001-a，
  本用例按 brief 挂 -c（注释已说明）。

共同构造性质：分型中心间隔 4 根 K 线、腿内单调无包含、pivot 极值精确落位、
每笔区间条件在口径 A/B 下均成立（同修复族的生成模板与校验）。
