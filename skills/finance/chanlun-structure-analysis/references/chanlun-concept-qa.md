# 缠论概念答疑口径（会话验证过的理论问答）

## Q1: 缠论为什么不看量能？

1. **不是完全不看**：缠师原文提过"放量突破中枢上沿"可作三买确认加分项，但量从不在核心定义链（分型→笔→中枢→背驰全靠价格+MACD面积）
2. **价格已包含成交信息**：每根K线形态本身就是量能博弈的最终记录
3. **MACD柱面积替代了量能角色**：传统"量价背离"（价新高量萎缩=衰竭）被替换为更稳定的度量——趋势力度=同向笔的MACD柱面积。面积本质是价格的二阶导数信息（动能变化率），与量萎缩表达同一件事但噪声小得多
4. **抗操纵性排序**：价格几何结构 > MACD动能 > 成交量。对倒可造天量，但伪造"不背驰的趋势结构"需持续真金白银推升，成本高；指数级完全无法操纵 → 缠论在指数上最准
5. **实践分工**：结构盲区在"突破真假确认"和"资金接力判断"——个股叠加量能/换手/龙虎榜做验证，是互补不是替代

## Q2: MACD 柱面积怎么算？（chan_analysis.py:109-173 实现口径）

1. EMA12/EMA26：k=2/(N+1)，首值用首根close做种子（同一标的内部对比时种子差异抵消）
2. DIF = EMA12 − EMA26（趋势"速度"）
3. DEA = DIF 的 9日EMA（速度均值→加速度）；柱 hist = (DIF−DEA)×2（×2是软件可视化惯例，常数因子不影响面积对比）
4. 面积 = 笔区间内 |hist| 求和（bi_macd_area：笔起止合并K线映射回原始K线索引[lo,hi]，sum(abs(hist))）——按笔分段不是全图累加；取绝对值防中途红绿翻转稀释总动能
5. 背驰判定：同向隔一笔对比，a2 < a1×0.9 且价格延伸（底背驰创新低/顶背驰创新高）
6. 实例（517520 日线顶背驰 8/24@2.358）：前笔面积0.26 vs 后笔0.16，0.16 < 0.234 ✅——价格新高但动能质量缩水>10%

## Q3: 小体量票适合缠论吗？

- 缠论假设走势=群体合力的自组织结果；参与者越多越分散越可靠：指数 > 大市值/宽基ETF > 中盘 > 小体量题材股
- 小票失效机制：游资一两个账户就能人为画分型/假突破；一字板无成交博弈使分型定义失真；连板波动由资金意图决定而非合力衰竭，背驰失效或滞后
- 小票正确工具：涨停性质（封单/开板次数）、换手率、龙虎榜席位、板块效应、情绪周期
- 反直觉点：小票波动大≠更适合抓波动——防守线频繁假止损 + 真跌破连续跌停跑不掉，风险收益两头不占
- 实操口径（用户既定）：缠论只用于大盘指数+ETF定仓位性质与时机；主板个股用量能/换手/支撑压力/K线/分时；小票突发涨停不做结构追入

## Q4: P2的均线背驰 vs 后面MACD绿柱面积——为什么换了？

同构：都是"快慢线差值的|·|时间累加"。均线面积=Σ|MA5−MA10|（P2教学口径）；柱面积=Σ2|DIF−DEA|（P4实战口径）。物理含义相同：短期成本偏离长期成本的总能量=趋势力度。
换工具原因：①EMA无SMA窗口跳变假信号；②DEA提供自参照基准，对衰竭更敏感；③逐bar有确定数值，与笔分段天然配合可程序化。
口径结论：数值不可互换（参数不同），方向性结论一致，冲突时以MACD为准。

## Q5: 中枢图解教学法（512400案例验证有效）

用用户持仓ETF真实数据画图讲解，流程见 SKILL.md"概念教学"节。讲解脚本：
①下跌笔结束(7/20低1.605) → ②回抽不创新低(8/3低1.753) → 三段重叠区=中枢[≈1.75,1.85] → ③离开中枢(8/11高2.029) → ④第一次回试不回中枢下沿(8/14低1.849)=破坏(L18定理三)+二买 → ⑤再离开。
