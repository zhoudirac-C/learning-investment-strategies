# 2026-02-03 山高林茂

$藏格矿业(SZ000408)$ $紫金矿业(SH601899)$ 自2024年起我就反复说这么几个观点：一是这轮铜可能创下史诗级的历史景气周期，并解释说含义为铜价会不断创出历史纪录，并且会在高位运行时间也创下历史纪录。二是自亚洲金融危机到现在全球发生的历次地区或全球性危机后，各国政府均采取相同的措施来应对——开动印钞机，这近三十年全球各国政府超发了天量的货币。货币超发虽然不能及时在物价上反应出来，但累积到一定量后必然会报复性反应出来。这是基本哲理——由量变到质变。三是我从现在起不关心铜价未来涨到多少？我更关心的是未来新的顶部出现后，铜价在下一轮周期中跌到多少？相对上一轮底部价格抬高多少？因为这对 藏格矿业 参股并由 紫金矿业 负责运营的巨龙铜矿来说至关重要！因为这个铜矿是一个低品位的特大铜矿，同时由于海拔高度等原因，开采成本较高。作为准备以长期持有藏格矿业股票收息养老的投资者，我更关心在未来铜价低谷出现后这个铜矿的盈利水平。今天看到国家宣布进一步扩大铜的战略储备，我的心情就是吃了一颗定心丸！ 这么说原因在：1、现在铜价运行在10万元以上，这个时候国家选择出台这一政策对于我们这些投资 藏格矿业 的投资者太振奋人心了！这意味着国家决策层在审视全球经济发展后认为现在这个价格扩大铜的战略储备既有现实必要、更有投资价值。一句话就是国家经济决策部门认为现在铜价便宜，现在进行收储在成本核算上是划算的。2、虽然我不敢肯定地说未来新一轮铜价的底部就是现在十万元左右的价格。因为国家储备战略物质通常是从两个方面来考虑的。一是未来与相关储备战略物质相关的品种价格畸高时抛售，达到平抑物价的目的。二是未来由于特殊原因供应链出现问题时才启用。无论是哪种情况都意味着国家抛售战略储备物质时的价格是会大幅高于收储价格的。从这个角度而言也许十万左右的铜价就是未来铜价中长期的最低价！ 其实就巨龙铜矿而言铜价达到5.1万元以上就有不错的盈利了。这不是我主观猜测，而是 紫金矿业 经过认真测算后之前已经公布了的数据。我们可以回顾 下2020年紫金矿业受让巨龙铜矿时一次性补偿条款的相关内容。当时双方约定在上海 有色金属 网铜价达到4.9至5.1万时紫金矿业给予铜矿原相关股东一次补偿8.1亿余元。超出部分不予补偿。这足以说明紫金矿业认真测算后根据当时的物价水平只要铜价达到4.9万元就有一定的盈利能力。 现在国家决定扩大铜战略储备时的铜价已经是上述价格倍数。所以过去总有些人说未来铜价跌了么办？我过去从来不与这类人争论，更不会发表自己的看法。我只是在想未来即使跌了，我们先看它跌到什么位置？是不是跌到4.9至5.1万元这个当年 紫金矿业 认真测算过的价格去。现在好了，我彻底放心了！既然国家在10万以上的价格时扩大铜的收储，未来铜价就绝无可能跌到4.9至5.1万元这个价了。
